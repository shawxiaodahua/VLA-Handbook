## 1. 核心架构/方法总览 (Overview / Architecture)

GALA 是两阶段框架：

- **Stage 1 几何感知潜动作学习**：从 RGB + 末端执行器点云的 start→goal 转移中，联合学出「视觉潜动作」与「几何潜动作」两组离散潜码。
- **Stage 2 几何感知 VLA 协同训练**：冻结潜码作为监督信号，通过 bridge token 注入 VLM，配合共享 DiT + 具身专属动作头输出原生动作。

### 1.2 关键机制 (Key Mechanism)

- **为什么用点云而非关节向量/MANO 网格**：无序点云不需要不同末端执行器共享同一运动学结构或拓扑，因而人手、灵巧手、仿真手、平行夹爪可以「同一格式」表达。
- **为什么解码要条件于初始几何**：若只给目标点云，潜码可能退化成"绝对姿态/形态"的捷径编码；条件化初始几何后，潜码被迫编码"start→goal 的转移"而非静态外形。
- **为什么要成对增广**：对 start-goal 点云对施加同一随机 3D 变换（尺度 a、旋转 R、平移 t），保持相对运动不变但扰动绝对坐标，降低对数据集坐标系的过拟合。
- **为什么要双向学习**：前向 + 后向共享编码器/码本/解码器，作为额外的转移监督，且不强制 Z_f 与 Z_b 之间有显式关系。
- **为什么保留原生动作空间**：不为统一动作空间而做人工重定向，而是共享 DiT + 各具身专属动作头，保留每个数据集的控制语义与维度。

⚡ **Eureka Moment**：让"末端执行器的 3D 几何转移"成为与 RGB 潜动作并列的一路显式监督，并用 UEMR 保证这路潜码跨具身可共享——把"手怎么动"从隐式视觉线索升级为可对齐的几何信号。

## 2. 数学核心 (Math Core)

📌 **Napkin Formula**（一行抓住本质）：

```
L_VLA = L_action + λ_latent · ( ℒ_img + λ_geo · ℒ_geo )
  即 共享DiT的流匹配动作损失 + 两路潜码交叉熵监督
```

**目标**：在不统一动作空间的前提下，让多具身数据（含无动作标签的人类视频）共同监督一个 VLA。

**(a) 几何潜动作量化 (EMA-VQ)**：

```
k_j = argmin_k || z_j^G − e_k ||_2^2 ,   q_j^G = e_{k_j}
```

**(b) UEMR 几何重建 (Chamfer Distance)**，解码器条件于初始几何：

```
P̂_g^R = D_G( P_s^R , Q(Z^G) )
P̂_g^L = D_G( P_s^L , Q(Z^G) )
L_G-rec = m^R · CD(P̂_g^R, P_g^R) + m^L · CD(P̂_g^L, P_g^L)
```

**(c) 成对几何增广**（同变换作用于两端，保相对运动）：

```
A(P) = a · R · P + t
(P_s^h , P_g^h) ↦ ( A(P_s^h) , A(P_g^h) )
```

**(d) 双向转移 + 总潜动作损失**：

```
Z_f^G = E_G(X_s, X_g, ℓ)   # 前向，重建 goal
Z_b^G = E_G(X_g, X_s, ℓ)   # 后向，重建 start
L_LAM = L_forward + L_backward
L_forward = L_I-rec + L_I-codebook + β·L_I-commit
          + λ_G·L_G-rec + β·λ_G·L_G-commit
```

**(e) Stage 2 具身条件流匹配**：

```
A_t^τ = τ·A_t + (1−τ)·ε ,  τ ~ U[0,1] ,  ε ~ N(0, I)
V_{θ,e}(A_t^τ | x_t, s_t, τ) = h_e( f_DiT(A_t^τ, x_t, s_t, τ) )
L_action = E_{τ,ε}[ || V_{θ,e}(A_t^τ | x_t, s_t, τ) − (A_t − ε) ||_2^2 ]
```

**(f) 潜码预测 (CE)**：

```
L_latent = CE(k^img, k̂^img) + λ_geo · CE(k^geo, k̂^geo)
```

**变量说明**：

| 符号 | 含义 |
|------|------|
| e | 具身 (embodiment) |
| h ∈ {L,R} | 左/右手侧 |
| P_t^{e,h} | 时刻 t 的末端执行器点云，N=1024 |
| Z^G / N_p | 几何潜表示 / 点云潜码个数 |
| {e_k}, K_G | 共享 EMA-VQ 码本及其大小 |
| m^R, m^L | 左右手有效性掩码 |
| X_t | 时刻 t 的多模态观测 (I_t, P_t^L, P_t^R) |
| τ | 流匹配时间步 |
| λ_G, λ_geo, λ_latent, β | 各损失权重 |
| h_e | 具身 e 专属动作头 |

**直觉**：整个系统的杠杆点是「条件化解码」——因为解码时已知初始几何，共享潜码里"不能"再塞形态/绝对坐标信息，只能塞"转移语义"，于是跨具身共享才变得有意义。

> 符号与本文/相关文档保持一致：Z^G 与文中 Z^G 同义；k 表示量化后的离散码索引。

## 3. 带数字走一遍：玩具例子 (Worked Example)

设某 start-goal 片段里右手抓一个杯子，点云 N=1024，共享码本 K_G=512。

1. **编码**：PTv3 把 (P_s^R, P_g^R) 编码为 N_p 个几何特征，比如 N_p=8。经 EMA-VQ，每个特征命中最近码 e_{k_j}（最近邻距离按平方 L2 计算）。
2. **重建**：D_G 接收「初始几何 P_s^R + 量化潜码 Q(Z^G)」，输出归一化目标点云 P̂_g^R。若抓握动作是"三指收拢 2cm"，则 CD 会惩罚预测点云与真值在指尖区域的偏差——指尖区域点少，误差权重自然放大，这正是"细粒度"监督的来源。
3. **成对增广**：对 (P_s, P_g) 同时施加 a=0.9、绕 z 轴 R(15°)、t=(2,−1,0)。两端一起变，相对位移不变 → 潜码仍应能重建出相同的相对运动。
4. **双向**：把 (X_g, X_s) 交换再跑一次，让 Z_b 重建回 start。
5. **探针验证**：冻结潜码后训练 MLP 预测 y = [Δp, ΔR, Δq_finger]。GALA 得到 Pos 5.359cm / Rot 7.898° / Finger 7.585°（论文 Table I），优于仅图像版 GALA w/o PC 的 6.790 / 8.567 / 15.113——尤其手指误差几乎腰斩。

一个可复述的闭环：**点云转移 → 量化潜码 → 条件化重建 → CD 反向传播 → 潜码学会"转移语义"**。

## 6. 能力与失败模式 (Capabilities & Failure Modes)

**能做**：
- 从无动作标签的人类 ego-centric 视频中学习可跨具身共享的细粒度末端运动表示。
- 在异构具身（人手 / 灵巧手 / 平行夹爪）混合训练时，带来正向迁移（Table IV 的 +12.6）。
- 保留各具身原生动作空间，无需人工重定向。

**不能做 / 未验证**：
- 实验限于桌面操作；**未在移动操作、双臂全身、人形行走操作上验证**，不要外推。
- 真实世界仅 4 个任务（Pick/Push/Press/Flip）与单一 12-DoF XHand 平台，跨硬件泛化待复现。
- 依赖 URDF/MJCF + 前向运动学与单目手部重建；重建误差与 URDF 缺失会直接污染几何潜码。
- 检索评测的"共享语义"结论依赖人工标注的 grasp/hold/release 标签，标签质量影响结论强度。

### 6.1 隐含假设 (Hidden Assumptions)

- **假设点云能在统一轴约定与手腕/根部中心坐标系下对齐**：跨数据集坐标系不一致时的鲁棒性未充分展示。
- **假设"转移级潜码"足以承载操作语义**：接触力、摩擦、材质等非几何属性不在几何分支内；力敏任务（如 PSR 所指的 contact-rich）可能触及天花板。
- **假设 SAM2 前的单目手部重建质量足够**：WiLoR/MANO 在遮挡、快速运动下的误差会隐性传导到潜码。
