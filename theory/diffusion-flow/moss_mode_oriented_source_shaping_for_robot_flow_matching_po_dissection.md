这篇论文解决什么？机器人同一个观测往往有多个都可行的动作——从左边绕还是右边绕、先抓左杯还是右杯。扩散策略和 flow matching 能表示这种多模态，但**最终执行哪一个由随机采样决定，用户控制不了**。

发现了什么？论文先证明（Theorem 1）：在理想确定性 ODE 传输下，源空间的高斯噪声已经被自动分成若干「noise zone」，每个 zone 的概率质量恰好等于对应行为模式的概率质量。也就是说，**源空间本来就藏着模式结构**，只是实践中被误差糊掉了。

对 VLA 研究者意味着什么？模式选择不必进网络。把 mode label 只用来挑「从哪个源分布采样」，速度场保持单份共享——这既避开了语言条件在视觉捷径下失效的问题，也天然兼容一步去噪这类不支持 guidance 的采样器。

## 1. 核心架构/方法总览 (Overview / Architecture)

### 1.1 系统对比概览 (System Component Comparison)

### 1.2 关键机制 (Key Mechanism)

要点式解释「为什么这样设计」：

- **模式信息的位置很关键**。论文把已有方案分两类：一类把 mode（通常实现为语言指令）注入生成模型条件；另一类隐式学习一组高斯先验。前者在数据不均衡时不可靠——论文引用 Fang et al. 2026 / Ren et al. 2026 的说法：高维视觉场景与任务执行强相关，模型容易学到「场景—动作」捷径，绕过低维语言条件。后者的先验没有与行为模式的显式语义对应，对齐仍需额外网络和后处理。
- **不恢复隐式分区，而是显式强加一个简单几何**。§3 证明源空间本来就有 mode 分区；MOSS 不去「学回」这个分区，而是直接给每个 mode 分配一个语义对齐的高斯源，需要分离时就把它们推开。
- **分离度随状态变化**。多模态只在任务某些关键阶段出现（论文引用 Jia et al. 2026a 的 MARS 观点）：接近分支点时多个模式共存，模式一旦选定后行为又趋同。因此 MOSS 估计局部多模态强度 q：q 大时源组件远离、重叠小；q 小时组件收缩回共享高斯，最大化数据共享。
- **mode label 不暴露给速度场**。好处有两个（作者主张）：避免条件注入导致的捷径解；相比推理时强 guidance 改变学到的向量场，mode-specific 源是「从训练时已确立的区域出发」，可能减少 guidance 造成的轨迹质量退化，并天然兼容一步去噪这类不支持 guidance 的方法。
- **样本效率的第二重来源**。共享速度场让少数 mode 可以复用多数 mode 学到的共同运动结构，同时保留清晰 mode 边界（§5.3 的 10:90 实验）。

⚡ **Eureka Moment**：**理想 FM 的确定性传输已经把「行为模式」编码成了源空间的分区；所以控制模式不需要改网络、不需要条件注入，只需要控制「从哪里开始传输」。**

## 2. 数学核心 (Math Core)

📌 **Napkin Formula**（一行抓住本质）：

```
选哪个 mode  =  从哪个源分布采样：  p(x_0 | k, q)  —  k 不进 v_θ
```

先给目标，再给公式，再给变量说明，最后给直觉。

**目标**：让「模式选择」成为生成起点的显式函数，同时保持单个共享速度场。

**A. 论文的理论起点（论文实测 + 作者主张）**

论文 §3 的概率路径与 FM 损失（论文 (1)、(5)）：

```
x_t = t·y + σ_t·z,   σ_t = 1 − (1 − σ_min)t,   σ_min ≥ 0
本文实现取 σ_min = 0：x_t = (1 − t)·x_0 + t·y
L_FM = E[ || v_θ(x_t, t, o) − (y − x_0) ||²_2 ]
```

**Theorem 1（Noise zoning，论文 (2)）**：若 Φ_o 连续且满足精确传输条件 (Φ_o)_# μ_0 = p_1^o，则

```
Z_k^o = Φ_o^{-1}(A_k^o)  （mode k 的源空间原像）
μ_0(Z_k^o) = p_1^o(A_k^o),    μ_0(B_Z^o) = 0
```

其中 {A_k^o} 是动作空间按语义边界 B_A^o 分出的两两不交开区域，B_Z^o = Φ_o^{-1}(B_A^o)。**直觉**：高斯源已经被行为模式切开了，每个 zone 的噪声质量恰好等于该模式的动作概率质量——分区不是设计出来的，是确定性传输的推论。

**Theorem 2（Margin-induced source separation，论文 (3)、(4)）**：在 bi-Lipschitz 条件下

```
e^{−Λ_o}·||z − z'||₂ ≤ ||Φ_o(z) − Φ_o(z')||₂ ≤ e^{Λ_o}·||z − z'||₂

Λ_o = ∫_0^1 L_t^o dt,   L_t^o = sup_x ||∇_x v_t^o(x)||_op

γ_o(z) = dist(Φ_o(z), B_A^o)          （端点语义 margin）
R_o(z) = e^{−Λ_o}·γ_o(z)               （源空间半径）
B(z, R_o(z)) ⊆ Z_k^o
||z − z'||₂ ≥ R_o(z) + R_o(z')         对 z ∈ Z_k^o, z' ∈ Z_j^o, k ≠ j
```

**直觉**：离语义边界越远的行为，在源空间里拥有的「同模式邻域」越大；不同模式在源空间里至少隔开两个半径之和。

当 σ_min > 0 时论文给出可验证的有限界（论文 (28)、(29)，取 σ_* = min{1, σ_min}）：

```
L_t^o ≤ |σ_min − 1|/σ_* + t·C_Σ,o/σ_*³
Λ_o   ≤ |σ_min − 1|/σ_* + C_Σ,o/(2σ_*³) < ∞
C_Σ,o = sup_{t,x} ||Cov[y | x_t = x, o]||_op
```

即**后验协方差有界 + ODE 全局适定**足以保证上述全局空间正则性。σ_min = 0 时论文不假设全局界，改在紧集 K 上给出局部版本（Appendix B.4），要求沿相关轨迹的 Jacobian 可积。

**B. 实践误差如何破坏分区（论文 §3.2）**

```
η_o(z) = ||Φ̃_o(z) − Φ_o(z)||₂          （端点传输误差）

Proposition 3: η_o(z) < γ_o(z)  ⇒  h_o(Φ̃_o(z)) = h_o(Φ_o(z))
Corollary 4:  γ_o(z) = O(η_o(z)) 的源点构成 boundary-sensitive region
              （误差界 ε 增大时，不保证模式保持的源点集合 S_ε 单调扩大）
```

**直觉**：有限演示、模式不均衡、网络有界 Lipschitz 常数、有限步积分都会推高 η_o，于是边界敏感区变宽，表现为模式交叉、模式偏好甚至局部模式坍缩。**理想分区存在 ≠ 实践中能学到清晰可用的分区**——这就是 MOSS 要显式强加几何的动机。

**C. MOSS 的源整形（论文 §4.2、§4.3）**

多模态监督信号（论文 (6)）：

```
r_i = Var_{B,i} / (Var_{B,i} + β·Var_{W,i} + δ)
```

其中 Var_{B,i} 是邻域内**跨模式**未来动作变化，Var_{W,i} 是**模式内**变化，β > 0 控制模式内变化的相对权重，δ > 0 为数值稳定项。估计器（论文 (7)）：

```
w = s_φ(o_{≤t}, a_{<t})        （标量 sigmoid 输出）
```

论文 Appendix C.2 给出 Var 的具体加权实现：邻域权重 α_ij = softmax(−d_ij/τ)，τ = 1；检索距离 d_ij 由观测距离和已执行动作距离各自除以其 median 后加权，λ_h = 1；p_ik = Σ α_ij，ȳ_ik 为模式内加权均值。

源分布（论文 (8)–(12)）：

```
ã_k = ā_k − (1/K)·Σ_j ā_j                       （去掉跨模式共享分量）
c_k(q) = α(q)·ã_k                                （模式 k 的源中心）
p(x_0 | k, q) = N( c_k(q), σ∥²(q)·UUᵀ + σ⊥²·(I − UUᵀ) )
Δ(q) = min_{i≠j} ||c_i(q) − c_j(q)||₂            （最小跨模式中心距）
σ∥(q) = clip( Δ(q)/(2ρ(q)), σ∥,min, σ∥,max )
```

调度（论文 (64)–(66)，超参见 Table 6）：

```
g(q) = [ clip( (q − q_floor)/(1 − q_floor), 0, 1 ) ]^γ
α(q) = α_min + (α_max − α_min)·g(q)
ρ(q) = ρ_min + (ρ_max − ρ_min)·g(q)

α_min = 0.0, α_max = 1.0, ρ_min = 1.25, ρ_max = 2.5
σ⊥ = 1.0, σ∥,min = 0.25, σ∥,max = 1.0, γ = 0.5
```

时间持续性（论文 (63)）：

```
q_t^eff = max( q_t, q_floor, λ_q · q_{t-1}^eff ),  q_floor = 0.05, λ_q = 0.75
```

校准（论文 (61)、(62)）：

```
q(w) = 0                                     若 w ≤ ε_w
q(w) = min( F̂_+(w)/η, 1 )                    若 w > ε_w
ε_w = 10^{−3},  η = 0.95
```

> 符号与本文保持一致：o 为观测（历史窗口），a 为已执行动作，y 为未来动作块（action chunk），k 为模式标签，q 为校准后的多模态强度，U 为模式判别子空间的正交基，d_s ≤ K−1 为其维度。

**直觉总结**：q 同时控制「中心推多远」（α）和「目标分离比多大」（ρ）。q→1 时中心远离、σ∥ 由 Δ/(2ρ) 决定；q→0 时所有 c_k 重合，退化为同一个源（K=2 时是沿一维模式轴对称的双高斯，退化为共享高斯）。

## 3. 带数字走一遍：玩具例子 (Worked Example)

> ⚠️ 以下数值**全部是我为演示公式而假设的**，不是论文实验数据。论文没有给出这些具体数值。

**假设设定**：归一化动作空间，K = 2，模式判别子空间维度 d_s = 1。假设 branch-critical 区域内两个模式的经验平均未来动作块经中心化后得到 ã_1 = +3.0、ã_2 = −3.0（于是 Δ 的尺度系数为 6.0）。用 Table 6 的超参：α_min = 0, α_max = 1, ρ_min = 1.25, ρ_max = 2.5, σ⊥ = 1.0, σ∥,min = 0.25, σ∥,max = 1.0, γ = 0.5, q_floor = 0.05。

**三个 q 取值下的源几何（按论文公式验算）**

| q | g(q) | α(q) | c_1 / c_2 | Δ(q) | ρ(q) | Δ/(2ρ) | σ∥(q)（clip 后） |
|---|------|------|-----------|------|------|--------|------------------|
| 0.05 | 0 | 0 | 0 / 0 | 0 | 1.25 | 0 | 0.25（触发下界） |
| 0.50 | 0.6882 | 0.6882 | +2.065 / −2.065 | 4.129 | 2.1103 | 0.978 | 0.978 |
| 1.00 | 1 | 1.0 | +3.0 / −3.0 | 6.0 | 2.5 | 1.2 | 1.0（触发上界） |

逐步验算（以 q = 0.50 为例）：

```
g = [ (0.50 − 0.05)/(1 − 0.05) ]^0.5 = [0.45/0.95]^0.5 = 0.4737^0.5 ≈ 0.6882
α = 0 + (1.0 − 0)·0.6882 = 0.6882
c_1 = 0.6882 × 3.0 = 2.065,  c_2 = −2.065
Δ = ||2.065 − (−2.065)||₂ = 4.129
ρ = 1.25 + (2.5 − 1.25)×0.6882 = 1.25 + 0.8603 = 2.1103
σ∥ = clip(4.129 / (2×2.1103), 0.25, 1.0) = clip(0.978, 0.25, 1.0) = 0.978
```

**从几何到「模式误判」的量级估算（我的一维独立高斯近似，非论文实验）**：若只看 Δ 这条轴，两个等权高斯中心距 Δ、标准差 σ∥，理想贝叶斯判别点在中心处，误判概率约为 2(1 − Φ(Δ/(2σ∥)))。用上表：q = 1 时 Δ/(2σ∥) = 3.0，误判率 ≈ 2(1 − Φ(3)) ≈ 2×0.00135 = 0.27%；q = 0.5 时 Δ/(2σ∥) = 2.11，误判率 ≈ 2(1 − Φ(2.11)) ≈ 3.5%；q = 0.05 时两个组件完全重合，该轴上不可区分。**这说明同一个机制在低 q 时主动放弃区分（换数据共享），在高 q 时把区分推到很干净的水平。**

**用 Theorem 2 / Proposition 3 再走一遍误差链（同样是假设数值）**：设 Λ_o = 0.2，某源点 z 满足 Φ_o(z) 到语义边界距离 γ_o(z) = 0.1，则 R_o(z) = e^{−0.2}×0.1 ≈ 0.0819，即半径 0.0819 的开球内所有源点在理想传输下都留在同一模式；但若实际传输误差 η_o(z) = 0.05 < 0.1，Proposition 3 仍保证模式不变；若 η_o(z) = 0.12 > 0.1，保证失效，进入 Corollary 4 的 boundary-sensitive region。这解释了论文的核心叙事：**η 增大 → 保证失效区变宽 → 源空间分区变糊。**

**真实评测数据的一致性验算（我的计算）**：论文摘要称真实世界平均 GR/SR 为 84.2%/85.3%，超过 Mode-conditioned FM 43.3 / 12.0 个百分点。用 Table 2 逐项验算：MOSS 六个 GR 值 0.95、1.00、0.80、0.65、0.90、0.75 的均值 = 5.05/6 = 84.17%；三个 SR 0.98、0.75、0.83 的均值 = 2.56/3 = 85.33%；Mode-conditioned FM 六个 GR 均值 = 2.45/6 = 40.83%，差值 43.33 个百分点；三个 SR 均值 = 2.20/3 = 73.33%，差值 12.0 个百分点。**与摘要自洽。**

## 4. 工程视角 (Engineering View)

**推理开销与步数**

- FM 积分固定 10 步（Table 8），每次 policy query 执行最多 8 个动作切片，真实机器人 15 Hz 闭环。因此一次 10 步积分要覆盖约 8/15 ≈ 0.53 s 的执行时间——单次生成的延迟预算必须落在这一量级内，否则会欠采样。
- MOSS 本身**不增加采样步数**：它只改 x_0 的采样分布，速度场形状和积分器不变。这是相比推理时 guidance 的工程优势（论文主张）：guidance 通常要求额外的无条件前向（CFG 形式），而 mode-specific 源是一个 O(d) 的高斯采样。
- 额外模块只有一个 2 层 MLP（隐藏 256）、一次 LayerNorm，以及一个 O(K·d) 的中心计算。估计器输入是 8 步观测 + 8 步动作，特征侧有一个 512 维冻结 ResNet-18 特征 + 本体状态、投影到 128 维（Appendix C.2）。

**内存与方差**

- 源协方差在模式轴上与正交方向不同（σ∥² 与 σ⊥²），实现上不需要显式构造 d×d 矩阵就可以采样：先按 U 投影或等价地用 ã_k 构造低秩结构再叠加 σ⊥ 的白噪声。d_s ≤ K−1，K=2 时 d_s = 1，接近零额外成本。
- σ∥ 的上下界 clip（0.25 / 1.0）与动作数值尺度耦合。**我的条件性分析**：如果 ã_k 的范数太小，σ∥ 会长期贴在 0.25 下界，此时源在模式轴上被压缩得比标准高斯更窄；如果太大，会贴到 1.0 上界。论文用同一套源整形超参跑所有任务（Table 6），说明作者依赖归一化动作空间让 Δ 落在合理量程内——迁移到新机器人时，这一量程需要重新标定。

**校准与部署约束**

- 校准只用训练集、拟合后固定（Appendix C.3），因此部署时没有在线统计漂移问题；代价是训练分布之外的状态，q 的外推行为没有理论保证。
- 时间持续性 λ_q = 0.75、q_floor = 0.05 是「最近检测到的多模态状态不会立即丢失源分离」的工程护栏；它同时意味着**模式分离在分支点过后仍会残留若干 query**，对高频控制是平滑，对快速切换模式则是滞后。
- 真实部署需要人工或高层规划器给出 k。GR 的定义（Appendix E.5）要求 rollout 既成功又实现请求的语义模式，因此 GR ≤ SR——这是一个比 SR 更严格的指标，不能把 SR 当 GR 读。

| 项目 | 单位与次数 |

| 仿真 | 每个明确请求的 mode **50 rollouts** |

指标定义：

```
SR = (1/N)·Σ_i S_i,                S_i ∈ {0,1} 表示 rollout i 是否完成任务
GR_k = (1/N_k)·Σ_i I[ S_i = 1 ∧ M_i = k ]     请求模式 k 时，成功且模式正确的比例
⇒ GR_k ≤ SR_k
```

**关键实测数字（区分来源）**

- 仿真 Table 1（GR / SR）：MOSS 在 Push Cube 为 0.99/0.99（Mode 1）与 1.00/1.00（Mode 2）；Grasp Eyeglasses 两个模式均 1.00/1.00；Stack Cube 0.98/0.98 与 0.96/0.96；Put Wine 0.92/0.94 与 0.86/0.94。Mode-conditioned FM 在 Grasp Eyeglasses 也是 1.00/1.00，但在 Stack Cube 为 0.96/0.96 与 0.94/0.94。GMM-Sourced FM 出现明显任务相关失配：Grasp Eyeglasses Mode 2 为 0.42/1.00，Stack Cube 为 0.58/1.00 与 0.56/1.00。
- 真实 Table 2：Place Cups MOSS 0.98 SR、GR1 0.95、GR2 1.00，Mode-conditioned FM 为 0.70 SR、GR1 0.15、GR2 0.85；Pick Veg MOSS 0.75 SR、0.80/0.65，Mode-conditioned FM 0.65 SR、0.00/0.60；Open Drawer MOSS 0.83 SR、0.90/0.75，Mode-conditioned FM 0.85 SR、0.85/0.00。
- 消融 Table 3（GR1 / GR2）：single Gaussian 为 0.50/0.68（Push Cube）、0.76/0.80（Grasp）、0.58/0.70（Stack）；single-step separation 为 0.64/0.62、0.66/0.72、0.54/0.68；w/o adaptive 为 0.86/0.85、0.86/0.90、0.78/0.88；MOSS 为 0.99/1.00、1.00/1.00、0.98/0.96。摘要据此称自适应源几何比固定高斯分离在相同训练预算下平均 GR 高 **12–14 个百分点**。
- 训练曲线（Appendix H.2）：epoch 100 时自适应 MOSS 的双模式平均 GR 为 0.96 / 0.99 / 0.98（Push Cube / Grasp / Stack），固定整形为 0.90 / 0.88 / 0.85。
- 离线源对齐与传输统计（Table 10）：自适应在三个任务上均降低 D_μ 与 D_tr，且模式判别方向的分量 D∥ 下降更明显（例如 Push Cube 从 2.767 降到 0.931）。论文解释：MOSS 主要沿模式判别方向改源，正交方向的大分量由两个变体共享。

**诊断实验（Appendix A，论文实测）**：2D Navigation 四个可行路线，用标准高斯源跑 1000 次闭环，记录首个执行 chunk 的 8 维初始噪声（只保留 y 维）。成功定义是终点距 (1.8, 0.5) 不超过 0.06；模式按穿墙区 x ∈ [0.78, 0.85] 的平均垂直坐标分档（y < 0.22 / 0.22–0.50 / 0.50–0.78 / ≥ 0.78）。排除失败后剩 939 条轨迹，四模式样本数 188 / 242 / 267 / 242。四模式的初始噪声均值 y 分量为 −0.303 / −0.182 / 0.135 / 0.286，**随路线垂直位置单调递增**。用每个模式的初始噪声均值做中心、保持 σ = 1 采样，每源 100 rollouts，对应模式命中率仅 62% / 29% / 34% / 56%（Table 4）——论文据此论证：自然涌现的分区有语义结构，但远不足以可靠控制。

## 6. 能力与失败模式 (Capabilities & Failure Modes)

**能做（论文实测支持）**

- 在同一观测下，按请求的语义模式生成动作，并在仿真达到最高 100% 的目标模式转向（摘要；Table 1 中 Grasp Eyeglasses 两个模式均为 1.00/1.00）。
- 在 10:90 强不均衡演示下恢复少数模式，论文称少数模式引导率超过 90%（摘要），并在 Figure 7 中显示 MOSS 用更少的少数模式训练窗口暴露量达到高 GR；作者据此主张共享速度场能复用多数模式的运动结构。
- 支持 K > 2 的多模式（2D Navigation、Place Cube，Figure 6）。
- 真实世界三个任务上保持可控性（Table 2），并在 Place Cups 与 Open Drawer 上避免了 Mode-conditioned FM 出现的单侧模式坍缩（GR 从 0.15/0.00 提升到 0.95/0.75 这类对比）。

**不能做 / 明确失败模式**

- **固定离散模式集合**：作者在 Limitations 明确说，当前形式假设训练前指定一组离散行为模式，不直接支持开放式模式控制或连续行为变化。
- **大规模策略未验证**：作者明确说，虽然源空间形式原则上兼容更大的生成式机器人策略，但在该类设置下的性能仍待评估。
- **模式标签必须在部署时给定**：MOSS 不做模式发现，也不从观测推断「用户想要哪个模式」；k 由用户或高层规划器提供。
- **CFG 不能稳定救回条件注入**（Appendix F，Mode-conditioned FM 的对照）：把 s_CFG 从 1 提到 3，Place Cups Mode 1 的 GR 从 0.15 升到 0.65（SR 0.55→0.70），但 Pick Veg Mode 1 GR 只到 0.20 且 SR 从 0.60 降到 0.45；Open Drawer Mode 2 GR 只到 0.25 且 SR 从 0.85 降到 0.75。论文结论：推理时放大模式条件不能可靠解决不对称的模式坍缩。（注意这是对照方法的结果，不是 MOSS 自己的失败模式，但它说明「用 guidance 打补丁」这条路线有边界。）
- **GR ≤ SR 的定义带来的读数限制**：GR 把「成功」和「模式正确」绑定，所以当任务本身成功率不高时（例如 Pick Veg MOSS SR 0.75、GR2 0.65），不能把 GR 与 SR 混为一谈。

### 6.1 隐含假设 (Hidden Assumptions)

作者默认成立、但论文未直接验证的前提：

1. **语义模式可以被预先、稳定地离散标注**。论文的 mode 标签是「按行为选择逐 episode 指派」（Appendix E.4），在 Open Drawer 中还丢弃了 1 个异常 episode。对连续/混合行为，这个前提不成立（作者也在 Limitations 承认）。
2. **模式判别子空间是静态的**。U 与 ã_k 由训练集一次算出后固定（Appendix D.1）。它假设「哪些方向区分模式」不随任务进度变化；而 q 随时间变化的机制只调节分离强度，不调节方向。**我的条件性分析**：如果不同阶段的分支方向不同（例如先选左右、后选上下），单一 U 可能无法覆盖。
3. **模式在观测上可被同一套视觉编码器捕捉**。估计器用的是冻结 ResNet-18 特征（Appendix C.2），论文未做编码器消融。
4. **q 的校准分布与部署分布一致**。校准只用训练集百分位（Appendix C.3），没有报告分布外状态的 q 行为。
5. **共享速度场不会在两个模式间产生负迁移**。论文报告了正向的样本效率证据（Figure 7），但没有给出「模式差异极大时是否仍共享得动」的边界实验。

## 7. 与相关工作对比 (Comparison)

| 方法 | 模式信息进入位置 | 是否修改速度场 | 源分布 | 训练数据要求 | 适用场景（论文口径） |
|------|------------------|----------------|--------|--------------|----------------------|
| FM-DiT / DDPM-DiT（论文基线） | 无 | 否 | 标准各向同性高斯 | 全量演示 | 不需要模式选择 |
| ACT / BET（论文基线） | 无（BET 用离散 latent 克隆 k 个模式） | 否 | — | 全量演示 | 常规行为克隆 |
| A2A（Jia et al. 2026b） | 无 | 否 | 动作历史表示（缩短传输、支持一步） | 全量演示 | 高效传输，不面向模式控制 |
| MARS Policy（Jia et al. 2026a） | 无（按多模态度自适应切换随机/确定） | 是（生成方式切换） | 标准高斯 | 全量演示 | 多模态建模但不可主动控制 |
| Mode-conditioned FM（Lei et al. 2026 形式） | 速度场条件（mode label 嵌入） | 是 | 标准高斯 | 需 mode label | 显式条件；论文实测在真实任务上不对称坍缩 |
| GMM-Sourced FM（Luo et al. 2026；Zhang et al. 2026） | 无显式语义，数据驱动 | 否 | 学得的高斯混合 | 需拟合 GMM | 源空间对齐，但语义对应弱 |
| SL-FM（Zhang et al. 2026） | 通过正交源抬升分离分支 | 否（共享速度场） | 抬升后的源 | 需分支监督 | 可干预多模态模仿 |
| **MOSS（本文）** | **源分布选择（k 不进 v_θ）** | **否（单份共享速度场）** | **语义对齐的 mode-specific 高斯，随 q 自适应** | **需 mode label + 离线估计器与统计** | **需要明确模式可控性的操作任务** |

论文相对基线的核心差异：与 Mode-conditioned FM 共用同一视觉编码器、速度场架构、动作 horizon、优化器和评测协议，只改变「模式信息进入的位置」（Appendix E.2），从而把性能差异归因到源分布 vs 条件注入。

**面试 Tip（一句话）**：被问到「MOSS 和 mode-conditioned flow matching 有什么本质区别」时，答——**条件注入是让网络在生成过程中改变流向；MOSS 是让生成从训练时已经确立的不同区域出发，速度场完全不变**；论文的实测证据是真实任务上后者在模式可控性上更均衡（例如 Place Cups GR1 0.15 → 0.95、Pick Veg GR1 0.00 → 0.80），代价是必须预先知道模式集合。

## 8. 精读建议 (Reading Guide)

**值得精读原文的人**

- 做**多模态机器人策略**的研究者：§3 的 Theorem 1/2 和 Appendix B 的证明给出了「源空间分区」的完整论证，可以判断这套几何论证是否可迁移到自己的生成式策略。
- 需要**测试时行为指定**（人类干预、高层规划器、偏好约束）的工程师：§4.2–§4.3 的估计器与源整形是可直接落地的模块，Appendix C/D 给出了完整超参。
- 研究**数据不均衡下少数模式学习**的人：§5.3 与 Appendix G 的实验设计（10:90、按累计少数模式窗口数为横轴、3 seeds）值得作为对照协议参考。

**建议章节路径**

- 先读 §3（尤其是 Theorem 1 与 §3.2 的误差链）→ 再看 §4.3 与 Appendix D（源整形公式与超参）→ 然后 §5.2 与 Table 2（真实任务可控性）→ 可跳 §2 Related Work 的逐条引用（除非要写综述）→ Appendix A 的诊断实验（自然源分区的实际质量）建议一读，它给「为什么需要显式整形」提供了最直接的证据。

**不值得精读的理由**

- 如果你的任务**没有离散模式语义**、不需要测试时行为指定，读摘要即可——MOSS 的价值集中在「可控模式选择」这一点上。
- 如果你已经熟悉 SL-FM / MARS / A2A 这一系列源空间方法，且不关心「自适应分离强度」这一具体机制，本文的可迁移增量主要是 Theorem 1 的分区视角与 q 调度设计。
- 如果你只关心无条件的成功率 SOTA，本文的 SR 并非在所有任务上都最高（例如 Open Drawer 上 Mode-conditioned FM 的 SR 0.85 略高于 MOSS 的 0.83），它的核心卖点是 GR 与两模式均衡性。
