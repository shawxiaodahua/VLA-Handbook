## 1. 核心架构/方法总览 (Overview / Architecture)

### 1.1 系统对比概览 (System Component Comparison)

| 模块 | 输入 | 输出 | 频率/时序 | 训练/推理差异 |
|------|------|------|-----------|---------------|
| Reset bank | 20 个装配对的 reset 状态 | 条目 (e_i, s̄_i) | 每 episode 重置时采样 | 训练时构建缓存；训练中更新的是每个条目的滚动成功率 p̂_i 和采样概率 q，而非 bank 本身；未说明推理使用固定 bank |
| Beta sampling | 每个条目的滚动成功率 p̂_i | 采样概率 q_i | 每次 reset | 训练时在线更新；推理不需要 |
| Policy πθ | 点云 + 本体感知 + 上一动作 | 8 维动作：7 关节增量 + 1 夹爪 | 25 Hz | 训练/推理同一网络；评测用 stochastic actions |
| Value Vφ | 同上 | 标量 | 每步 | 仅训练 |
| PPO | 并行 rollout | 梯度 | 每 iteration 32 步/环境，5 epochs，4 minibatches | 仅训练 |

### 1.2 关键机制 (Key Mechanism)

- **Reset bank 带装配身份**：每个条目同时存任务 e_i 和初始状态 s̄_i。采样一个条目就同时选任务和初始配置，策略不需要离散任务 ID 作为输入。
- **Beta sampling 聚焦能力前沿**：q_i 在 p̂_i 接近 0.5 时最大，把 reset 集中到“会一点但不完全会”的状态；ε_q 保证每个条目仍可被采样。
- **二值奖励统一目标**：所有任务都只奖励“完全装配”，中间进度没有奖励。控制代价只惩罚大动作、快关节运动和大扭矩，不提供装配进度信息。
- **异构任务联合训练**：20 个任务共享一个策略和一个值函数，标准 PPO，无任务特定 value head、无梯度投影、无专家预训练。
- **为什么控制代价不算 shaping**：它只正则化动作平滑性和硬件安全性，不告诉策略“离成功还有多远”。

⚡ **Eureka Moment**：把“任务多样性”从多任务学习的负担变成稀疏奖励探索的资源——共享的二值成功信号让不同装配对互相提供可复用的抓取和接触经验，而 beta 采样把算力压到能力前沿。

### 1.3 信息流/架构图 (Flow / Diagram)

```
Reset bank {(e_i, s̄_i)}
        │  beta sampling: q_i ∝ ε_q + sqrt(p̂_i(1-p̂_i))
        ▼
并行仿真环境 (1–256K, 每 GPU 4K)
        │  点云 + 本体感知 + 上一动作
        ▼
πθ (SimBa actor) ──► 8D 动作 ──► 阻抗控制器 @25 Hz
        │
        ▼
二值奖励 1[d_asm < 0.001 m] - c(||a||² + ||q̇||² + ||τ||²)
        │
        ▼
PPO 更新 πθ, Vφ；用最近 L 个 episode 更新 p̂_i
```

## 2. 数学核心 (Math Core)

📌 **Napkin Formula**：

```
q_i ∝ ε_q + sqrt(p̂_i(1 - p̂_i))
r_t = 1[d_asm(s_{t+1}) < ε] - c(||a_t||² + ||q̇_t||² + ||τ_t||²)
```

目标：有限时程 MDP，最大化

```
J(θ) = E_{ρ,p,πθ} [ Σ_{t=0}^{T-1} γ^t r_t ]
```

Reset bank：

```
D_reset = {(e_i, s̄_i)}_{i=1}^{M}
```

二值任务奖励：

```
r_t^succ = 1,  若 d_asm^e(s_{t+1}) < ε
           0,  其他
ε = 0.001 m
```

总奖励：

```
r_t = r_t^succ - c(||a_t||² + ||q̇_t||² + ||τ_t||²),  c ≥ 0
```

密集奖励消融：

```
r_t^dense = r_t + c_2 r_t^reach + c_3 r_t^align,  c_2 = c_3 = 0.01
```

| 符号 | 含义 |
|------|------|
| e | 装配任务，|E| = 20 |
| s̄_i | reset 状态，包含机器人、板、可动件状态 |
| M | reset bank 总条目数（论文未给具体值） |
| p̂_i | 条目 i 最近 L 个 episode 的经验成功率 |
| ε_q | 采样下限，论文只给 ε_q > 0，未给具体值 |
| d_asm | 当前相对位姿到完全装配位姿的距离 |
| ε | 成功阈值 0.001 m |
| c | 控制代价系数，论文未给具体值 |
| a_t | 8 维动作：7 关节增量 + 1 夹爪 |
| q̇_t, τ_t | 关节速度、关节力矩 |

直觉：beta 采样是“把训练放在当前会一点但又不完全会的状态上”；二值奖励是“只告诉终点，不告诉路线”。

## 3. 带数字走一遍：玩具例子 (Worked Example)

> 以下数值为假设，仅用于演示公式行为；论文未给 ε_q、c、L、M 的具体值。

**Beta 采样。** 假设三个 reset 条目，p̂ = [0.02, 0.5, 0.98]，ε_q = 0.01。

```
条目 1：sqrt(0.02 × 0.98) = sqrt(0.0196) = 0.14；+ 0.01 = 0.15
条目 2：sqrt(0.5 × 0.5)   = 0.5；          + 0.01 = 0.51
条目 3：sqrt(0.98 × 0.02) = 0.14；         + 0.01 = 0.15
总和 = 0.81
q = [0.15/0.81, 0.51/0.81, 0.15/0.81] ≈ [0.185, 0.630, 0.185]
```

验算：0.15 / 0.81 ≈ 0.1852，0.51 / 0.81 ≈ 0.6296。中间条目占约 63%。这说明 beta 采样会把大部分 reset 分配给成功率接近 0.5 的条目，而不是已经成功的 0.98 或几乎失败的 0.02。如果把 ε_q 调大，三个条目会更平均；ε_q 越小，采样越集中在能力前沿。

**控制代价。** 假设 c = 1e-4，7 维关节增量每个 0.1 rad：

```
||a||² = 7 × 0.1² = 0.07
关节速度每个 0.5 rad/s：||q̇||² = 7 × 0.5² = 1.75
力矩每个 5 N·m：||τ||² = 7 × 5² = 175
总代价 = 0.07 + 1.75 + 175 = 176.82
乘 c = 0.0177
```

相对成功奖励 1，约 1.8%。如果力矩每个 20 N·m，||τ||² = 2800，总代价 2801.82，乘 c = 0.28，占成功奖励的 28%。这说明控制代价在大力矩时不可忽略，但论文没有公开 c，实际数值无法复算。

## 4. 工程视角 (Engineering View)

- **控制频率**：25 Hz，每步 40 ms 预算。策略输出相对关节位置目标 q_target = q + Δq，7 维加 1 维夹爪；底层是隐式阻抗控制器，用 libfranka 刚度和阻尼，带硬件匹配的 armature 和关节摩擦。
- **硬件约束**：关节速度限制 2.175 rad/s（关节 1–4）、2.61 rad/s（关节 5–7）；力矩限制 87 N·m 和 12 N·m。这些限制用于防止策略利用不真实的速度或力矩。
- **训练规模**：64K 环境、25K 迭代，4K 环境/GPU，需要 16 GPU。每 iteration 每环境收集 32 步，5 epochs，4 minibatches。按论文参数估算，每 iteration 约 2.048M 环境步，25K iterations 约 51.2B 环境步（此数字为估算，论文未直接给出）。
- **成本**：共享策略 410 GPU-hours；20 个单独策略合计 16.1K GPU-hours，约 39.3 倍。这里比较的是训练设备时间，不含评测和 reset bank 构建。
- **推理**：论文未给推理延迟、点云点数 n_pts、reset bank 大小 M。25 Hz 下的点云编码和 SimBa 前向是否满足实时，需要实测。
- **多对装配**：15 秒/对，10 对最多 150 秒；25 Hz 下最多 3750 步。二值奖励只在全部完成时给，稀疏性随对数增加而加剧。
- **评测协议**：stochastic actions，冻结混合 reset bank，任务内均匀采样，15 秒内完成且无安全失败。训练成功率和评测成功率要分开看。

## 5. 数据与评测 (Data & Eval)

- **数据来源**：Isaac Lab 仿真，20 个 NIST ATB1 装配对。观测是机器人状态、可动件/配合几何/机器人的表面点云，没有离散任务 ID，没有示范，没有脚本基元。
- **Reset 覆盖**：未抓取 workspace、拾取、运输、近装配、部分装配。这些 reset 家族定义训练分布，不是预设序列；策略不接收 stage identifier。
- **训练**：标准 PPO，共享 actor-critic，无任务特定 value head、无梯度投影、无专家预训练。
- **并行规模评测条件**：在并行规模评测中，所有 checkpoint 用 stochastic actions；冻结混合 reset bank，任务内均匀采样；成功要求 15 秒内完全装配且无同时发生的安全失败；成功判定 d_asm < 0.001 m。
- **主要数字（论文实测）**：
  - 64K 环境、25K 迭代：共享策略 98.2% 训练成功率，410 GPU-hours；20 个单独策略平均 81.4%，16.1K GPU-hours，39.3 倍设备时间（§V-A、Fig. 6）。
  - 单独策略在 M4 nut threading、4 mm peg insertion、rod insertion 上从随机初始化状态出发成功率 ≤ 0.3%；共享策略能解决这三类任务（§V-A）。
  - 20 个单独 dense 策略最终平均 78.3%，范围 45.0%（M4 threading）到 93.6%（medium gear）；联合 dense 训练 25K 迭代仅 17.8%（§V-A、Fig. 5）。
  - Fig. 7：sparse + beta 在 1K 环境 38.6%，4K 78.9%，8K 86.9%；dense 在 1K–4K 为 11.8–12.0%。256K 环境：sparse beta 97.4%，uniform 84.3%；dense beta 77.4%，uniform 34.3%。
  - Table I 多对装配：1 对 99%，2 对 97%，3 对 95%，4 对 93%，5 对 92%，6 对 90%，7 对 89%，8 对 87%，9 对 86%，10 对 84%。

> 注意：98.2% 是训练成功率；97.4% 是 256K 环境下的评测成功率。两者不可混用。Fig. 7 的评测是 5 个 evaluation seeds，每个任务每个 seed 32 trials，覆盖 20 个装配。

## 6. 能力与失败模式 (Capabilities & Failure Modes)

**能做什么**：

- 单一策略解决 20 个 ATB1 任务，包括小零件、紧配合、螺纹拧入。
- 从宽初始位姿范围学习，包括倒置等不利条件。
- 涌现行为：为后续装配选择抓取、用板面几何重新定向、释放再抓取、 extrinsic contact、单夹爪拧螺母、把挡路零件移开、先准备一个零件再装配另一个再返回。
- 多对装配最多 10 对，无预设顺序，成功奖励只在全部完成时给。

**不能做什么/风险**：

- 全部在仿真；真机迁移未验证。作者说将用传感器观测和随机化接触/延迟模型评估真机。
- 多对最多 10 对，不是完整 20 件板；扩展到 20 件是未来工作。
- 成功判定依赖仿真中的 d_asm < 0.001 m；真实感知误差可能让这个判定不可用。
- 观测是点云加本体感知，不是语言指令；不是 VLA 模型。
- 并行规模评测用 stochastic actions（该设置不覆盖全部实验）；确定性策略表现未给。
- 关键超参 c、ε_q、L、M、n_pts 未公开具体值，复现难度高。
- 训练成本 410 GPU-hours、64K 环境、16 GPU，不是普通实验室可轻松复现的规模。
- 多对成功率随对数增加下降：1 对 99% → 10 对 84%，长时程组合误差累积明显。
- 15 秒/对的时间预算；更短节拍或动态环境未测。

### 6.1 隐含假设 (Hidden Assumptions)

- Reset bank 覆盖足够多样，且仿真中的 reset 状态在真机上可达。
- 仿真接触和摩擦模型足够真实，学到的接触策略可迁移。
- 二值成功判定在仿真中可靠；真实中部分装配可能被误判为成功或失败。
- 控制代价系数 c 对所有任务都合适；论文说固定 c，但未给值。
- 多对任务中，部件之间的遮挡和干涉可以通过重新排列解决，不存在不可恢复死锁。
- 共享策略的正迁移大于负迁移；论文在 20 个 ATB1 任务上观察到正迁移，但未覆盖其他装配板。
- Beta 采样的 p̂_i 在非平稳策略下仍然有效；用最近 L 个 episode 的滚动平均，L 未给。
- 评测的 15 秒/对足够；真实工业节拍可能更短。
