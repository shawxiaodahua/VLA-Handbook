## 1. 核心架构/方法总览 (Overview / Architecture)

### 1.1 系统对比概览 (System Component Comparison)

| 模块 | 输入 | 输出 | 更新频率 | 训练/推理差异 |
|------|------|------|----------|----------------|
| **力条件先验 (frozen prior)** | 外视 D435i + 腕视 D405 + 语言 ℓ + 本体 s_t + 腕力 w_t | 动作 chunk A_base（H=50 步，相对请求状态归一化） | 推论请求触发，模型时基 f_m=30 Hz | 示范 SFT 训练后**冻结**；在线不更新 |
| **残差 actor π_ω** | z_n = [s_n, w_n, Δw_n, b_n]（本体、腕力、腕力增量、当前选定基底动作） | bounded 残差 δ ∈ [−c_res, c_res]⁶ | 每个执行决策 n（控制器每次 dispatch） | 在线更新；初始化输出为零，故初始行为等于先验 |
| **twin critics Q_φ1, Q_φ2** | ξ_n = [z_n, b_n^g]（额外含基底夹爪指令） | Q 值（对残差提案打分） | 每个自主 minibatch | 在线更新；只吃**自主** transition |
| **人类接管 (human)** | 操作者经 SpaceMouse 给修正目标 a_n^H,acc | 提供模仿监督 δ̃_n^H（投影到残差范围） | 接管时 | 人类 transition **不进** critic 学习 |

### 1.2 关键机制 (Key Mechanism)

- **先验冻结 + 残差解耦**：不动 VLA 主干，仅学一个两层 256 单元的小残差网络。低算力、低风险、可控；actor 输出头初始化为零，故「初始自主行为 = 先验行为」，不会一开始就破坏基座。
- **执行期力反馈**：chunk 生成后、执行每个指令时，用**当下采样**的腕力 w_n 与其时间增量 Δw_n 去修正。因为视觉对被遮挡的接触界面只能给间接信息，而「视觉上相似」的姿态可能有完全不同的接触力/力矩。
- **重新锚定 (re-anchoring)**：先验输出的 chunk 是相对「请求时的状态」归一化的；执行到第 n 个决策时，先把它还原成绝对目标、再相对「当前量测状态」重新表达为 b_n，残差叠在 b_n 上——避免旧 chunk 相对过时状态的偏移。
- **跨 intervention 边界遮罩 (β_n)**：只在同一自主 segment 内的「已验证立即后继」才允许 bootstrap（β_n=1）；segment 边界处 β_n=0。人类救回来的成功，**不会**把 TD credit 回传给介入前的自主动作。这是对「成功不代表介入前动作好」这一 credit assignment 问题的直接处理。

⚡ **Eureka Moment**：**把「接触感知」与「任务回报优化」拆到两个层次——大先验负责产生力条件动作，小残差负责在执行期用即时腕力做 value-guided 的微调；且只在自主 segment 内传递 TD credit。**

## 2. 数学核心 (Math Core)

📌 **Napkin Formula**（一行抓住本质）：

```
a_n^TCP = b_n + c_res·tanh f_ω(z_n)      # 冻结先验给 b_n，小残差看腕力微调
```

**目标**：在示范训练的冻结先验之上，学一个残差策略 π_ω，使自主任务完成率最大化；监督信号同时来自人类纠正（模仿）与稀疏任务奖励（价值）。

**先验训练（力条件流匹配 SFT）**：

```
x_i^τ = (1 − τ)·A_i^exp + τ·ε_i ,   ε_i ~ N(0, I),  τ ∈ [0,1]

L_SFT = E[ || v_θ(x_i^τ, τ ; o_i^F) − (ε_i − A_i^exp) ||²_M ] + L_route
```

**力条件融合（交叉注意力）**：

```
h̃_{i,j}^τ = h_{i,j}^τ + tanh(α)·W_o·Attn( q_{i,j}^τ , Z_i^F )
Z_i^F = F_MoE( P_i , φ_w(w_i) )        # P_i = 视觉-语言特征
```

**残差与时序**：

```
j(n) = ⌈ f_m·( t_n^sel − t_{i(n)}^ref ) ⌉ ,   f_m = 30 Hz

z_n = [ s_nᵀ , w_nᵀ , Δw_nᵀ , b_nᵀ ]ᵀ
Δw_n = ( Δt_ref / ( t_n − t_{n⁻} ) )·( w_n − w_{n⁻} ) ,   Δt_ref = 0.1 s

π_ω(z_n) = c_res·tanh f_ω(z_n)          # bounded 残差
a_n^TCP = b_n + π_ω(z_n)
c_res = min{ c_norm , min_j ( d_j^max / σ_j ) }
```

**TD 目标与 critic 损失**：

```
y_n = r_n + γ·β_n·Q̄_min( ξ_{n+1}, π_ω̄(z_{n+1}) )
      # segment 边界处 β_n=0 ⇒ y_n = r_n（不评估后继）

L_Q = ½ · Σ_{k=1}^{2} E_{B_TD}[ ( Q_φk(ξ_n, δ_n^prop) − y_n )² ]
```

**actor 目标（价值 + 模仿 + 正则）**：

```
L_π = λ_Q·L_V + λ_H·L_H + λ_R·L_R

L_V = − E_{R_pol^Q}[ Q_min( ξ_n , π_ω(z_n) ) ]
L_H = (1/6)·E_{R_human}[ || π_ω(z_n) − δ̃_n^H ||² ]      # δ̃_n^H = Π_C(δ_n^H)
L_R = (1/6)·E_{R_reg}[ || π_ω(z_n) ||² ]
```

**变量说明**：

| 符号 | 含义 |
|------|------|
| b_n | 当前量测状态下重新表达的基底 TCP 目标（六个姿态坐标，经 P_TCP 选取） |
| z_n | 残差 actor 的观测（本体 + 腕力 + 腕力增量 + 基底动作） |
| ξ_n | critic 观测 = z_n 再附上基底夹爪指令 b_n^g |
| Δw_n | 时间归一化的腕力增量（不同反馈间隔下对齐到 Δt_ref=0.1 s） |
| β_n | bootstrap 遮罩：同 segment 内已验证后继为 1，segment 边界为 0 |
| c_res | 残差上界（保证修正不越界成一个全新动作） |

**直觉**：先验负责「大方向、力条件」，残差负责「临门一脚的接触微调」；γ/β_n 让信用只在自己动手的 segment 内累积，不让「人类救场」污染自主动作的价值估计。相比 ConRFT/RECAP 在全模型层面做在线 RL，这里把在线学习的自由度压缩到一个小残差上，样本效率与安全性更好。

## 3. 带数字走一遍：玩具例子 (Worked Example)

用插销（plug insertion）走一个简化闭环（数值为示意，非论文原文）：

1. **先验**：模型回传 chunk H=50 步，相对「请求状态」归一化。设 f_m=30 Hz，选定 slot j(n)=⌈30·(t_n^sel − t_i^ref)⌉。若 t_n^sel − t_i^ref = 0.10 s，则 j(n)=3。
2. **重锚定**：把第 3 步的相对动作还原成绝对目标，再相对「此刻量测状态」表达为 b_n（设 delta 为 0.0003 m, 0, 0 的位置偏移）。
3. **残差**：设 z_n 含 w_n=[2.1 N, −0.3 N, 4.0 N, 0.02, 0.01, 0.05]（六维力/力矩）、Δw_n 由 (0.1/(t_n−t_{n⁻}))·(w_n−w_{n⁻}) 求得。若 f_ω 输出 0.12，c_res=0.02（示意），则 δ = 0.02·tanh(0.12) ≈ 0.0024；叠加后 TCP 目标沿某轴再推 0.0024（归一化单位）。
4. **执行与记录**：控制器可能再处理后接受；记录残差提案 δ_n^prop。夹爪在自主执行时跟随基底指令。
5. **学习**：本次若为自主、且后继已验证，β_n=1，TD 目标 y_n = r_n + γ·Q̄_min(ξ_{n+1}, π_ω̄(z_{n+1}))；若在 segment 边界（如发生接管），β_n=0，y_n = r_n（成功终端奖励 r=1，其余 0）。critic 用 y_n 做回归，actor 用 −Q_min 做价值提升，同时用 δ̃_n^H 做模仿。

**可计算闭环**：决策次数、chunk 派发预算（M=8, L=7）、critic 更新量 ⌊N_TD/8⌋ 全都是可数的——这篇的「在线」不是无限循环，而是有明确允许量的。

## 4. 工程视角 (Engineering View)

| 面向 | 设计 | 工程含义 |
|------|------|----------|
| 算力 | 只更新 actor + twin critics（各两层 256 单元 SiLU） | 部署端可跑；先验前向是主要延迟来源 |
| 控制时序 | f_m=30 Hz；chunk H=50；每 chunk 允许 M=8 次 dispatch，剩 ≤L=7 且无 pending 时异步请求新 chunk | 异步重规划允许「新 chunk 在旧 chunk 预算耗尽前就替换」，降低 replan 抖动 |
| 反馈频率 | 腕力在**每次执行决策**采样，非只随 chunk | 接触变化可在 chunk 内被响应，突破「chunk 是离散块」的响应瓶颈 |
| 时间归一化 | Δw_n 依实际间隔缩放至 Δt_ref=0.1 s | 让不等间隔的腕力样本可用同一网络处理 |
| 边界处理 | 接管作废当前 chunk 与待处理请求；放开时以新观测重新推论 | 避免跨接管的 stale action |
| 记忆/数据 | replay R_pol 仅收 admitted 且 record/execution 验证 + 人机结果一致的自主 transition | 记录量大但可控；避免污染数据 |
| 训练预算 | 30 分钟数据采集+训练/任务；≥1000 条 unique TD transition（来自 ≥3 episodes）才开 critic；一次性 256 步 critic-only warm-up | 部署后调适成本明确、可预算 |

> 落地约束：需要腕部六维 F/T 传感器 + 人类接管界面（SpaceMouse）+ 一个已示范训练好的力条件先验。缺任一环，流程不成立。

## 5. 数据与评测 (Data & Eval)

- **平台**：Franka Research 3 + Robotiq 2F-85 夹爪 + OnRobot HEX-E 腕部 F/T 传感器 + 外视 D435i + 腕视 D405；人类纠正用 SpaceMouse Compact（§V-A）。
- **任务**：插销插入、环上柱装配、白板擦拭（三项真机接触密集任务）。
- **示范**：每个任务 **50 条示范**，所有方法共用。
- **评测协议**：每设定 **30 次自主 rollout**，固定策略参数与初始化；成功需在 60 s（插销/装配）或 180 s（擦拭）内完成，且无人工介入、无 trial 内重置、无保护停机。
- **在线预算**：每个在线变体 **30 分钟**数据采集 + 训练，相同接管准则。
- **主要结果（Table I，成功/30）**：

| 任务 | 残差模仿 | ForceRFT | 变化 |
|------|---------|----------|------|
| 插销插入 | 19/30 | **25/30** | +6 |
| 环上柱装配 | 22/30 | **27/30** | +5 |
| 白板擦拭 | 8/30 | **11/30** | +3 |

（论文正文另述 ForceRFT 插销 5 次失败全为 timeout；装配 3 次失败为 2 timeout + 1 次环从夹爪中因接触导致姿态大变而掉落。）

- **腕力消融（Table II，插销）**：全模型 25/30；去掉 w_n 与 Δw_n 两者 → 19/30；只去掉 Δw_n → 23/30。作者解读：先验的力条件**不能替代**执行期的直接力反馈；当下腕力保留了大部分收益，显式腕力动态（Δw_n）证据较弱。
- **解读要点**：从 25→19（去掉力反馈）的落差大于 25→23（去掉力增量），说明「有无执行期腕力」比「是否显式建模腕力变化率」更关键。擦拭（8→11）说明收益与任务对「接触感知的依赖度」正相关：擦拭主要难在高层进度/终止判断，而非局部接触——这恰好是本文方法覆盖不到的部分。所有结果均为固定策略参数的 checkpoint 评价，无跨任务迁移测试。

## 6. 能力与失败模式 (Capabilities & Failure Modes)

**能做**：
- 在示范先验失败后（首次插入/装配失败）产生渐进式接触修正，提升自主完成率。
- 用自主任务结果做 value-guided 精修，优于纯粹模仿人类纠正（消融 λ_Q=0 的残差模仿全面落后）。
- 响应「视觉相似但接触力不同」的场景（透过执行期腕力）。

**不能做 / 失败模式**（论文自陈 + 观察）：
- **擦拭任务增益弱**：8/30→11/30；单趟常留痕需重复清洁、且「清完后仍继续擦」与「擦不干净」跨方法普遍存在 → 高层终止/进度判断未被解决。
- **姿态干扰导致的物体滑落**：装配中 1 次因接触引起环在夹爪内姿态大变化而掉落 → 残差只动 TCP，不处理**夹持内部状态**的重估。
- **timeout 主导**：插销 5 败全为超时 → 修正可能过于保守（bounded 残差 c_res 限制）。
- **未验证的泛化**：所有实验仅单一 Franka + 三任务，作者未声称对移动/双臂/人形或新任务域有效。

### 6.1 隐含假设 (Hidden Assumptions)

- 假设「固定示范统计」归一化（状态、腕力）足以覆盖部署分布 — 若部署工况漂移，归一化统计可能失准。
- 假设腕部 F/T 传感器量测的 wrench 在 TCP 处可靠，且场景中的接触可完全由腕部 wrench 表征（忽略非刚性/多点接触）。
- 假设「冻结先验 + 小残差」的表达力足以涵盖所需修正 — 若成功需要改变动作**语义**（而非局部微调），bounded 残差可能不够。
- 假设 controller acceptance 与环境动态可被视为环境的一部分、且 replay 中的自主 transition 可代表控制器的处理效果。
- 假设稀疏终端奖励（成功=1，其余=0）+ frozen reward detector 与人工标注一致即可支撑价值学习。
- 假设「自主 segment 内」的 TD credit 传递足以建模长期回报——跨 segment 的长期信用被显式截断，多阶段任务可能因此学不到全局策略。

|------|--------|------|----------|----------|
| SmolVLA-SFT | 纯示范 VLA（无力） | SmolVLA | 示范 SFT | 通用，非接触密集 |
| Force Prior（本文内部） | 力条件动作生成 | SmolVLA + ForceVLA 融合 | 示范 SFT，冻结 | 接触密集但无在线学习 |
| 残差模仿（本文内部） | 模仿人类纠正 | 冻结先验 + 残差 | 人类模仿（λ_Q=0） | 有纠正资料、无任务回报 |
| ConRFT / RECAP | VLA 在线 RL | Q 引导一致性 / 优势条件生成 | 在线 RL（全模型层面） | 通用在线微调 |
| ResiP / Policy Decorator / ResFiT | 残差式适配 | 在既有策略上学残差 | 残差 RL | 精细操作/适配 |
| TORL-VLA / Facet-0 | 力/触觉引导在线 RL | 力/触觉 cue + RL | 在线 RL，含边界处理 | 接触密集 |
| **ForceRFT（本文）** | 执行期腕力 + 价值引导残差 | 冻结力条件先验 + 残差 actor + twin critic | 人类模仿 + 自主 TD（β 遮罩） | 接触密集、部署后精调 |

差异点：ForceRFT 把「力反馈 → 动作修正 → 其价值」的学习集中在一个小残差上，且**不需预测未来 wrench**（区别于部分时序方法与 Facet-0）。与 ConRFT/RECAP 相比，它不碰生成模型本体，只在执行指令层做在线 RL。

🎯 **面试 Tip**：被问到这篇时，一句话答——「**冻结力条件 VLA 先验产生动作 chunk，执行期用腕部 wrench + 其时间增量去修正单个 TCP 指令；人类纠正做模仿、自主 transition 做 twin-critic 价值学习，并用 β_n 把 TD credit 限制在自主 segment 内**；插销 19→25/30、装配 22→27/30。」

## 8. 精读建议 (Reading Guide)

- **值得精读原文的人**：
  1. 做**接触密集操作**、需要在真机上对示范策略做部署后精调的研究者；
  2. 评估「冻结大模型 + 在线小残差」这条低算力路线可行性的工程师；
  3. 对 **human-in-the-loop RL 的 credit assignment（跨 intervention 边界）** 感兴趣的人。
- **建议章节路径**：先读 §III-A（问题定义与观测/动作表示）→ 再看 §IV-C（残差锚定与时序）→ 重点 §IV-D（β_n 遮罩与 TD 目标、actor 三项损失）→ 实验看 §V-B/§V-C 的表格与消融。可略读 §II 相关工作（除非要做对比矩阵）。
- **不值得精读的理由**：如果你不做机器人学习、或已熟悉 residual RL（ResiP/Policy Decorator）与 human-in-the-loop RL 的常规做法，读摘要 + §IV-D 的 β 设计即可，其余增量有限。

## 🔭 Pulsar 系统洞察 (System Insight)

- **对本仓库的定位**：本文属 `theory/rl`，是「VLA 部署后精调」方向的第一篇结构化拆解。它与已有的 VLA 在线 RL 条目（ConRFT/RECAP）形成互补：前者动全模型，本文只动小残差——这为 Ken 团队「RL 训练 VLA / VLA 后训练」方向提供了一条低成本参照路线。
- **跨域连接信号**：本文的「冻结先验 + 小残差适配」范式与 AI 应用线的 **adapter / LoRA / tool-layer 微调**思路同源——都是「保持基座不动，用小模块承接在线/场景适配」。这类「residual adapter」模式在两条线上同时出现，值得作为跨域交叉点持续观察。
- **可迁移假设**：若团队已有力感知 VLA（ForceVLA 类）先验，本文的 β_n 边界遮罩可直接迁移到任何 human-in-the-loop 采集流程，用于避免「人类救场」污染自主策略的信用估计——这一点与采集流程设计强相关。
- **待验证**：论文未做仿真与多平台，故「单平台三任务」的结论能否外推至其他本体/任务，需后续条目验证；已作为待观察项记录。
