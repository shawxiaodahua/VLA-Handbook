## 1. 核心架構/方法總覽 (Overview / Architecture)

### 1.1 系統對比概覽 (System Component Comparison)

FARM 的整個設計建立在一次「**表徵重用**」的實驗性追問上：失敗信息到底是世界模型裡「已經有」的，還是必須靠專門的監控模塊「學出來」的？

| 模塊 | 輸入 | 輸出 | 是否訓練 | 備註 |
|------|------|------|----------|------|
| V-JEPA2 編碼器 | 觀測歷史 | world-state tokens | ❄️ 凍結 | VLA-JEPA 的一部分 |
| VLA-JEPA 預測器 | world-state tokens + 任務條件化 latent-action tokens | 預測態 | ❄️ 凍結 | 取第 12 個 block 輸出（歸一化前）|
| **WM 態提取** | 預測器輸出 | H ∈ ℝ^(768×1024) | ❄️ 凍結 | 移除動作條件化 token，保留 768 個 world-state token × 1024 隱寬 |
| **FARM 讀出頭** | H | z^F ∈ ℝ^32, 逐步分數 s_t ∈ [0,1] | ✅ 唯一可訓練 | 33,985 參數 |
| **因果風險聚合** | s_t 序列 | q_t = max_{τ≤t} s_τ | 無參數 | 只需存一個標量 |

### 1.2 關鍵機制 (Key Mechanism)

- **完全凍結骨幹**：ϕ（WM 態提取路徑）在所有訓練與部署模式下都被 `sg`（stop-gradient）固定。只有 θ（讀出頭）被優化。這讓實驗能「直接測試失敗信息是否**已經**在預訓練預測表徵裡」，而不是測試一個新訓練的動力學模型有多大容量。
- **32 維瓶頸是刻意的**：作者明說「32 維瓶頸故意做小」，逼讀出頭去**選擇並組合**已經存在於 WM 態裡的信息，而不是從失敗監督裡「重新造一個預測模型」。
- **共享投影 + 注意力池化**：權重 W_p 在 token 間共享，使參數量不隨 token 數增長；注意力池化讓讀出頭在不同執行狀態下強調不同的預測 token。
- **因果性雙重保證**：(1) H_{i,t} 只依賴 x_{i,≤t}；(2) q_{i,t} 只聚合到 t 為止的分數。因此系統可在每個 replanning step 更新風險，而不訪問未來狀態。
- **可選的領域適配**：固定讀出頭零樣本遷移 vs. 僅更新讀出頭（readout-only adaptation），共享同一表徵與架構，差別只在是否有目標域監督來更新那 33,985 個參數。

⚡ **Eureka Moment**：**「失敗信息不需要被『學出來』——它已經在世界模型的內部預測態裡，你只需要一個足夠小的線性探針把它讀出來。」** 這是一句對「專用監控模塊」範式的反駁：與其訓練第二個模型去監控第一個模型，不如直接閱讀第一個模型已經算出來的東西。

## 2. 數學核心 (Math Core)

📌 **Napkin Formula**（一行抓住本質）：

```
失敗 = 可從「凍結」「內部態」線性+注意力讀出的東西：  s_t = σ( Readout_θ( sg[ F_φ(x_{≤t}) ] ) )
```

**目標**：給定軌跡集合 D = {τ_i}，每條軌跡屬任務 k_i、結果 y_i ∈ {0,1}（1=Fail），只訓練 θ 讓逐步失敗分數 s_{i,t} 能預測 y_i。

**前向**：

```
H_{i,t}^{WM} = sg[ F_φ(x_{i,≤t}) ]        # 凍結的世界模型內部態
s_{i,t}      = G_θ(H_{i,t}^{WM}) ∈ [0,1]  # 讀出頭逐步分數
q_{i,t}      = max_{τ≤t} s_{i,τ}          # 因果軌跡風險（遞歸 max）
```

**讀出頭內部**（去索引後）：

```
u_j  = GELU( LN( W_p · h_j + b_p ) )          # W_p ∈ ℝ^(32×1024)
α_j  = softmax_j( a^T u_j )                    # a ∈ ℝ^32
r    = Σ_{j=1}^{768} α_j · u_j  → ℝ^32
z_F  = GELU( W_f · r + b_f )
s    = σ( w_o^T z_F + b_o )
```

**損失（任務平衡二元交叉熵）**：

```
L_FARM(θ) = E_{k,i,t}[ ℓ_BCE(s_{i,t}, y_i) ]
ℓ_BCE(s,y) = -y·log s - (1-y)·log(1-s)

採樣：k ~ Unif(K_tr) → i ~ Unif(D_k) → t ~ Unif(T_i)   # 分層、任務等權
```

| 符號 | 含義 |
|------|------|
| F_φ | 預訓練 WM 態提取器（V-JEPA2 編碼器 + VLA-JEPA 預測器路徑），ϕ 恆凍結 |
| sg | stop-gradient，切斷對骨幹的反傳 |
| G_θ | FARM 讀出頭，θ 為唯一可優化參數 |
| α_j | 第 j 個 world-state token 的注意力權重（**僅在當前 replanning step 內**，不跨時間混合）|
| q_{i,t} | 到 t 為止的因果軌跡風險，遞歸 max，只需存一個標量 |

> 符號與本文一致：用 `max` 而非求和做時間聚合，是為了「保留短暫但強烈的失敗證據」。

**直覺**：整個數學的關鍵只在一個「stop-gradient」。因為骨幹不接受失敗監督，讀出頭的高 AUROC 就直接證明了失敗信息**原本就存在**於預訓練預測態中——這是引用式論證，而非能力論證。

## 3. 帶數字走一遍：玩具例子 (Worked Example)

假設某條 SO-101 抓藍色方塊的軌跡，一個 replanning step 得到 WM 態 H（768×1024）。走一步：

1. **共享投影**：1024 → 32。此步貢獻 32,800 個參數（32×1024 = 32,768，加 bias 32）。
2. **LayerNorm**：64 個參數（32 scale + 32 shift）。
3. **注意力**：a ∈ ℝ^32，32 個參數。對 768 個 token 算 α_j = softmax(a^T u_j)，加權求和得 r ∈ ℝ^32。
4. **隱藏層**：32 → 32，貢獻 1,056 個參數（1024 + 32 bias）。
5. **輸出頭**：32 → 1，33 個參數。

合計：32,800 + 64 + 32 + 1,056 + 33 = **33,985**（論文 §III-C 明列）。

假設三個連續 step 的逐步分數為：

```
s_1 = 0.08   → q_1 = max(0,   0.08) = 0.08   ✅ 正常抓取階段
s_2 = 0.04   → q_2 = max(0.08, 0.04) = 0.08   ✅ 分數回落（局部假陽性被 max 保留但不再升）
s_3 = 0.91   → q_3 = max(0.08, 0.91) = 0.91   ⚠️ 失敗浮現
```

**可計算閉環**：部署側只需設一個閾值（例如 q > 0.6 → 觸發介入）。因為 q 用 `max` 遞歸，只需保存**一個標量**，記憶體開銷極低——這正是「可落地」的核心。

論文給出的真實參考點：在軌跡長度 25% 時 Pooled AUROC/AUPRC 已達 75.07±0.73 / 80.75±0.16；到 75% 時達 81.63±0.40 / 85.53±0.65，只比全歷史低 1.78/1.27 點。也就是**觀察到 3/4 過程時，就已拿到幾乎全部判別力**。

## 4. 工程視角 (Engineering View)

| 指標 | 數值（論文 §IV-E）| 工程含義 |

**測量邊界很重要**：以上延遲**只包含讀出頭本身**，明確排除了世界模型推理、WM 態提取、預處理、傳輸、控制器開銷。也就是說 0.2256 ms 是「假設凍結態已經在手」的增量成本——真實部署的瓶頸仍可能在骨幹推理。

**訓練超參**（§IV-A2）：AdamW，lr 1e-3，weight decay 1e-4，軌跡 batch 4，最多 80 epochs，patience 10，梯度範數裁剪 1。

**記憶體/存儲**：WM 態是 768×1024 的張量（float32 約 3 MB/step），因此若要逐 step 監控，緩存 WMT 態的開銷遠大於讀出頭本身；工程上應在線計算、用完即棄。

**部署模式二選一**：
- **固定讀出頭零樣本**：源域訓練好直接搬到目標域，目標域數據完全不參與訓練與選型。
- **僅讀出頭適配**：有目標域標籤時，只更新 33,985 參數，骨幹與提取路徑不動——適合新機器人/新相機的快速對齊。

## 6. 能力與失敗模式 (Capabilities & Failure Modes)

**能做**：
- 在多任務（10 任務）上給出**逐步**失敗分數與**因果**軌跡風險，Seen 指標上領先全部 15 個匹配基線（Table III），比 SAFE-MLP 高 5.42/4.88 Macro AUROC/AUPRC。
- 跨策略/跨平台零樣本遷移（PIPER X 兩種策略、SO-101、Franka），且 FARM-Expanded 在四個零樣本設置上一致優於 FARM-Core（Table IV）。
- 僅更新讀出頭的適配能吸收殘餘目標域漂移：完整 Franka 種群五折 OOF 達 75.78±1.08 AUROC / 74.31±0.96 AUPRC。
- 從**部分因果歷史**判別失敗（25% 歷史即 75.07/80.75）。

**不能做 / 失敗模式**：
- **零樣本遷移不均勻**：嚴格 Unseen 任務上，STAC-Single（任務無關的動作一致性分數）排第一，FARM 僅高於 SAFE-MLP/LSTM。作者明說「嚴格 Unseen 任務漂移比匹配 Seen 更難」。
- **需要訪問內部態**：必須能拿到世界模型的內部預測態——對純黑盒 API 或無法導出中間態的系統不可用。
- **需要標籤**：訓練或適配都需要**帶成敗標籤**的軌跡。
- **最大聚合的副作用**：使用 `max` 保留短暫強證據，但也意味著一次誤報會被永久保留在軌跡風險裡（局部假陽性不可被後續低分覆蓋）。
- **實驗域偏窄**：模擬集中在 LIBERO 桌面操作；真實域為抓取/插入/擺放類任務，未見移動/雙臂/人形驗證。

### 6.1 隱含假設 (Hidden Assumptions)

- **假設失敗信息「穩態存在」於預測態中**，且不隨策略/任務大幅漂移——但 Unseen 結果恰恰顯示這個假設在跨任務時會動搖。
- **假設單幀（或短歷史）WM 態足以判別**：SO-101 每次只用 0.7 秒、8 幀的雙相機歷史產生一個 WM 態評分；對慢演化失敗（如長時潛伏漂移）是否足夠未驗證。
- **假設軌跡級標籤可下放到 step 級**：同一軌跡所有 WM 態都繼承 y_i，等於默認「失敗軌跡裡的每一步都是失敗」——這在早期正常階段是標籤噪聲，靠分層採樣與等權損失部分緩解，但未正面量化。
- **假設 VLA-JEPA 是代表性世界模型**：整套結論建立在單一骨幹上，未測其他世界模型（如 DINO-WM / DreamerV3）是否同樣「可直接讀出」。

**面試 Tip**：被問到「FARM 和 SAFE 有什麼本質區別」時，一句話答——**「SAFE 讀的是策略特徵，FARM 讀的是世界模型的內部預測態；前者問『策略是否自信地做對』，後者問『世界模型預測的未來是否正走向失敗』——而兩者都只訓一個輕量讀出頭、都不動骨幹。」**

## 8. 精讀建議 (Reading Guide)

- **值得精讀原文的人**：
  1. 做**世界模型驅動的 VLA 部署監控**的研究者——尤其是想复現「凍結表徵 + 輕量探針」這條低成本路線的人。
  2. 需要評估**跨機器人/跨策略監控遷移可行性**的工程師——§IV-D 的四平台設置與零樣本/適配對照最有用。
  3. 對「表徵裡到底編碼了什麼」（probing）感興趣的表徵學習研究者。
- **建議章節路徑**：先讀 §III（讀出頭與因果聚合的公式）→ 再看 §IV-B/IV-C（表徵證據 + 匹配基線對比）→ 再看 §IV-D/IV-E（遷移 + 延遲）→ §II 相關工作可跳（除非要寫 survey）。
- **不值得精讀的理由**：如果你**不做機器人學習**，或**已經很熟悉「凍結特徵 + 線性探針」的范式**，讀摘要 + 本文的「快速判斷表」即可——它的新意主要在「把探針應用到 WM 內部態」這個切入點，而非全新的學習算法。
