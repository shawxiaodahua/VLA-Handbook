## 1. 核心架構/方法總覽 (Overview / Architecture)

PRISM 是一個**訓練期改造策略**：它不新增任何推理模組，只在訓練時改變 (a) 流匹配損失的樣本權重、(b) VLM 條件表徵的輔助監督。核心由三個部件構成：

- **PPS（Proprioceptive Precision Scoring）**：離線從示範軌跡估計逐幀「精度需求」標籤 ρ ∈ [0,1]，訓練前固定。
- **PSW（Precision-Scaled Weighting）**：用 ρ + 流時間強調 + SNR 門控，給流匹配損失加權。
- **CPR（Conditional Precision Regularization）**：用一個 MLP 頭，讓 VLM 條件表徵能預測同一 ρ，訓練後丟棄。

### 1.1 系統對比概覽 (System Component Comparison)

| 模組 | 輸入 | 輸出 | 運行階段 | 訓練/推理差異 | 是否保留至推理 |
|------|------|------|----------|---------------|----------------|
| PPS | 關節位移 Δq、末端位移 Δe、夾爪狀態 | 逐幀 ρ ∈ [0,1]（離線標籤） | 訓練前一次性 | 純後處理，無可學習參數 | 否（僅產標籤） |
| PSW | ρ、流時間 τ、SNR | 樣本權重 w ∈ [1, 1+γ] | 訓練 | 只乘在損失上 | 否（推理無此項） |
| CPR | 遮罩池化 VLM 表徵 h_c | ρ̂ = σ(MLP(h_c)) | 訓練 | 輔助回歸損失 | 否（MLP 頭丟棄） |
| 主幹 VLA | (o, l, s) | 動作塊 z ∈ R^{H×D} | 訓練+推理 | **完全不變** | 是 |
| ODE 求解器 | 噪聲 x_τ | 乾淨動作 z | 推理 | **完全不變** | 是 |

### 1.2 關鍵機制 (Key Mechanism)

- **為什麼要按情境加權**：同樣的歸一化動作誤差，在搬運階段（容差 ~4 cm）無害，在插接階段（容差 0.15 mm）致命。示範軌跡裡搬運段長、對準段短，平均損失把大部分監督給了長而無關緊要的搬運段。
- **為什麼要按流時間加權**：推理時積分的是「局部監督學到的速度場」。論文用等能量擾動實驗證明：在乾淨端區間 τ ∈ [0, 0.2] 施加的速度誤差，對最終動作的影響最大（附錄 E.1, Figure 10）。等量損失 ≠ 等量後果。
- **為什麼要 SNR 門控**：τ 大時插值噪聲主導，動作證據還「看不見」，此時放大監督只會學噪聲。用泊松到達模型把 SNR 轉成飽和的「可見度概率」1 − e^{−SNR/τ0}。
- **為什麼要 CPR**：光靠 PPS 告訴模型「哪幀重要」不夠——模型還得在推理時**自己認得出**當下需不需要高精度（CPR 使表徵編碼此需求）。

⚡ **Eureka Moment**：**監督不該按「誤差大小」分配，而該按「誤差的物理後果」分配**——而後果由情境容差（Λ、J）與流時間傳播（Φ）共同決定，這兩者恰好無法從示範中直接觀測，所以要用可觀測代理（動作學 + SNR）去近似它們的乘積。

## 2. 數學核心 (Math Core)

📌 **Napkin Formula**（一行抓住本質）：
```
Flow-Time Starvation 下界直覺：‖η‖² ≤ 𝓔(B) · 𝓢(B)
即「標準流匹配損失 𝓔」乘上「端點敏感度 𝓢」才決定真實物理後果 —— 而 𝓢 隨情境與流時間劇變。
```

先給目標：**在訓練時把監督能量重新分配到「後果大」的 (情境, 流時間) 區域**，同時讓表徵預測精度需求。

**目標與公式（全部用代碼塊，無 LaTeX）：**

```
# (1) 物理後果的一階展開：動作誤差 → 任務空間誤差
Δy_c ≈ J_c · e_z ,   e_z = ẑ − z* ,   J_c = ∂F_c/∂z |_{z*}

# (2) 容差歸一化（δ 為各方向允許誤差；δ 越小，權重越大）
Λ(c) = diag(δ_1(c)^{-2}, …, δ_m(c)^{-2})

# (3) 情境風險（越低容差，風險放大越快，"十分之一容差 → 百倍懲罰"）
R(c) = E[ e_z^T J_c^T Λ(c) J_c e_z | c ]

# (4) 流匹配插值（τ=1 噪聲, τ=0 乾淨）
x_τ = (1−τ) z* + τ ε ,     u_τ = dx_τ/dτ = ε − z*

# (5) 殘差能量（標準流匹配懲罰的局部量）
E_c(B) = ∫_B p_τ(τ) ‖r_c(τ)‖² dτ ,  r_c(τ) = (v_θ − v*)(x*(τ), τ, c)

# (6) 端點擾動：局部殘差經傳播矩陣 Φ 到乾淨動作，再映射到任務空間
η_c(B) = −∫_B A_c(τ) r_c(τ) dτ ,   A_c(τ) = Λ(c)^{1/2} J_c Φ_c(0, τ)

# (7) ★ Flow-Time Starvation 界 (Proposition 1)
‖η_c(B)‖² ≤ E_c(B) · 𝓢_c(B) ,   𝓢_c(B) = λ_max[ ∫_B A_c(τ)A_c(τ)^T / p_τ(τ) dτ ]

# (8) 樣本 SNR 與可見度門控
σ_{f,i} = RMS(z*_i) ,  SNR_i = (1−τ_i)² σ_{f,i}² / (τ_i² + ε)
Pr(可見) = 1 − e^{−SNR_i/τ0}

# (9) PSW 權重
Ψ_i = (1−τ_i)^p · (1 − e^{−SNR_i/τ0}) ,   w_i = 1 + γ ρ_i Ψ_i ,  Ψ_i∈[0,1] ⇒ w_i∈[1,1+γ]

# (10) 加權損失 + CPR 輔助
L_PSW,i = (w_i / HD) · Σ_{h,d} (v_{θ,i,h,d} − u_{i,h,d})²
ρ̂(c_i) = σ(MLP(h_{c_i})) ,  L_CPR,i = (ρ̂(c_i) − ρ_i)²
L = L_PSW + λ_CPR · L_CPR
```

**變量說明：**

| 符號 | 含義 |
|------|------|
| c = (o, l, s) | 視覺觀察、語言指令、本體狀態 |
| z*, ẑ | 示範動作塊、生成（乾淨）動作塊 |
| J_c | 動作→任務空間的雅可比（本文核心：後果映射） |
| Λ(c) | 容差歸一化對角陣（δ⁻²） |
| r_c(τ) | 可約殘差（模型速度場 vs 最優速度場） |
| Φ_c(t,s) | 狀態轉移矩陣（把流時間 s 的擾動傳到 t） |
| 𝓢_c(B) | 最壞情況端點敏感度（單位殘差能量） |
| SNR_i | 樣本信噪比（動作證據可見度） |
| ρ_i | PPS 離線精度需求標籤 ∈ [0,1] |
| p, τ0, γ, λ_CPR | 四個標量超參（乾淨端強調、可見度飽和、放大上限、CPR 權重） |

**直覺**：式 (7) 是一個 Cauchy–Schwarz 型上界——「標準損失」乘「敏感度」夾住了「真實後果」。因為 Φ_c(0,τ) 同時依賴流時間與情境，J_c、Λ(c) 又各自依賴情境，這個乘積**不存在一個與情境無關的流時間加權**（論文原話："admits no context-independent flow-time weighting in general"）。所以 PRISM 用可分離代理近似：ρ 抓情境、τ 強調乾淨端、SNR 門控抓可見度。

> 符號與本文一致：與 π0/π0.5 系列流匹配記號對齊（τ=1 噪聲，τ=0 乾淨）。論文未直接給出 𝓢_c 的可計算形式——實際用可分離代理替代，屬**近似**而非精確最優。

## 3. 帶數字走一遍：玩具例子 (Worked Example)

假設一個 1D 插接任務，容差 δ = 0.15 mm；動作歸一化後 1 單位 = 1 cm 物理位移。取兩個訓練樣本：

**樣本 A（搬運段）**：容差 δ_A = 40 mm = 4 cm → 歸一化後 δ_A = 4 單位。ρ_A 低（PPS 給 0.1）。
**樣本 B（對準段）**：容差 δ_B = 0.15 mm = 0.015 cm → 歸一化後 δ_B ≈ 0.015 單位。ρ_B 高（PPS 給 0.9）。

假設兩者動作殘差大小相同，歸一化空間 e_z = 0.01。

```
# 容差歸一化後果（式 3 的心臟，δ⁻² 放大）
A 樣本:  誤差/容差 = 0.01 / 4     = 0.0025      → 幾乎無害
B 樣本:  誤差/容差 = 0.01 / 0.015 ≈ 0.667       → 逼近失敗門檻（閾值 1）

# 容差縮小 10 倍 ⇒ 懲罰放大 100 倍
(4 / 0.015)² ≈ 266.7  ⇒ B 的歸一化風險約 A 的 267 倍（同絕對誤差下）
```

**再加流時間與 SNR 門控**（取 p=2, τ0=1, γ=3）：
- B 樣本取 τ=0.1（靠乾淨端）、σ_f=0.5 → SNR = (0.9²·0.25)/(0.1²+ε) ≈ 20.25；門控 1−e^{−20.25} ≈ 1.0。
  Ψ_B = (1−0.1)²·1.0 = 0.81，w_B = 1 + 3·0.9·0.81 ≈ **3.19**。
- B 樣本若取 τ=0.9（靠噪聲端）：SNR = (0.1²·0.25)/(0.81+ε) ≈ 0.0031；門控 1−e^{−0.0031} ≈ 0.0031。
  Ψ_B ≈ 0.01²·0.0031 ≈ 3e-6，w_B ≈ **1.0000**（幾乎不放大）。
- A 樣本：ρ_A=0.1 → 即便 Ψ=0.81，w_A = 1 + 3·0.1·0.81 ≈ **1.24**（輕微）。

**結論**：同一批資料裡，模型學到的有效監督量從「所有樣本等權重」變成「精密樣本 + 乾淨端的權重是被托起約 3 倍，粗糙樣本幾乎不變」。這正是「只加不減」（w ∈ [1, 1+γ]）的分配方式——從不撤走任何樣本的監督，只往後果大的地方補。

## 6. 能力與失敗模式 (Capabilities & Failure Modes)

**能做：**
- 亞毫米級對準/插接/擰緊（0.1–0.2 mm 容差），端到端成功率 2 倍以上提升。
- 保留或提升一般雜務能力（RLBench/LIBERO 均不退化）。
- 對「變化擺放/不利預對準」更穩健（論文稱 DAgger 在這些條件下優勢變弱）。
- 精度需求可從運動學自學，**不需力/觸覺傳感器或新觀測模態**。

**不能做 / 失敗模式：**
- **僅桌面雙臂操作驗證**：3 個 MSSM 任務 + 現有基準，未測移動、人形、單臂長程任務——不要外推泛化性。
- **依賴離線 PPS 兩階段**：精度標籤訓練前固定，無法與策略聯合學習（作者自陳未來工作）。
- **γ 過大反而變差**：γ=1..5 掃描中 γ=3 最佳，γ=5 掉到 0.85（過度強調高需求樣本破壞平衡）。
- **低 SNR 區域無效**：Figure 5(c) 顯示低 SNR 組的殘差幾乎不改善——門控設計使然。
- **CPR 單獨會傷害低需求 bin**：需 PSW 配合才能全面提升。
- 對 token 預測式 VLA 不直接適用（針對流匹配/擴散頭設計）。

### 6.1 隱含假設 (Hidden Assumptions)

1. **PPS 代理 = 物理精度需求**：論文用「動作慢 + 夾爪嚙合 + 趨近 + 靜止」啟發式近似容差，但 δ 和 J_c 其實不可觀測。CPR 對 PPS 的相關性高（Spearman 0.915），但這只證明「模型能學會擬合代理」，不代表代理等於真容差。
2. **可分離代理足夠好**：式 (7) 的 Λ·J·Φ 乘積被拆成 ρ·τ·SNR 三項獨立因子，論文未給近似誤差界。
3. **示範軌跡的運動統計可跨任務遷移**：PPS 用 episode 內百分位排名，假設「慢 = 需要精度」在 19 個任務上都成立。
4. **同分佈訓練-測試**：真機任務對象置於預定義位置，泛化到任意佈局未驗證。

## 7. 與相關工作對比 (Comparison)

| 方法 | 關注點 | 架構/機制 | 訓練方式 | 適用場景 |
|------|--------|-----------|----------|----------|
| π0 / π0.5 | 通用流匹配 VLA | VLM + 流匹配動作專家 | 均勻流匹配損失 | 通用操作，精密段弱 |
| ForceVLA | 力感知 | 力覺 MoE | 需力傳感器 | 接觸豐富任務 |
| TA-VLA | 力矩感知 | torque-aware | 需力矩傳感 | 接觸豐富任務 |
| Tactile-VLA | 觸覺泛化 | 觸覺模態注入 | 需觸覺硬件 | 觸覺依賴任務 |
| Reactive DP | 慢-快視觸覺 | 視覺規劃 + 快速觸覺修正 | 需觸覺 | 接觸豐富操作 |
| DAgger 變體 | 資料側修正 | 加 100 修正示範/任務 | 需人為採集 | 特定失配矯正 |
| **PRISM（本文）** | **監督分配** | **PPS + PSW + CPR（推理不變）** | **僅改損失權重與表徵監督** | **亞毫米精密，無新傳感器** |

**與傳感器路線的定位差異**：ForceVLA/TA-VLA/Tactile-VLA 靠「讓接觸動力學更可觀測」，PRISM 靠「重新分配既有示範的監督」——前者要硬件，後者要重訓。兩者可互補（PRISM 亦可搭配力/觸覺輸入）。

🎯 **面試 Tip**：被問到「VLA 精密操作怎麼破」時，先答**病因診斷**——「標準流匹配損失在情境和流時間上平均分配監督，而誤差的物理後果由容差 Λ 和傳播 Φ 決定，兩者乘積無法用情境無關的流時間權重表達」；再答**處方**——「按精度需求量身重加權 + 讓 VLM 表徵自學預測精度需求，推理零成本」。

## 8. 精讀建議 (Reading Guide)

- **值得精讀原文的人**：
  1. 做 VLM + 流匹配/擴散動作專家 VLA 的研究者或工程師（可直接套用）。
  2. 要評估「零推理成本」升級精密操作可行性的部署工程師。
  3. 研究損失重加權 / SNR 加權 / 課程學習在機器人域遷移的研究者。
- **建議章節路徑**：先讀 §2（Proposition 1 與 Flow-Time Starvation 的直覺）→ 再看 §3.2–§3.3（PPS 與 PSW 的可落地細節）→ §4.5 消融看每個部件的增益 → §4.6 機制分析確認「CPR 與 PSW 互補」。可跳 §4.1 基線羅列（除非要做完整比較）。
- **不值得精讀的理由**：若你不做機器人學習、不用迭代式生成動作頭，或已熟悉 SNR 加權（如 Min-SNR、Perception Prioritized training）在圖像擴散的應用，讀摘要 + Figure 2/5 即可掌握全貌。
