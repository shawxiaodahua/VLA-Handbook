## X-Ray

GR00T N1.6-3B 是 NVIDIA 公开模型卡描述的跨具身视觉-语言-动作模型。卡确认动作模块使用 DiT 实现 flow matching：视觉语言特征经 cross-attention 条件化动作模块，diffusion step 经 AdaLN 输入，训练联合使用 flow matching 与 world-modeling 目标。卡的 Network Architecture 段写 SigLip2 与 T5，但 References 列 Eagle 2.5；仅凭这张卡不能确认这些描述如何对应实际 checkpoint，因此本文不把该骨干组合视为已核实配置。卡未提供 VLM 分模块参数、默认采样步数、控制频率或完整评测表。

模型卡描述了两条不同的条件路径：视觉语言 embeddings 经 cross-attention 输入，diffusion step 经 AdaLN 输入。按 embodiment 设置的 MLP 处理本体与动作接口差异，但这不证明仅换 ID 就能零样本适配任意机器人。world-modeling 是已声明的联合训练目标；卡未交代其推理期输出与计算开销，不能据此推断它必须输出或完全不参与推理。

## 数学核心：flow matching 的动作目标（教学记号）

**目标**：用速度场解释如何把高斯噪声输运到连续动作分布。下面特意选择线性插值、平方速度误差及“t=0 为噪声”的时间方向作为教学模型。卡只说明随机插值和速度预测，没有给出官方完整公式；以下不是已核验的训练损失、代码变量或采样配置。

```text
x_t = (1 - t) ε + t a,  t ∈ [0,1]
v_target = a - ε
L_action = E[ || vθ(x_t, t, c) - (a - ε) ||² ]
```

变量：`a` 为干净动作向量；`ε` 为高斯噪声；`t=0` 为噪声端，`t=1` 为动作端；`c` 为视觉语言、proprio、embodiment 等条件；`vθ` 为预测速度。

**直觉**：训练让网络在插值线上预测“从噪声指向动作”的速度；推理从噪声出发，沿速度场积分到动作。

```text
x_0 = ε
Δt = 1/N，t_k = k/N
x_{k+1} = x_k + Δt * vθ(x_k, t_k, c)
a_hat = x_N
```

`N` 是教学步数，不是官方默认采样步数。卡中同时出现 “diffusion transformer” 与 flow matching；本文按卡将其理解为以 DiT 实现的 flow matching 速度预测，不推断 DDPM 噪声目标。

联合目标只能分开示意：

```text
L_total 示意 = L_action + λ L_world
```

卡确认联合训练，但未给 `λ`、world-modeling 损失形式或输出定义，不能当作官方公式。

**Napkin Formula**：上述教学损失让 vθ 拟合 a−ε；对应的教学采样为 a_hat ≈ ε + ∫_0^1 vθ(x_t,t,c) dt。实际模型的参数化与求解器仍需查实现。

## 示意可计算玩具例子（非实验）

设一维干净动作 `a=1.0`，噪声 `ε=-0.2`，教学时间 `t=0,0.5,1.0`，并假设模型完美预测恒定速度 `a-ε=1.2`。用两步 Euler：

| 阶段 | 计算 | 结果 |
|---|---|---|
| 起点 | `x_0=-0.2` | 噪声 |
| 第1步 | `-0.2 + 0.5*1.2` | `0.4` |
| 第2步 | `0.4 + 0.5*1.2` | `1.0` |

得到 `a_hat=1.0`。真实模型的速度依赖 `x_t,t,c`，这里只是手算示意，不是作者实验、不是测量值，也不是默认采样设置。

- 模型卡给出 NVIDIA 许可链接；本次没有核验许可证正文、文件适用范围及后续变更，因此不依据链接文件名作商用授权判断。

## 数据与评测条件

卡中数据集标签为 `nvidia/PhysicalAI-Robotics-GR00T-X-Embodiment-Sim`。描述称训练混合包含 bimanual、semi-humanoid、expansive humanoid，以及真实采集数据与用 Isaac GR00T Blueprint 组件生成的合成数据；并称可通过 post-training 适配具体 embodiment、任务和环境。

评测方面，卡只说修改 connector 后改善 “our sim benchmarks”，没有给 benchmark 表、分母、样本数、指标定义或真机基准表。本篇因此不报告成功率或基线优势数字。部署时仍需核对 embodiment ID、状态/动作单位、padding 和相机接口是否匹配；world-modeling 的推理开销、目标环境性能及 sim-to-real 偏移也仍未知。这些是待验证工程条件，不能默认为训练细节不影响推理或仿真结果代表目标真机。
