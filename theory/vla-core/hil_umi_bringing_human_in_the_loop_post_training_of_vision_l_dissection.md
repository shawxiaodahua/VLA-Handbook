💡 **X-Ray 开场**
机器人"补课"通常要反复在真机上跑策略、由人手接管纠错（DAgger 家族），贵且难并行。这篇问：能不能不碰真机也做"策略感知"的数据采集？答案是——让人拿着 UMI 夹爪演示时，同时在同一观测流上查询当前策略，用人类动作与策略预测分布之间的**分歧（Energy Score）**判断"这里是不是策略的盲区"，是就当场补一段高质量演示。对 VLA 研究者意味着：后训练的数据采集第一次可以脱离物理机器人，按操作者和地点并行扩展。

## 1. 核心架构/方法总览 (Overview / Architecture)

HIL-UMI 把后训练拆成两路并行采集 + 两路模型更新，每轮（round r）交替执行。核心是把"哪里值得采、哪些数据有用"都交给在线模型判断。

### 1.1 系统对比概览 (System Component Comparison)

| 模块 | 输入 | 输出 | 频率/时序 | 训练/推理差异 |
|------|------|------|-----------|----------------|
| 策略 OOD 检测器 | 观测 o_t + 指令 c；人类动作块 H_t | δ_t^P ∈ {0,1} | 与人演示同步在线，N=10 路并行策略采样 | 仅推理；延迟 ~112 ms |
| 优势 OOD 检测器 | 观测对 (o_{t−K}, o_t) + c | δ_t^A ∈ {0,1} | 在线，t ≥ K 时 | 仅推理；延迟 ~93 ms |
| 优势估计器 f_ψ | (o_u, o_v, c) | 相对进度 ŷ = z_v − z_u | 每轮后更新一次 | 训练（MSE 回归）；推理用于打标 |
| 策略 π_θ | o, c^b（含优势标签的 prompt）| 动作块 | 每轮后更新一次 | ACBC 训练；推理用正优势 prompt |
| UMI 采集设备 | 人手演示 | 机器人兼容的 obs+action | 30 Hz | 采集，不执行策略预测 |

### 1.2 关键机制 (Key Mechanism)

- **机器人免部署**：人在 UMI 夹爪上演示，策略只在同一观测流上"旁路预测"，**不把预测结果执行到真机上**（这是与 HG-DAgger 的根本区别）。
- **策略条件化 OOD**：不是用数据集级的新颖度（如 EgoGuide），而是比较人类动作与**当前策略的预测分布**——分歧大 = 策略盲区 = 值得补采。
- **能量分数适配流式策略**：π0.5 是 flow-based 策略，没有显式似然，用 Energy Score 只需采样即可度量分布分歧，无需高斯假设。
- **优势模型自省**：另起一路，用在线优势预测挑出"估计器低估了进度"的片段，专门修优势模型，再让修好的模型给数据打效用标签。
- **ACBC 打标**：基础数据按优势 top-η 分配正/负标签，新采集数据一律正标签，用正优势 prompt 训练、推理时偏向"推进任务"的行为。

⚡ **Eureka Moment**：把"人类动作与策略预测分布的**分歧**"当成在线 OOD 探测器——于是数据采集不再需要真机 rollout，人类演示本身就成了对策略盲区的实时探针。

## 2. 数学核心 (Math Core)

📌 **Napkin Formula**（一行抓住本质）：

```
δ_t^P = 𝕀[ ES(H_t) > τ_P ]    # 人类动作块与策略预测分布分歧过大 → 判为 OOD → 补采
```

**目标**：用最少的额外人类采集，把策略更新集中到"当前策略做不好"的状态上。

**① 动作块距离（位置+姿态+夹爪）**：

```
ρ²(A,B) = (1/T) Σ_{k=1..T} [ λ_p·‖p_k^A − p_k^B‖₂²
                            + λ_R·d_R(R_k^A, R_k^B)²
                            + λ_g·‖g_k^A − g_k^B‖₂² ]
```

**② 姿态差用 SO(3) 测地距离**：

```
d_R(R₁, R₂) = arccos( (tr(R₁ᵀ R₂) − 1) / 2 )
```

**③ Energy Score（人类块 vs 策略采样分布，N=10 次随机采样）**：

```
ES(H_t) = (1/N) Σ_n ρ(A_t^(n), H_t)
        − 1/(2N(N−1)) Σ_{n≠m} ρ(A_t^(n), A_t^(m))
```

**④ 策略 OOD 检测**：

```
δ_t^P = 𝕀[ ES(H_t) > τ_P ]      # τ_P 跨任务共享
```

**⑤ 优势在线检测与标定**：

```
Â_t^online = f_ψ(o_{t−K}, o_t, c),   δ_t^A = 𝕀[ Â_t^online < τ_A ]
τ_A = κ₀ / 2      # κ₀ = 在基础数据上取优势 top-η 分位的经验阈值, η = 0.3
```

**⑥ 线性进度目标与优势模型损失**：

```
基础片段:   z_{i,t} = t / (L_i − 1)
迭代片段:   z_{r,j,t} = ( t / (L_{r,j} − 1) ) · ( L_{r,j} / L̄₀ )
有符号目标: y_{u,v} = z_v − z_u
损失:       L_A(ψ) = E[ ( f_ψ(o_u, o_v, c) − y_{u,v} )² ]
```

**⑦ 数据混合与 ACBC 打标**：

```
Mix(D_new, D_hist) = α·Unif(D_new) + (1−α)·Unif(D_hist)
b_{r,t} = 𝕀[ Â_{r,t} ≥ κ_r ]   若 (o_t,a_t) ∈ D₀（基础数据）
        = 1                      若 (o_t,a_t) ∈ ∪_{j≤r} D_j^P（新采集）
L_ACBC(θ) = E_{(o,a,b)~D̃_r^P}[ ℓ_BC( π_θ(·|o, c^b), a ) ]
```

**变量说明**：

| 符号 | 含义 |
|------|------|
| ρ, ES | 动作块距离 / 能量分数（度量人与策略分布分歧）|
| τ_P, τ_A | 策略、优势的 OOD 触发阈值 |
| K | 优势估计的观测帧时间偏移 |
| ψ, θ | 优势估计器参数、策略参数 |
| κ_r | 第 r 轮基础数据 top-η 优势分位阈值 |
| α | 当前轮 vs 历史数据混合系数 |
| c^b | 带正/负优势标签的 prompt |
| ℓ_BC | 策略原生动作预测损失 |

> 符号与本文保持一致：ES = Energy Score，OOD = Out-of-Distribution，ACBC = Advantage-Conditioned Behavior Cloning。

**直觉**：Energy Score 第一项度量"策略采样离人类动作多远"，第二项度量"策略采样自身的分散度"。两者相减后，既惩罚"离得远的错误预测"，也惩罚"分布塌缩"——避免退化成简单的逐点误差平均。这正好契合 flow/diffusion 策略没有显式似然的特点。

## 3. 带数字走一遍：玩具例子 (Worked Example)

设动作块长度 T=1（单步，便于手算），只用位置项 λ_p=1、λ_R=λ_g=0，N=2 次策略采样。

- 人类动作：h = [0.10]
- 策略采样：A⁽¹⁾ = [0.12]，A⁽²⁾ = [0.18]

第 1 项（采样到人的平均距离）：

```
(1/2)[ |0.12−0.10| + |0.18−0.10| ] = (1/2)(0.02 + 0.08) = 0.05
```

第 2 项（采样间分散度，n≠m 只有一对）：

```
1/(2·2·1) · |0.12−0.18| = 0.06 / 4 = 0.015
```

Energy Score：

```
ES = 0.05 − 0.015 = 0.035
```

若阈值 τ_P = 0.03，则 ES > τ_P → δ_t^P = 1 → 判为 OOD，当场补采。反过来，如果策略采样是 [0.10, 0.11]（贴着人类动作），ES 会很小 → 不触发。若采样是 [0.10, 0.40]（分散度极高）→ 第一项被拉大，同样触发——这正是 Energy Score 兼顾"位置 + 分散"的效果。

## 4. 工程视角 (Engineering View)

| 项 | 数值/含义 |
|----|-----------|
| 采集频率 | 30 Hz（UMI 设备，AgiBot OmniPicker + Meta Quest 3 控制器）|
| 策略 OOD 检测延迟 | 112 ms（N=10 路并行采样，缓解推理延迟）|
| 优势 OOD 检测延迟 | 93 ms |
| 计算平台 | 本地工作站 RTX 4090D |
| 每帧采集时间 | HIL-UMI 73.40 ms vs HG-DAgger 412.99 ms（5.63×）|
| 视觉输入 | RealSense D405（腕部视角）+ D455（第三人称固定视角）|

**工程含义**：

- OOD 检测开销（112/93 ms）远小于人类演示的节拍，因此可以在线跑，不阻塞采集。但 112 ms 相对 30 Hz（33 ms/帧）明显更慢——实现靠"并行采样 + 只在人类动作块观测完后比较"，而非逐帧同步。
- HIL-UMI 单帧**比 SFT 更慢**（多了在线选择开销），但因为把预算花在盲区上，相同累计采集时间下 TPS 更高、且不 plateau——这是一个典型的"单位时间质量换数量"的 trade-off。
- 阈值 τ_P 跨任务共享，但 τ_A 需按任务标定（用基础数据的分位 κ₀）。这是部署时最需要动手调的旋钮。

## 6. 能力与失败模式 (Capabilities & Failure Modes)

**能做**：
- 在长时程与高精度任务上，同数据预算下一致优于 SFT（SFT 提升有限、甚至短暂回退）。
- 比真机 HG-DAgger 采集效率高 5.63×，Clean Up Table 上 TPS 高约 5 分。
- 消融显示优势模型关键：去掉优势 → ACBC 退化为普通微调 → 性能显著下降。

**不能做 / 风险**：
- 仅在**单臂 Franka + 四个桌面任务**上验证，跨机器人主体（双臂、移动、人形）泛化未证明。
- 依赖人工演示"推进任务"这一假设——若操作者演示质量差，触发逻辑会失真。
- τ_P 跨任务共享、τ_A 需标定，阈值敏感（消融显示过松/过紧都掉分），迁移到新任务可能要重标。
- 能量分数基于 N=10 次采样估计分布，N 太小或策略采样方差大时，OOD 判定可能抖动。

### 6.1 隐含假设 (Hidden Assumptions)

- **假设人类动作块 H_t 是"正确答案"**：ES 大就判 OOD，但如果人类演示本身次优或走捷径，会把噪声当成盲区采进来。
- **假设低优势预测 = 估计器错误**：也可能只是该片段真的进度低；论文用"操作者假设在推进任务"来兜底，但未严格验证。
- **假设 UMI 观测与真机部署观测分布足够接近**：这正是 UMI 系列（HiFi-UMI 等）在攻的问题，本文未单独量化跨主体观测偏移。
- **假设 30 Hz 手部跟踪与策略推理的时序对齐无偏**：实时性用延迟数字支撑，但同步误差对 ES 的影响未做敏感性分析。
