💡 **X-Ray 开场**
VLA 策略预测一段未来动作（action chunk）后要执行多少步再重新观察？这个"action horizon"过去几乎都写死成常数。GeoAAC 的发现是：Flow Matching 生成动作时，内部会逐步修正速度场；**动作序列前 k 步的去噪几何抖动越大，说明这段预测越不可靠**。于是它把"去噪轨迹的形状"当成一根可靠性温度计，在单次生成里读出该执行到哪一步，无需额外训练、无需多次采样。

## 1. 核心架构/方法总览 (Overview / Architecture)

### 1.1 系统对比概览 (System Component Comparison)

| 模块 | 输入 | 输出 | 发生的时机/频率 | 训练 vs 推理 |
|------|------|------|----------------|--------------|
| Flow Matching 动作头 | 观测 o、噪声起始 x_0 | 中间速度预测 {v^(t)}、动作块 A | 每次策略推理时，T 个去噪步 | 预训练，GeoAAC 不改动 |
| 前缀几何特征 (Eq.2–3) | 每个前缀的前 k 维速度序列 | 局部几何变化 b_k^(t)、未校正 U_k | 单次生成内，逐去噪步逐前缀 | 纯推理计算 |
| 时间校正 (Eq.4–5) | 各去噪步相关性的长短 | 权重 w_t、校正后 Ũ_k | 单次生成内 | 纯推理计算 |
| Horizon profile (Eq.6) | 全部前缀的 Ũ_k | 向量 Ũ=(Ũ_1,…,Ũ_H) | 单次生成内 | 纯推理计算 |
| 执行边界选择 (Eq.7–13) | Ũ | 最终执行步数 k* | 每次 replan 前 | 纯推理计算（含 k_min, α 固定超参）|

关键点：整条链都发生在**推理阶段**，不改权重、不需额外标注、不需多次采样（区别于 MS 基线的多采样熵）。

### 1.2 关键机制 (Key Mechanism)

- **为什么用前缀几何而非输出熵**：机器人动作分布常是多模态的——同一次观测下，多条差异很大的动作序列都可能是"对的"。多采样得到的输出差异可能反映"合法模式的多样性"而非"预测不可靠"。因此作者转而看生成**过程**本身的稳定度。
- **为什么用去噪中间速度差**：Flow Matching 逐步把噪声搬运到动作上，相邻去噪步的速度差刻画了轨迹的局部形变。形变小 = 生成动力学一致 = 更可靠；形变大 = 模型在反复调整 = 更不确定。
- **为什么要时间校正**：几何变化在后期去噪步变大，但它与不确定性的相关性在中期之后反而下降。所以给各步加位置权重，强化中间步、抑制首尾步（Eq.4）。
- **为什么用"累积分布的 0.5 分位"而非最大响应**：绝对尺度随观测/任务漂移，固定阈值难校准；单个局部尖峰可能是噪声。用相对增长的正部累积到中位数，既去尺度、又抗瞬时抖动。

⚡ **Eureka Moment**：**同一个 Flow Matching 生成过程里已经免费附带了一个"预测可靠性剖面"——把去噪轨迹沿动作前缀的几何抖动读出来，取正增长累积分布的中位数，就是这个动作块该执行多少步。**

## 2. 数学核心 (Math Core)

📌 **Napkin Formula**（一行抓住本质）：

```
k* = max( median_k  Cumsum( max(ΔŨ_k/|Ũ_{k-1}|, 0) ) ,  k_motion )
```

先看目标：从单次 Flow Matching 生成中，给定每个候选前缀长度的几何"可靠性"剖面 Ũ，选出一个既不过短（避免频繁推理）也不过长（避免开环失手）的执行边界 k*。

**步骤 1｜Flow Matching 前向**（Eq.1）：

```
dx_τ/dτ = v_θ(x_τ, τ | o)
```

**步骤 2｜局部几何变化**（Eq.2）：

```
b_k^(t) = ‖ vec( (v_{1:k}^(t+1) − v_{1:k}^(t)) / (Δτ_t + ε) ) ‖₂ ,   t = 0…T−2
```

**步骤 3｜（未校正）前缀几何聚合**（Eq.3）：

```
U_k = T · Σ_{t=0}^{T−2} b_k^(t)  /  ( Σ_{t=0}^{T−1} ‖vec(v_{1:k}^(t))‖₂ + ε )
```

**步骤 4｜时间权重**（Eq.4）：

```
s̄_t = (t/T + (t+1)/T) / 2
w_t = s̄_t (1 − s̄_t)²  /  [ (1/(T−1)) Σ_{j=0}^{T−2} s̄_j (1 − s̄_j)² ]
```

**步骤 5｜校正后聚合 → profile**（Eq.5–6）：

```
Ũ_k = T · Σ_{t=0}^{T−2} w_t b_k^(t)  /  ( Σ_{t=0}^{T−1} ‖vec(v_{1:k}^(t))‖₂ + ε )
Ũ   = (Ũ_1, Ũ_2, …, Ũ_H)
```

**步骤 6｜相对增长 → 正部 → 累积分布**（Eq.7–9）：

```
r_k = (Ũ_k − Ũ_{k−1}) / (|Ũ_{k−1}| + ε) ,   k = 2…H
e_k = max(r_k, 0)
F_k = ( Σ_{i=2}^{k} e_i ) / ( Σ_{j=2}^{H} e_j ) ,   k = 2…H ,  F_1 = 0
```

**步骤 7｜中位边界 + 运动下界 → 最终 horizon**（Eq.10–13）：

```
k̂_50 = k + (0.5 − F_k)/(F_{k+1} − F_k)      # 中位数落在 k 与 k+1 之间时插值
q          = min( M(A)/α , 1 )
k_motion   = floor( k_min + (1 − q)(H − k_min) + 1/2 )
k*         = max( k_50 , k_motion )
```

变量说明：

| 变量 | 含义 |
|------|------|
| o | 当前观测（图像+语言+状态）|
| τ, t, T | flow time、去噪步下标、总去噪步数 |
| H | 最大预测 horizon（动作块长度）|
| v_{1:k}^(t) | 第 t 步、前 k 个动作维度的速度预测 |
| b_k^(t) | 前缀 k 在第 t 步的局部几何变化 |
| U_k / Ũ_k | 未校正 / 时间校正后的前缀几何量 |
| w_t | 位置相关时间权重（中间步加强）|
| r_k, e_k, F_k | 相邻相对增长、正部、正增长累积分布 |
| M(A) | 动作块整体运动幅度；α 为参考尺度 |
| k_min | 固定最小 horizon；k* 为最终执行步数 |

直觉：Ũ 像"随前缀增长的不确定度曲线"。若某前缀之后曲线陡增，说明再往后执行就越来越不可信 → 在中位增长处截断；若预测整体很"平"，则退回到 H（不早停）。运动下界 k_motion 防止"动作幅度很小却仍频繁 replan"的空转。

## 3. 带数字走一遍：玩具例子 (Worked Example)

假设 H=6、T=5，某次生成后（时间校正已完成）得到 profile：

```
Ũ = [0.90, 0.96, 1.05, 1.42, 1.60, 1.66]   （下标 k=1..6）
```

**第 1 步：相对增长 r_k（k=2..6）**

```
r_2 = (0.96 − 0.90)/0.90 = +0.067
r_3 = (1.05 − 0.96)/0.96 = +0.094
r_4 = (1.42 − 1.05)/1.05 = +0.352   ← 明显跳变
r_5 = (1.60 − 1.42)/1.42 = +0.127
r_6 = (1.66 − 1.60)/1.60 = +0.0375
```

**第 2 步：正部 e_k = max(r_k, 0)**（此处全正）

```
e = [—, 0.067, 0.094, 0.352, 0.127, 0.0375]   Σ_{j=2..6} e_j = 0.6775
```

**第 3 步：累积分布 F_k**

```
F_2 = 0.067/0.6775 = 0.099
F_3 = (0.067+0.094)/0.6775 = 0.238
F_4 = (…+0.352)/0.6775 = 0.758   ← 首次越过 0.5
```

0.5 落在 F_3=0.238 与 F_4=0.758 之间：

```
k̂_50 = 3 + (0.5 − 0.238)/(0.758 − 0.238) = 3 + 0.262/0.520 = 3.50
k_50  = round(3.50) = 4        # 中位数法取整（F 恰不取 0.5）
```

**第 4 步：运动下界**。设 k_min=3、α=1.0，此刻动作块运动量 M(A)=0.40：

```
q        = min(0.40/1.0, 1) = 0.40
k_motion = floor( 3 + (1−0.40)(6−3) + 0.5 ) = floor( 3 + 1.8 + 0.5 ) = floor(5.3) = 5
```

**第 5 步：最终边界**

```
k* = max(k_50, k_motion) = max(4, 5) = 5
```

解读：几何曲线在 k=4 附近"陡一下"，本来想只执行 4 步就重看；但因为**预测到的运动幅度很小**，执行 4 步几乎不改变状态、还白白多跑一次策略推理，所以运动下界把 horizon 抬到 5。这正是"几何可靠"与"运动启发式"两个信号的耦合——**只有两者都不冲突时才真的早停**。

## 6. 能力与失败模式 (Capabilities & Failure Modes)

**能做**：
- 在不训练、不改权重的条件下，让同一 checkpoint 在多个仿真基准与真机上稳定提升成功率。
- 按任务阶段/动作原语自动伸缩 horizon：精密对位阶段变短、连续搬运阶段变长。
- 在多模态动作分布下，用"过程几何"而非"输出多样性"判断可靠性，规避了多采样熵的固有歧义。

**不能做 / 失败模式**：
- **不改进生成质量本身**：它只决定执行多长；若单次预测本身就错，选再好的 horizon 也救不回。
- **依赖 flow-based 动作头**：自回归离散 token 策略（无连续速度场）无法直接套用。
- **几何↔不确定性相关性是经验假设**：论文在 GR00T N1.5 + LIBERO 上验证（200 观测 × 32 采样），换模型/换域是否仍成立，待外部复现。
- **固定超参的残差**：k_min、α 号称全任务固定，但本质上仍是需要选的超参；极端任务（超长 horizon 或动作幅度分布迥异）可能导致 k_motion 长期主导、退化为近似固定 horizon。
- **只调"执行多长"，不调"何时再看"**：作者在结论里也承认，未来工作才考虑"何时该获取任务相关信息"。

### 6.1 隐含假设 (Hidden Assumptions)

1. **"几何变化大 ⇒ 预测不可靠"在跨域成立**：该相关性的验证局限于 GR00T N1.5 在 LIBERO 上的采样统计，被视为普适前提。
2. **单次生成足够代表可靠性**：GeoAAC 只跑一次生成（区别于 MS），隐含"一次采样的去噪几何已含充分不确定性信息"。
3. **中位数是合适的截断点**：0.5 分位被当作"该停"的经验判据，而非从任务损失推导出的最优解。
4. **运动幅度与"值得早停"单调相关**：Eq.11–12 假设动作幅度小 ⇒ 应延长 horizon，未讨论"小幅度但高精度"任务的例外。
5. **固定 α 可跨任务**：参考尺度 α 与 k_min 全任务共享，隐含不同机器人/动作空间的运动幅度尺度可比。> TODO: 论文未给出 α、k_min 的具体取值与敏感性分析，待补充。

| **GeoAAC（本文）** | 生成过程几何 | Flow Matching 去噪轨迹前缀几何 | 否 / **单次生成** | flow-based VLA，追求零训练自适应 |

**面试 Tip**：被问到"GeoAAC 和基于多采样熵的自适应切分有什么本质区别？"——可一句话答：**熵类方法看的是"多次预测输出之间的差异"，容易把合法的多模态行为误判为不可靠；GeoAAC 看的是"单次生成内部、去噪过程本身的稳定度"，是过程级信号，因此不需要多次采样就能读出可靠性。**
