## 1. 核心架构/方法总览 (Overview / Architecture)

### 1.1 系统对比概览 (System Component Comparison)

| 模块 | 输入 | 输出 | 频率 / 时序 | 训练还是推理 |
|------|------|------|-------------|-------------|
| 邻近度估计器 `f` + sigmoid | 冻结 VLM 的 last-token、last-hidden-state 表征 `φ(x)` | 标量分数 `s(x) ∈ [0,1]` | 离线一次性；batch 128，通常在 75–100 step 触及 ≥90% 验证准确率并早停（附录 A） | 仅训练期 |
| Top-K 数据选择 | 候选池全体样本的分数 | EmbodiedMidtrain-1M | 离线一次性，`K = 1.28M`（注意：数据集名叫「1M」，实际选取量是 1280k） | 仅训练期 |
| VLM mid-training | 选定的 1.28M 条样本 | 中间训练后的 VLM checkpoint | 5,000 step × global batch 256，seq len 1024，全参数 SFT | 仅训练期 |
| VLA fine-tuning | 单视角图像 + 语言指令（不使用 robot state） | 连续手臂动作 + 夹爪二分类 | Calvin 8,000 step / batch 128；SimplerEnv 与 LIBERO-10 各 16,000 step / batch 256 | 训练 |
| 真实机器人部署 | 预测出的动作 chunk | 20 Hz 逐动作下发，Deoxys 在 1 kHz 底层闭环内执行 | 推理 | 推理（架构未变，故延迟与基线一致） |

关键点：**中间训练不改变模型的推理期形态**。它只是换了一个初始化，因此部署时序、动作 chunk 长度、控制频率全部沿用原 VLA 管线，这也是它工程上容易插入的原因。

### 1.2 关键机制 (Key Mechanism)

- **先证明差距存在，再动手**：作者用 MMD 量化数据集两两距离，用 t-SNE 看形状。结论有两条——跨组距离普遍大于组内距离；但 VLM 内部不同来源靠近 VLA 的程度差异很大（图 2）。第二条才是方法成立的支点。
- **把「数据配比」重写成「域判别 + top-K 检索」**：不去人工设计各数据集的采样比例，而是训练一个二分类器区分 VLA 与 VLM 样本，把预测概率当作连续邻近度分数。
- **冻结特征、只训线性头**：`φ(·)` 全程不更新，估计器只是最后一层隐状态上的单层线性 + sigmoid（式 4）。这让整个选择过程可以用缓存特征离线完成。
- **样本级而非数据集级**：附录 K 的表 16 显示，只按数据集平均分挑选（dataset-level）在 Calvin 上只有 3.273，与全池随机 3.398 相当；做到样本级才跳到 3.714。
- **跨底座复用同一份数据**：用 InternVL3.5-1B 的特征空间选出的数据，直接拿去中间训练 Qwen3VL-2B，不再重训估计器、不重选数据（§5.3）。

⚡ **Eureka Moment**：真正的关键做法是**把「该用哪些数据」变成一个在冻结表征空间里可学习的二分类问题**——因为域判别器的最优解对密度比 `p_VLA / p_VLM` 单调递增，所以一个线性分类器的输出概率就是天然的邻近度排序信号。

## 2. 数学核心 (Math Core)

📌 **Napkin Formula**（一行抓住本质）：

```
D_sel = TopK_{x ∈ D_VLM} σ( f( φ(x) ) )
```

先给目标，再给公式，再给变量说明，最后给直觉。

**(a) 分布差距的度量**（论文式 (1) 之前的 MMD 定义）：

```
MMD²(P,Q) = E_{x,x'~P}[k(x,x')] + E_{y,y'~Q}[k(y,y')] - 2·E_{x~P, y~Q}[k(x,y)]
k(x,y)    = exp( -||h(x) - h(y)||² / (2σ²) )
```

| 符号 | 含义 |
|------|------|
| `h(·)` | 冻结 InternVL3.5 的最后一层隐状态 |
| `σ` | RBF 带宽，用 median heuristic 设定 |
| `P, Q` | 两个数据集（VLM 或 VLA）的样本分布 |

直觉：MMD 小 = 两个数据集在特征空间里「混得开」；论文报告跨组距离普遍大于组内距离。

**(b) 选择目标**（论文式 (1)(2)）：

```
D_sel = argmax_{D' ⊆ D_VLM, |D'| = K} Σ_{x ∈ D'} s(x)
D_sel = TopK_{x ∈ D_VLM} s(x)
```

直觉：目标对样本可加，所以「选 K 条最大化总分」的解析解就是取分数最高的 K 条，不需要组合优化。

**(c) 为什么分类器概率可以当邻近度**（论文式 (3)）：

```
s*(x) = p_VLA(φ(x)) / ( p_VLA(φ(x)) + p_VLM(φ(x)) )
```

在等先验、打分函数不受限的条件下，最小化总体二分类交叉熵的最优解就是这个形式；它对密度比 `p_VLA/p_VLM` 单调递增。直觉：**概率 0.5 对应两个域等似然，>0.5 就是「更像 VLA」**。

**(d) 实际训练目标**（论文式 (4)(5)）：

```
s(x)  = σ( f(φ(x)) )                      # f 为单层线性
L_cls = -E_{y~D_VLA}[ log s(y) ] - E_{x~D_VLM}[ log(1 - s(x)) ]
```

两个域等权，避免 VLA 正样本量少时被淹没。

**(e) 多样性度量**（论文式 (10)，附录 F.1）：

```
S_div(D_i) = 1 / E_{u,v ~ D_i}[ exp( -t·||u - v||² ) ],   t = 2
```

`u, v` 是冻结 VLM 末层隐状态空间中的特征。分数越高表示样本铺得越开。用途是检验筛选后有没有把数据「塌缩」到 VLA 附近的一小团。

> 符号一致性说明：`D_VLM` 是候选池，`D_VLA` 是目标域数据，`K` 是选择预算，`φ` 是冻结表征，`f` 是唯一被训练的参数化部分。

## 3. 带数字走一遍：玩具例子 (Worked Example)

> ⚠️ 以下数值为**假设构造**，仅用于把公式走通，不对应论文任何实验。

假设候选池只有 6 条 VLM 样本，线性层输出的 logit 与经 sigmoid 后的分数为：

| 样本 | logit z | s = σ(z) |
|------|---------|----------|
| x1 | 2.0 | 0.881 |
| x2 | 1.2 | 0.769 |
| x3 | 0.0 | 0.500 |
| x4 | -0.4 | 0.401 |
| x5 | -1.4 | 0.198 |
| x6 | -2.0 | 0.119 |

**全池平均邻近度**：`(0.881 + 0.769 + 0.500 + 0.401 + 0.198 + 0.119) / 6 ≈ 0.478`

**取 K = 3 后**：保留 x1、x2、x3，平均分 `(0.881 + 0.769 + 0.500) / 3 ≈ 0.717`

也就是说，仅靠 top-K 操作，选定子集的平均邻近度从约 0.478 抬到约 0.717——这正是论文图 4 最右panel「选择前后分数分布向高分侧移动、低分质量被削掉」所描述的现象。**验算结论：筛选是有效的，但它只保证「选出的样本更像 VLA」，不保证下游一定变好，后者必须靠实验。**

**再走一遍损失**：假设一对平衡样本，正样本 y 得分 0.881、负样本 x 得分 0.119（即 logit 为 +2 与 −2 的对称情形）：

```
L_cls = -log(0.881) - log(1 - 0.119)
      = -log(0.881) - log(0.881)
      ≈ 0.127 + 0.127 = 0.254
```

对称 logit 给出对称损失，这解释了为什么作者用等权 BCE 时分类器会很快把两类推开——附录 A 报告通常 75–100 step 就达到 90% 验证准确率。

**K 值的敏感性（论文实测，非假设）**：附录 J 表 14 显示 `K = 1.28M` 最优（Calvin 3.714 / SimplerEnv 56.3 / LIBERO-10 54.2），`K = 2.56M` 回落到 3.455 / 51.0 / 50.4，`K = 320k` 为 3.211 / 47.9 / 48.6，全池不筛为 3.398 / 43.8 / 48.4。**这说明选择不是「越多越好」也不是「越少越好」，而是有一个中间的最优工作点。**

## 6. 能力与失败模式 (Capabilities & Failure Modes)

**能做**：
- 在冻结特征上低成本地为 VLM 数据打「具身相关度」分，且分数在数据集级和样本级都有区分度（图 5）。
- 选出的数据可跨 VLM 底座复用（InternVL 选 → Qwen3VL 训，无需重选）。
- 可跨动作头复用：并行解码（OpenVLA-OFT 风格）与 flow matching（π0 风格）上都有提升，幅度 4.0–12.5 点（附录 H.2 表 12）。
- 可跨目标任务复用：把 LIBERO 完全从选择目标中剔除后，LIBERO-10 仍从 39.0 提到 53.4，保留全量方法（54.2）约 95% 的增益（附录 H.1 表 11，作者表述）。

**不能做 / 未验证**：
- 未验证移动操作、双臂、人形、多视角、需要本体状态输入的场景；全部仿真与真机实验都是单臂桌面操作 + 单视角。
- 真机证据规模有限：5 个任务 × 10 次 rollout = 50 次评测，任务级差异的置信度有限。
- 通用 VLM 能力有小幅回退（附录 G 表 9）：POPE 86.33 → 86.29（基本持平），BLINK 43.45 → 40.45（−3.0），SpatialEval 49.82 → 48.00（−1.8）；VisuLogic 21.00 → 24.90 与 3DSRBench 47.87 → 49.51 上升。BLINK 子任务里跌幅最大的是 Visual Similarity（0.726 → 0.474，−0.252）与 Jigsaw（0.620 → 0.527，−0.093），作者归因于「多图 / 拼图类输入格式在机器人数据里罕见，筛选后覆盖不足」。
- 估计器的停止点很敏感：附录 J 表 15 显示，验证准确率 70% / 90% / 95% 三个检查点下，全池中 `s(x) < 0.10` 的样本占比分别是 21.0% / 52.8% / 80.7%，LAION-400M 的分数 IQR 从 0.293 收到 0.158 再到 0.042。**训太久会把分数压向 0、丢掉样本级区分度**，这是个需要调的旋钮。

### 6.1 隐含假设 (Hidden Assumptions)

- **假设一：冻结特征 + 线性探针足以刻画「对 VLA 有用」**。方法只在末层隐状态上训一层线性，若真正有用的信号藏在中间层或需要非线性组合，这个探针会漏掉。
- **假设二：目标 VLA 数据的分布能代表下游任务**。选择器需要正样本，论文用的是 VLA 微调数据的平衡混合；跨任务迁移（附录 H.1）缓解了这条，但没有被彻底证伪。
- **假设三：仿真数据选出的分布能迁移到真机**。§5.4 声称成立，但真机只有 5 个任务。
- **假设四：VLM 通用能力的回退是可接受的代价**。作者明确写了「目标不是全面提升通用 VLM 任务」，这是价值判断而非实验结论。
- **假设五：中间训练与 VLA 微调之间没有负迁移**。论文只在两个底座上验证，底座规模都在 1–2B 量级；更大底座是否同样受益未测。

**与「直接多训几步」的区别**（这是最容易被追问的一点）：附录 I 表 13 做了 FLOP 对齐——把同等算力全花在延长 VLA 微调上得到 SimplerEnv 43.8 / LIBERO-10 45.8，而中间训练路线是 56.3 / 54.2。**同等总算力下，中间训练更划算。**

**面试 Tip**：被问到时一句话答——「它不是新 VLA 架构，而是在 VLM 和 VLA 之间加了一个用冻结特征做域判别、top-K 选数据的中间训练阶段；核心证据是表 14 的 K 值消融（1.28M 最优；全池在 SimplerEnv 与 LIBERO-10 上低于各筛选子集）和表 13 的 FLOP 对齐对照，说明增益来自『选对了数据』而不是『多训了』。」

## 8. 精读建议 (Reading Guide)

- **值得精读原文的人**：
  1. 正在做 VLM 底座改造、需要决定「预训练 → 中间训练 → 下游微调」三阶段怎么切的研究者；
  2. 手上有一堆异构多模态数据、想知道怎么按目标域做样本级筛选而非数据集级配比的工程师；
  3. 想评估「把已有 VLM checkpoint 再喂一轮数据」这条路性价比的团队。
- **建议章节路径**：先读 §3 与图 2（确认差距与异质性这两个前提）→ 再看 §4 与式 (1)–(5)（方法本体）→ 然后直接跳附录 J 表 14 与附录 K 表 16（K 值与选择粒度的真实敏感度）→ 最后看附录 I 表 13（算力归因）与附录 G 表 9/10（能力回退）。§2 相关工作与 §5.2 基线罗列可以速读。
- **不值得精读的理由**：如果你的工作不涉及机器人学习、或已经熟悉「用分类器做数据筛选」这一类 importance-resampling 思路，读摘要 + 图 2 + 表 14 即可抓住全部要点；本文的数学工具（MMD、密度比、BCE）都是标准件，没有新的推导。
