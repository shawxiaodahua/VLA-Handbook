💡 **X-Ray 开场**
世界动作模型（WAM）一边预测未来画面、一边生成机器人动作，效果强但部署极贵（ImageWAM 用 bf16 要 19.9 GB 显存）。这篇发现：量化时「哪一层最敏感」不能只看这一层自己的输出误差——真正该问的是「这一层的舍入误差经过后面所有去噪步之后，会让最终动作偏多少」。作者用标定时的一次反向传播把这个问题变成每层一个矩阵（AOG），再只把动作最敏感的少数方向放进 16-bit 分支、其余全部压到 4-bit。对 VLA 研究者意味着：扩散式策略的低比特部署第一次有了「以动作保真为目标」的专用量化准则。

## 1. 核心架构/方法总览 (Overview / Architecture)

WAM 的推理链路在一个控制步内是这样的：编码观测+语言指令得到条件 z，然后动作头从高斯噪声出发做 T 步 Euler 去噪得到动作块 a。每一去噪步对 h 个动作 token 跑一次 transformer。Q-WAM 不改这个结构，只在「线性层怎么量化」上做文章。

### 1.1 系统对比概览 (System Component Comparison)

| 模块 | 输入 | 输出 | 时机/频率 | 训练/推理差异 |
|------|------|------|-----------|----------------|
| 条件编码器 | 观测 o_t（相机+本体态）、指令 l | 缓存条件 z | 每控制步 1 次 | 与 bf16 一致 |
| 视频/世界模型专家 | z | 未来视觉表示 | 仅训练监督（Fast-WAM 设定） | 量化时保护它收益极低 |
| 动作专家 (action head) | 噪声 a^(0) + z | 速度场 v_θ | 每去噪步 T 次 × h token | 承担 89.3%+「动作质量」 |
| AOG 标定 | 标定输入 + 随机探针 u | 每层 G_ℓ | 离线一次 | 仅推理前标定，不需重训练 |
| ASP 低秩分支 | x̃ 在动作子空间的分量 | 16-bit 输出 | 每步推理 | 固定子空间，几乎零额外算力 |
| 4-bit 主路径 | 去保护后的激活/权重 | W4A4 输出 | 每步推理 | 稠密 GEMM，走整数核 |

### 1.2 关键机制 (Key Mechanism)

- **为什么不用「局部误差」选保护对象？** 论文实测（§4.1, Fig.3a）：在 Fast-WAM 上逐层单独量化，用「该层输入量化误差 ‖δ‖²」预测动作损伤，Pearson 相关只有 ρ=0.04；而用 AOG 预测则达到 ρ=0.95。换句话说，传统 PTQ 的「减小每层输出误差」在 WAM 里几乎是瞎猜。
- **为什么是「方向」而不是「通道」？** 保精度最有效的是激活空间中动作敏感的方向，这些方向混合了许多通道，且由「动作对误差的响应」而非激活值大小决定（§4.2）。
- **为什么要按专家分配？** 在 Mixture-of-Transformers 里，动作专家参数不到 1/5，却承载 89.3%（Fast-WAM）/99.99%（ImageWAM）的「动作质量」（μ_E）。只保护动作专家即可，扩到第二个专家只加 0.17–0.18 BPW 而收益小于标定噪声。
- **为什么低秩分支不贵？** 保护秩 r=32，远小于通道维度；两条路径都是稠密 GEMM，可在 GPU 上高效运行（§4.2）。

⚡ **Eureka Moment**：把「这一层量化会伤到动作多少」直接定义为每层一个可标定的矩阵（AOG = 动作对激活误差的 Gramian），从而用**最终动作**而非**本层输出**来决定谁该保精度。

## 2. 数学核心 (Math Core)

📌 **Napkin Formula**（一行抓住本质）：

```
E‖A_δ − A‖² ≈ Σ_ℓ  δ_ℓᵀ G_ℓ δ_ℓ      其中 G_ℓ = E[ Σ_i J_ℓ^(i)ᵀ J_ℓ^(i) ]
```

先给目标：我们希望量化后模型生成的动作 A_δ 尽量接近全精度动作 A，即最小化 E‖A_δ − A‖²。对激活舍入残差 δ 做一阶泰勒展开，并在「残差零均值、互不相关、与 Jacobian 不相关」的近似下，交叉项消失，只剩每层一个二次型。

变量说明：

| 符号 | 含义 |
|------|------|
| a / A | 全精度模型生成的动作块，m = h·d_a 维 |
| A_δ | 激活带舍入残差时生成的动作块 |
| x_ℓ^(i) | 第 ℓ 层在第 i 个 token–step 对的输入激活 |
| δ_ℓ^(i) | 量化残差 Q4(x) − x |
| J_ℓ^(i) | 动作对 x_ℓ^(i) 的 Jacobian ∂a/∂x，m×d_ℓ |
| G_ℓ | Action Observability Gramian，d_ℓ×d_ℓ 对称半正定 |
| λ_j, v_j | G̃_ℓ 的第 j 个特征值/特征向量 |

**AOG 的估计（探针法）**：精确算 Jacobian 每行都要一次反传，太贵。用随机探针 u~N(0,I_m)，一次 ⟨a,u⟩ 反传即可拿到所有层的 Jᵀu；由于 E[uuᵀ]=I，探针外积的期望就是 JᵀJ：

```
Ĝ_ℓ = (1 / N·P) Σ_n Σ_p Σ_{i∈I_ℓ} (Jᵀ_{ℓ,n} u_{np})(Jᵀ_{ℓ,n} u_{np})ᵀ
```

每个标定输入只需 P 次反传而非 h·d_a 次；论文取 P=12，约为精确计算的 1/37（Fast-WAM）。

**ASP 的拆分（先旋转，再投影）**：先做 SmoothQuant 缩放 + Hadamard 旋转，把 AOG 变换到新坐标 G̃_ℓ = H diag(γ) G_ℓ diag(γ) H。因 G̃ 对称半正定，可特征分解：

```
δᵀ G̃_ℓ δ = Σ_j λ_j (v_jᵀ δ)² ,   λ_1 ≥ λ_2 ≥ … ≥ 0
```

取前 r 个特征向量 V，投影 Π = V Vᵀ，把激活拆成：

```
x̃ = V(Vᵀx̃) + x̃_⊥ ,   x̃_⊥ = (I − Π) x̃
```

层输出随之拆成两条路径：

```
W̃ᵀx̃ ≈ (VᵀW̃)ᵀ(Vᵀx̃)          [16-bit 低秩分支]
        + Q4(W̃_⊥)ᵀ Q4(x̃_⊥)     [W4A4 主路],  W̃_⊥ = (I − Π)W̃
```

**专家选择（action mass）**：旋转后舍入误差近似各向同性（各方向方差 σ²），故每层损伤 ≈ σ²·tr(G̃_ℓ)。对专家 E 的层求和：

```
μ_E = Σ_{ℓ∈E} tr(G̃_ℓ)
```

按「单位 16-bit 开销带来的动作损伤削减」保护 μ_E 最大的专家。

> 直觉总结：AOG 把「全模型层面的动作偏移」压缩成每层一个矩阵，而矩阵的特征值谱快速衰减 → 只需保护少数几个方向即可回收绝大部分损伤。这就是 Q-WAM 用极小 16-bit 分支换回接近 bf16 精度的原理。

## 3. 带数字走一遍：玩具例子 (Worked Example)

设想单层、d_ℓ=4 维，已做旋转，AOG 特征值为 λ = [100, 10, 1, 0.1]，保护秩 r=2。

- 若激活残差在某方向均方 σ²=0.01（各向同性假设），则未保护时预期损伤 ≈ σ²·Σλ_j = 0.01×(100+10+1+0.1) = 1.111。
- 保护前 2 个方向后，剩余损伤 ≈ σ²×(1+0.1) = 0.011，即回收约 99%。

这就是「特征值快速衰减 → 少量方向吃掉了几乎所有损伤」的数值直觉。即便 σ² 换成 0.1，未保护损伤 11.11、保护后 0.11，比例不变。

再算开销：保护 r=2/4 维，16-bit 分支每条激活多存 2×2=4 字节；主路径 4-bit。用论文的账本（Fast-WAM，§5.1）印证：ASP 只让 BPW 从某基线增加 0.08–0.26，显存多 0.05–0.16 GB，却把与 bf16 的差距收回 76–95%。

> 注：以上 λ、σ² 为示意数值，用于说明机制；论文未给出这组具体数字。

## 4. 工程视角 (Engineering View)

- **显存**：ImageWAM 用 bf16 需 19.9 GB（§1）；Q-WAM 使被量化块的显存降 68–71%（3.1–3.4×）。LingBot-VA 上维持 4.76 BPW / 3.27 GB。
- **延迟**：在 L40S 上用真实 4-bit kernel，处理动作 token 的量化层比 bf16 快 1.06×（Fast-WAM）、1.56×（ImageWAM）、1.41×（LingBot-VA）。注意加速有限，因为动作块很短，这些层「权重的加载」主导代价，而 4-bit 存储正好减轻这一点。
- **标定成本**：每个标定输入需 P=12 次反传；这是主要的离线一次性成本。标定数据敏感度：两份标定集之间平均成功率差 1.12 点（§5.2），这是判断「ASP 扩到第二个专家是否有收益」的噪声地板。
- **部署约束**：纯后训练（PTQ），无需重训练全模型；保护子空间推理时固定，16-bit 分支很小、几乎零额外算力。需要能跑标定反传的 GPU（论文用 H100 标定、L40S 仿真、RTX 5090 实机）。
- **超参**：保护秩 r=32、分组 W4A4 组大小 32、保护分支 16-bit。这些是默认配置，未在正文系统扫（部分在附录）。

## 5. 数据与评测 (Data & Eval)

- **模型**：Fast-WAM、ImageWAM（均为 Mixture-of-Transformers，动作头挂视频/图像编辑主干）、LingBot-VA（共享单主干）。
- **仿真**：RoboTwin 2.0（ICML），50 个任务，clean + randomized 两种条件，100 条演示。
- **实机**：Fast-WAM 与 ImageWAM，5 个任务，2 种本体——Unitree G1 人形（工具分拣、物品分类）、双臂 UR3（擦桌、叠方块、抽屉操作），每任务 25 次试验。
- **基线**：bf16、SmoothQuant、ViDiT-Q、SVDQuant（仿真）；实机对比 bf16 与 SVDQuant。量化方法统一 W4A4，BPW 计入存储开销。

**主要结果（仿真，§5.1）**：

| 模型 | Q-WAM 平均成功率 | 距 bf16 | 超 SVDQuant | BPW (Q-WAM vs SVDQuant) |
|------|------------------|---------|-------------|--------------------------|
| Fast-WAM | 90.78% | −1.03 | +2.53 | 4.62 vs 4.84 |
| ImageWAM | 92.97% | −0.29 | +8.69 | 4.58 vs 4.75 |
| LingBot-VA | 89.56% | −0.96 | +5.08 | 4.76 vs 4.76 |

randomized 条件下超 SVDQuant 分别为 +2.56 / +8.72 / +5.80 点。SmoothQuant 与 ViDiT-Q 在某些模型上严重退化（如 ImageWAM 上仅 59.20% / 80.42%）。

**实机结果（§5.1）**：Q-WAM 平均成功率 Fast-WAM 56.0%、ImageWAM 76.0%，超 SVDQuant 12.8 / 17.6 点；但距 bf16 仍差 8.8 / 7.2 点。最大改善在 ImageWAM 叠方块：19/25 vs SVDQuant 5/25，bf16 为 21/25。

**消融（§5.2）**：仅加 Smoothing+rotation 后仍距 bf16 差 4.26/5.84/5.44 点，ASP 收回其中 76–95%，代价仅 0.08–0.26 BPW。在 ASP 之上再叠加 SVDQuant 的低秩权重保护，只会增加比特数而无收益。把 ASP 扩到第二个专家只改变 +0.08/+0.52 点，小于 1.12 点的标定噪声。

## 6. 能力与失败模式 (Capabilities & Failure Modes)

**能做**：把 WAM 的 W4A4 量化做到接近 bf16 的仿真任务成功率；跨 MoT 与共享主干两类架构通用；实机闭环保真度明显优于 SVDQuant。

**不能/受限**：

- 实机仍显著低于 bf16（Fast-WAM −8.8、ImageWAM −7.2 点）。低比特部署在真机上不能宣称「无损」。
- 评测面窄：只有 2 种本体、5 个实机任务；RoboTwin 2.0 虽含 50 任务但属双臂桌面域——**不要外推到移动/人形全身/户外**（G1 仅做工具分拣与分类这类桌面级任务）。
- 保护依赖标定：AOG 需在标定时做反向探针，标定集不同会带来约 1.12 点的成功率波动。
- 固定保护秩 r=32，未展示对不同 backbone 规模/秩的自适应。

### 6.1 隐含假设 (Hidden Assumptions)

- **一阶泰勒 + 残差近似**：假设 δ 零均值、互不相关、且与 Jacobian 不相关（附录 A.2）。在较大量化误差或强非线性处，二阶项可能不再可忽略。
- **旋转后误差各向同性**：专家选择 μ_E 与「保护 top-r 方向最优」的证明都建立在这个近似上；若实际残差有方向偏置，结论可能松动。
- **各层共享同一 σ²**：μ_E 求和时假定所有层舍入方差一致，未逐层验证。
- **动作-权重误差的乘积项**可忽略：拆分公式里余下的是权重与激活误差的乘积项，论文将其视为可忽略。
- **标定数据代表性**：AOG 由标定输入分布估计，分布漂移（新任务/新场景）下其保护方向是否仍最优，论文仅在附录 C.3 做了有限检验。

## 7. 与相关工作对比 (Comparison)

| 方法 | 关注点 | 保护对象的选择准则 | 保护形式 | 适用场景 |
