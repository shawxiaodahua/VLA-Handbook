## 1. 核心架构/方法总览 (Overview / Architecture)

RWM 的骨架可以概括为：**一个共享的表征空间 + 局部逆动力学监督 + 推理期路径构造**。它刻意不训练一个"显式动力学预测器"，而是让表征的几何结构本身承载状态、转移与可执行计划三件事。

### 1.1 系统对比概览 (System Component Comparison)

| 模块 / 组件 | 输入 | 输出 | 训练 vs 推理差异 | 备注 |
|------|------|------|------|------|
| 表征编码器 (Encoder) | 观测 (状态 / 图像特征) | latent 表征 z | 两者共用 | 承载"状态"信息 |
| 表征几何 (Representation Geometry) | latent 空间 | 可导航的结构 | 训练期由逆动力学监督塑形 | 本文核心：planning 内嵌于此 |
| 路径构造 (Latent Path) | 起点表征 z_start、目标表征 z_goal | 一条 latent 路径 | **仅推理期使用** | 替代 rollout / 搜索 |
| 逆动力学 (Inverse Dynamics) | 相邻 latent 表征对 | 动作 a | 训练期提供 loss；推理期还原动作 | 局部、非递归 |
| 显式动力学预测器 | — | — | **不存在** | 与多数世界模型的关键差异 |
| 搜索 / 优化器 | — | — | **不存在** | 规划不必再"搜" |

### 1.2 关键机制 (Key Mechanism)

- **规划即几何**：不再"学一个动力学模型再去搜"，而是让表征空间被训练成"内部可导航"——起点与目标之间的距离/路径本身携带可执行的转移信息。
- **局部逆动力学监督**：作者沿"由端点表征构造出的 latent 路径"局部地施加逆动力学监督，迫使这些路径**保留任务相关的状态与转移信息**。即：路径上的每一小段，都必须能反推出对应的动作。
- **推理零 rollout、零搜索**：推理时直接在当前表征与目标表征之间构造一条 latent 路径，再用逆动力学逐步还原动作。没有递归想象，也没有动作空间里的搜索。
- **端点表征驱动**：路径由"端点表征"（起点 + 目标）构造，而非由显式动力学一步步推演——这是它省算力的根源。

⚡ **Eureka Moment**：**把"规划"从"对未来做搜索"改写为"在表征空间里连一条线"**——只要这条线的每一小段都能被逆动力学映射成合法动作，那么"连线"就等于"规划"。

### 1.3 信息流/架构图 (Flow / Diagram)

```
训练期:
  观测 s ──▶ Encoder ──▶ 起点表征 z_s
  目标表征 z_g ─────────────────┐
                                 ▼
                      构造 latent 路径 {z_0=z_s, ..., z_N=z_g}
                                 │
                    局部逆动力学监督 (inverse dynamics)
                                 │
                                 ▼
                  loss: 每段 (z_i → z_{i+1}) 都应还原出合法动作 a_i
                                 │
                                 ▼
                 表征几何被塑形为"可导航、保状态/转移信息"

推理期 (无 rollout / 无搜索):
  z_start ──(构造 latent 路径)──▶ {z_0 ... z_N} ──▶ 逆动力学 ──▶ 动作序列 {a_i}
     ▲                                                              │
  z_goal ───────────────────────────────────────────────────────────┘
```

## 2. 数学核心 (Math Core)

📌 **Napkin Formula**（一行抓住本质）：

```
planning(z_start, z_goal) := inverse_dynamics( path(z_start, z_goal) )
```

先给目标，再给公式，再给变量说明，最后给直觉。

**目标**：学一个表征空间，使得"在表征中构造的路径"经逆动力学还原后，是一段物理可执行的轨迹。等价于：让表征几何本身就编码"可执行的转移"。

**核心结构（用代码块表达，避免 LaTeX）**：

```
L = L_inv + λ · L_geo

L_inv = Σ_i  d_a( f_inv(z_i, z_{i+1}),  a_i* )        # 局部逆动力学：每小段反推动作
L_geo = R( z_0 = z_s, z_N = z_g, {z_i} )              # 让路径满足端点约束 + 平滑/保信息

其中:
  z_s, z_g   : 起点 / 目标 表征 (来自 Encoder)
  {z_i}      : 由端点表征构造出的 latent 路径
  f_inv      : 逆动力学网络
  a_i*       : 与该段转移对应的真实动作 (监督信号)
  d_a        : 动作空间距离度量
  λ          : 几何正则权重

推理:
  {z_i} = path(z_start, z_goal)      # 构造, 非搜索
  a_i   = f_inv(z_i, z_{i+1})        # 逐步还原, 非递归 rollout
```

> 符号与本文保持一致：`z` = latent 表征；`f_inv` = 逆动力学；`path(·)` = 端点表征间的路径构造算子；`λ` = 几何/正则权重。

**直觉**：传统世界模型学的是"未来长什么样"，RWM 学的是"从这到那该怎么走"。前者需要在想象的未来里搜索，后者把"怎么走"压进空间形状里——于是规划退化为一次几何连线 + 一次局部映射。

## 3. 带数字走一遍：玩具例子 (Worked Example)

用一个 1D 玩具把"连线即规划"走一遍（数值为合理假设，用于说明闭环，非论文数据）：

```
设定: 一维沿轴移动, 状态 = 位置。目标是让末端从 0 走到 1。

Encoder: z(x) = x           # 玩具里表征就是位置本身, 便于说明
端点: z_start = 0.0,  z_goal = 1.0

path(0.0, 1.0) 给出 N=4 段的 latent 路径:
  z = [0.00, 0.25, 0.50, 0.75, 1.00]

逆动力学 (学到的近似): a_i ≈ (z_{i+1} - z_i) / Δ  # 假设备段 Δ 相同
  a_0 = 0.25, a_1 = 0.25, a_2 = 0.25, a_3 = 0.25
  → 还原出的动作序列 = [0.25, 0.25, 0.25, 0.25]

闭环校验: 从 0 累加动作 → 0.25 → 0.50 → 0.75 → 1.00  ✅ 到达目标

对比"搜索式"规划:
  需要先学动力学 f(z, a) → 预测下一步, 再在动作空间里试/优化 4 步,
  每步可能试多个候选动作 → 调用次数 ≫ 4 次局部 f_inv。

RWM 的成本: 1 次路径构造 + 4 次局部逆动力学 ≈ 线性于路径长度 N。
```

要点：**RWM 的成本主要随"路径步数 N"线性增长**，而搜索式规划的成本随"每步候选数 × 深度"爆炸。这正是它省推理延迟的来源。

## 4. 工程视角 (Engineering View)

| 维度 | 传统世界模型（动力学 + 搜索） | RWM（表征几何规划） | 工程含义 |
|------|------|------|------|
| 推理步数 | 深度 × 每步候选（搜索爆炸） | ~N 次局部逆动力学（线性） | 控制频率上限更友好，易做到实时 |
| 是否需要动力学展开 | 是（递归 rollout） | 否 | 无递归 → 延迟可预测、无误差累积 |
| 是否需要动作空间搜索/优化 | 是 | 否 | 去掉在线优化器 → 部署更轻 |
| 抖动 / 误差累积 | rolloup 越长越漂 | 仅局部映射误差 | 长时程规划理论上更稳，但依赖路径质量 |
| 内存 / 算力瓶颈 | 动力学 + 搜索预算 | 一次路径构造 + 逐段 f_inv | 可按 N 预算延迟 |
| 部署约束 | 搜索耗时难保上界 | 延迟≈线性可估 | 更适合固定控制周期的机器人 |

**关键 trade-off**：省下来的是"在线搜索"的成本，代价是"离线把表征几何训练好"的难度——如果表征几何在分布外崩了，规划出来的路径可能物理不可达，而且这类失败**不会像搜索那样在过程中被代价函数拦住**（因为没有在线评估）。因此 §6 的失败模式要重点关注。

## 6. 能力与失败模式 (Capabilities & Failure Modes)

**能做（摘要支持）**：
- 在连续控制任务上做**直接规划**（无需 rollout / 搜索）。
- 将规划扩展到**机器人操作**这类更复杂的具身控制（作者声称"有潜力"，非强结论）。

**不能做 / 未证明**：
- 未证明可泛化到**移动机器人 / 双臂 / 人形 / 长时程多阶段**任务。
- 未证明对**分布外**目标表征仍能构造物理可达路径。
- 未证明在**高维动作空间 + 真实噪声**下的鲁棒性（仅"潜力"）。

### 6.1 隐含假设 (Hidden Assumptions)

1. **表征空间"内部可导航"**：假设存在一种几何，使得端点之间的路径能对应真实可执行转移——这依赖训练数据覆盖足够的状态-转移流形。
2. **逆动力学是良定义且单值友好的**：同一段表征转移应主要对应一个动作；若真实动力学多模态（同一转移多解），`f_inv` 的反推可能歧义。
3. **端点表征可可靠获得**：目标表征 `z_goal` 假设能由目标状态/图像干净地编码出来，未讨论目标不可观测或歧义时的情形。
4. **局部监督可组合成全局规划**：每段局部正确 ≠ 整条路径全局最优；论文未强调路径是否需要可微的最优性约束。
