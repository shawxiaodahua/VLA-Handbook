## 1. 核心架構/方法總覽 (Overview / Architecture)

### 1.1 系統組件對比概覽 (System Component Comparison)

| 模块 | 骨干/实现 | 输入 | 输出 | 训练信号 | 推理时是否跑 |
|------|-----------|------|------|----------|--------------|
| **Physical Reasoner**（物理推理器） | Qwen3-VL-2B-Instruct（解冻） | 当前观测 o_t、指令 I、物理语言目标 | 语义 token + 语言输出（含 VQA 回答/动作描述） | L_lang（自回归，只算 answer token） | 是（保留语言头） |
| **World Generator**（世界生成器） | Wan2.2-TI2V-5B | 当前观测 latent（保持干净）+ 未来帧 | 未来视觉 latent 的 flow 速度场 | L_v（flow matching，仅未来帧） | 是（可与动作联合去噪） |
| **Action Predictor**（动作预测器） | 连续 flow matching 头 | 动作 chunk + 当前状态 token s_t | 动作 chunk 的连续 flow 场 | L_act（flow matching）+ 物理语言 | 是 |

关键差异点（论文自述）：与 Motus 等 WAM 的**解码层结构相似**，但在**训练配方、数据组成、整体能力**上不同——UniWAM 显式把「推理」也作为一个独立专家并保留语言能力。

### 1.2 關鍵機制 (Key Mechanism)

- **Joint Attention 是黏合剂**：三个专家的 token 投影到公共注意力空间后沿 token 维拼接共同注意力（Eq.2/3），因此动作 token 能同时「看到」语义上下文和演化中的视觉预测。
- **物理语言监督（Physical Language）**：把末端执行器运动编码成自然语言（沿用 LAP 思路），让 VLM 的动作监督对齐它预训练的输入输出分布——**既学具身知识，又不破坏原有语言能力**。
- **互补监督分配**（本论文最核心的工程设计）：
  - VQA 数据 → 只监督 Reasoner（保住预训练世界知识）
  - 人类第一视角数据 → 监督 Reasoner + Generator（利用人类视频的物理知识，但**避开低精度动作标签**）
  - 机器人数据 → 监督全部三者（动作标注最准、与下游后训练物理一致性最高）
- **后训练两招**：future-frame noise augmentation（降低对精确未来预测的依赖）+ history-conditioned flow matching（用历史动作初始化去噪，减少步数）。

⚡ **Eureka Moment**：**不要用同一份监督去训所有专家，也不要让动作监督污染语言能力——把「谁的监督喂给谁」当作一等公民来设计。** 一旦物理语言成为人类与机器人共享的监督目标，两种具身表征就在表征空间里自然对齐了（Figure 8 的 t-SNE 证据）。

## 2. 數學核心 (Math Core)

📌 **Napkin Formula**（一行抓住本质）：
```
联合分布目标:  p_θ( y, o_{t+1:t+h}, a_{t+1:t+h} | o_t, s_t, I )
总损失:        L = w_a · L_act + w_v · L_v + L_lang
```

**目标**：在给定当前观测、本体状态与指令下，联合建模「语言输出 + 未来观测 + 未来动作」的分布。

**联合注意力**（跨模态信息交换）：
```
Q_m = X̃_m^ℓ · W_m^Q ,  K_m = X̃_m^ℓ · W_m^K ,  V_m = X̃_m^ℓ · W_m^V
O   = softmax( (Q·Kᵀ)/√d + M ) · V ,   Q = [Q_v ; Q_a ; Q_u]
```
其中 m ∈ {u, v, a} 表示 understanding / video / action；K、V 按同一顺序拼接；d 是头维度；M 是注意力掩码。

**预训练总损失**（flow matching + 语言）：
```
L_v    = E[ ‖ û_θ^v − (Z_t¹ − Z_t⁰) ‖₂² ]      # 视觉流，仅未来帧
L_act  = E[ ‖ û_θ^a − (A_t¹ − A_t⁰) ‖₂² ]      # 动作流
L_lang = − Σ_{j=1}^{T} log p_θ( y_j | o_t, I, y_{<j} )   # 只算 answer token
L      = w_a · L_act + w_v · L_v + L_lang
```
预训练时视觉源 Z_t¹ 与动作源 A_t¹ 都是**高斯噪声**，生成从 t=1（噪声）走向 t=0（干净）。

**后训练·future-frame noise augmentation**（式 7）：
```
Z̃_t^τv = s_aug · Z_t^τv + (1 − s_aug) · ε_v
s_aug ~ U(0.5, 1) ,   ε_v ~ N(0, I)      # 每样本 50% 概率触发
```

**后训练·history-conditioned flow matching**（式 8/9）：
```
A_t¹ = A_{t−1} + ε_a ,   ε_a ~ N(0, η²I) ,  η = 0.02     # 用历史动作当源，不是噪声
A_t^τ = (1 − τ)·A_t⁰ + τ·A_t¹                            # 干净目标 ↔ 历史源的插值
u_t^a = A_t¹ − A_t⁰                                      # 回归目标：位移向量
```

> 符号与本文保持一致：o_t 观测、s_t 本体状态、I 指令、Z_t 未来视觉 latent、A_t 动作 chunk、τ 归一化噪声水平、η 历史扰动尺度、h 预测时域。

**直觉**：
1. 视觉与动作两条 flow matching 是「两条独立噪声轨 + 一次联合前向」，靠 joint attention 交换信息。
2. 物理语言把连续动作离散成**跨具身共享的语言目标**，是让人类/机器人表征对齐的隐性桥梁。
3. 后训练的两处修改都在动摇「精确未来预测」这一假设——不再依赖它，只把它当作有用但不可靠的上下文。

## 3. 帶數字走一遍：玩具例子 (Worked Example)

设预测时域 h=2、动作维度=2（例如末端位移 (dx, dy)），故一个动作 chunk A ∈ R^{2×2}。

**干净目标（要预测的下一段动作）**：
```
A_t⁰ = [[0.20, 0.05],
        [0.18, 0.00]]
```

**历史动作（最近已经执行的两步）**：
```
A_{t−1} = [[0.25, 0.10],
           [0.22, 0.08]]
```

**构造历史源（式 8）**：采样 ε_a，η=0.02，例如 ε_a = [[0.01,−0.01],[0.00,0.02]]
```
A_t¹ = A_{t−1} + ε_a = [[0.26, 0.09],
                        [0.22, 0.10]]
```

**回归目标 u_t^a（式 9）**：
```
u_t^a = A_t¹ − A_t⁰ = [[0.06, 0.04],
                       [0.04, 0.10]]
```

**插值取中间样本 τ=0.5**（送进网络的输入）：
```
A_t^0.5 = 0.5·A_t⁰ + 0.5·A_t¹ = [[0.23, 0.07],
                                 [0.20, 0.05]]
```

**为什么这比 noise-to-action 好**：源 A_t¹ 已经带着「朝哪动、多快」的先验（它≈历史动作），去噪只需学一个小位移 u_t^a（量级 ~0.1），而不是从一个与目标无关的 N(0,I) 出发。这就是后训练能把去噪步数显著砍掉、性能还不掉的原因（消融：A2A 69.73% vs N2A 64.80%）。

**视觉噪声增强的玩具值**（式 7）：若某样本 s_aug=0.7，ε_v 采样为小噪声：
```
Z̃_t^τv = 0.7 · Z_t^τv + 0.3 · ε_v
```
即未来视觉 latent 被「拉向噪声」，而当前观测 latent 保持干净——动作预测被迫从**模糊的未来**里抽取控制相关语义。

## 6. 能力與失敗模式 (Capabilities & Failure Modes)

**能做**（有明确实验支撑）：
- 在分布内维持高成功率（LIBERO 99.2%、C2C 75.14%）
- 抗扰动与泛化：光照 97.9%、背景 97.6%、语言 92.2%、机器人初始态 89.5%（Table 6）
- 组合指令接地：真实 Diverse-Interaction 上 SR 40.0%→72.5%、IFR 50.0%→80.0%
- 长时域推断中间子目标：仅给「Tidy up the desk.」也能逐步推进（Task Progress 5.0）

**不能/弱**（务必注意）：
- **相机扰动下退化明显**：LIBERO-Plus Camera 仅 92.0%，非最优列
- **噪声扰动 94.3%**：也不是最高列
- 真实世界**只在一个双臂平台**（AgileX Piper）验证，未测移动/人形/跨平台
- 人类数据在**小数据规模下有害**：250 小时量级加人类数据反而掉性能，需 ≥1k 小时才转正
- 长时域只是 6 步里程碑、单一桌面整理场景

### 6.1 隱含假設 (Hidden Assumptions)

1. **物理语言模板足够通用**：假设结构化模板能把任意具身的动作无损编码为语言；跨具身动作空间差异大时是否仍然成立未验证。
2. **动作标注质量是训练核心**：默认机器人数据动作标注「最准」，但多源数据（Bridge/Fractal 等）的标注一致性只靠清洗管线保证，残余噪声影响未量化。
3. **推理时 Generator 存在**：架构默认联合去噪可承受 5B 视频骨干的开销，隐含对算力的强假设。
4. **scaling law 与性能同向**：假设验证 loss 下降 → 真实任务成功率上升；仅在自家数据配比下成立，跨实验室迁移性未知（R²≈0.983 是拟合结果，非因果证明）。
