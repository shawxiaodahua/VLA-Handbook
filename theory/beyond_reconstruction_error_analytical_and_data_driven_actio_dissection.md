## 1. 核心架构/方法总览 (Overview / Architecture)

### 1.1 系统对比概览 (System Component Comparison)

三套 tokenizer 被强制跑在**同一个 tokenization 接口**上：固定 K 个标量 token、相同预算、相同量化、相同 VLA 主干。唯一的自变量是表征基底。

| 模块 | Temporal-DCT | PCA (Karhunen–Loeve) | MLP 自编码器 (AE) |
|------|--------------|---------------------|-------------------|
| 类型 | 固定解析基 | 数据驱动线性基 | 非线性神经表征 |
| 先验假设 | 轨迹沿时间平滑（谐波结构） | 轴间运动存在经验相关性 | 无显式假设，靠网络拟合 |
| 是否跨轴混合 | 否（每通道独立变换） | 是（主成分混合多轴） | 是 |
| 拟合来源 | 无（闭式 DCT-II） | 训练集协方差 SVD | 训练集端到端训练 |
| 结构 | 1D DCT-II，沿 T 维 | 前 K 主成分作 B 的行 | 112→64→14→64→112, GELU |
| 量化 | 对称均匀，V=256（8-bit） | 同左 | 同左 |
| 反量化路径 | 转置投影 B^T c | 转置投影 B^T c | 非线性解码 g(h) |
| 训练/推理差异 | 无参数，无需训练 | 仅需一次性 SVD | 需训练 AE |

关键公平性设定：三者共用同一 VLA 主干 **Qwen3-VL-4B**、同一优化器、同一 rollout 协议、同一 token 预算（K=14）、同一词表（V=256）。DCT 分支显式**不含** FAST 的 BPE 压缩——因此它评的是 FAST 背后的**解析表征阶段**，而非完整 FAST tokenizer。

### 1.2 关键机制 (Key Mechanism)

- **固定解析基 vs 数据驱动基**：PCA 会把你训练集里的轴间相关性吃进来，理论上"更贴合数据"；DCT 只有一条固定假设——轨迹平滑。谁更好？取决于你用什么标准衡量。
- **为什么统一标量 token 接口**：避免 BPE、可学习 codebook 等下游技巧污染结论，把"表征基底"这一变量单独隔离出来。
- **严格无泄漏**：normalizer 只在训练任务（Tasks 0–8）上拟合；标准化用的均值/方差、PCA 协方差、AE 权重全部不看 Task 9。这是 Trick 级的干净设定。
- **三把不同的尺子**：几何保真度（重建 MSE）、序列统计（token 熵 / n-gram 困惑度）、解码器稳定性（扰动增益 G_z），再加上最终闭环成功率。

⚡ **Eureka Moment**：**表征排序会随评估标准翻转**——重建 MSE 给出的名次（AE ≫ PCA ≫ DCT），和控制成功率给出的名次（DCT ≫ AE ≫ PCA）几乎是反的。所以"tokenizer 好不好"根本没有单一答案，你必须先问"用哪把尺子"。

## 2. 数学核心 (Math Core)

📌 **Napkin Formula**（一行抓住本质）：

```
rank_MSE(θ) ≠ rank_success(θ)    ← 重建名次 ≠ 控制名次，这就是全文 THE 结论
```

### 2.1 线性 tokenization（DCT 与 PCA 共用）

目标：用 K 个正交基向量把 112 维动作块压到 K 维，再无损（尽可能）还原。

```
编码:  c = B · ã          其中 ã ∈ R^112 是标准化后的动作块
解码:  â = B^T · c        约束: B·B^T = I_K (行正交)
```

变量说明：

| 符号 | 含义 |
|------|------|
| ã ∈ R^112 | 标准化后的动作块（T=16 × D=7 展平） |
| B ∈ R^{K×M} | 表征基底，K 行正交向量，M=112 |
| c ∈ R^K | 投影系数（量化前） |
| â | 重建动作块 |

- **DCT 基**：沿时间维做独立 1D DCT-II，矩阵元素
  ```
  C_{u,t} = sqrt(2/T) · α_u · cos( π(2t+1)u / (2T) )
  α_0 = 1/√2,  α_u = 1 (u≥1)
  ```
  频率优先分配：K=7m 时，每个通道保留前 m 个频率分量。本文 nominal K=14 → m=2。
- **PCA 基**：对训练集协方差 Σ = E[(ã−ā)(ã−ā)^T] 做 SVD，取特征值最大的前 K 个特征向量作 B 的行。

### 2.2 对称均匀量化

```
z_k = round( (clip(c_k / σ_{c,k}, -5, +5) + 5) · (V-1)/10 )

反量化: ĉ_k = ( z_k · 10/(V-1) - 5 ) · σ_{c,k}
```

- σ_{c,k}：第 k 个系数在训练集上的标准差（per-coefficient 标准化，让不同尺度系数共用同一量化网格）。
- 名义设定 b=8 bit → V=2^8=256。所有上报 MSE 都是在**坐标缩放动作空间**中、**量化之后**测的。

### 2.3 扰动增益 G_z（解码器稳定性的度量）

```
G_z = || â(z + δz) − â(z) ||₂ / ||δz||₂
```

- â(z) = D(Q^{-1}(z))：从离散 token 还原出的动作；线性基时 D = B^T(·)，AE 时 D = g(·)。
- 直觉：**往 token 里塞一点离散噪声，动作会抖多大**。G_z 越大，说明解码器把离散误差放得越狠——这正是重建 MSE 看不见的性质。

> 符号与本文保持一致：M = T×D = 112，T=16，D=7；K = token 预算（nominal 14）；V = 量化等级数。

## 3. 带数字走一遍：玩具例子 (Worked Example)

设一个极简 1 维、4 步动作块（真实是 112 维，这里等比缩小以手算）。

**设定**：ã = [1.0, 0.5, -0.5, -1.0]（一条先升后降的平滑轨迹），token 预算 K=2，量化 V 暂设为"很粗"以放大差异。

**DCT 分支**：DCT-II 把这条平滑轨迹的能量集中到前 2 个低频分量。低频基与轨迹形状高度对齐 → 前 2 个系数就抓住主要结构，反变换后近似 [1.0, 0.45, -0.45, -1.0]，每通道误差分布**均匀且局部**。

**PCA 分支**：在更丰富的数据里，PCA 的第二个主成分可能混入多轴信息（例如"平移 + 旋转"的组合方向）。当这个混合分量被粗量化打偏 δz，反投影 B^T 会把误差**同时撒回多个物理坐标**——单看系数 MSE 也许更小，但物理动作上偏差更分散。

**量化抖动对比**：把某个 token 从 z 改成 z+4（|δz|=4）：

```
线性基 (DCT/PCA):  G_z ≈ 0.0336   → 动作偏移温和
自编码器 (AE)   :  G_z ≈ 0.0431   → 动作偏移 +28% 左右
```

AE 的非线性解码器在瓶颈处梯度更陡，同样的 token 扰动被放大成更大的动作抖动。**结果就是**：AE 的重建 MSE 最低（比 PCA 低 36.7%、比 DCT 低 41.9%），但闭环成功率只有 82.7%，夹在 PCA（80.0%）和 DCT（86.2%）之间，且扰动最敏感。

**闭环后果**（LIBERO-Spatial，三种子平均）：

```
Temporal-DCT : 86.2%   ← 重建更差，控制最好
AE           : 82.7%   ← 重建最好，控制中等
PCA          : 83.2%   ← 重建次好，控制最差
```

## 4. 工程视角 (Engineering View)

| 维度 | 观察 | 工程含义 |
|------|------|----------|
| 静态开销 | DCT 无参数、闭式；PCA 需一次 SVD；AE 需训练 | DCT 零训练成本，适合快速迭代；AE 的收益（重建）不换来控制，投入产出比低 |
| 量化鲁棒性 | 2-bit 极端量化下 DCT 全面胜出；PCA 在 8-bit 名义设定才领先 | 若部署端 token 预算被压到极低精度，倾向 DCT |
| 序列可预测性 | DCT 位置熵低 0.75 bit，困惑度低 12.5–20.7%，teacher-forced loss 3.419 vs 3.513 nats/token | 序列更易预测 = 自回归解码更稳，直接影响采样/推理质量 |
| 解码器稳定性 | AE 扰动增益高 26.5–30.3% | 离散 token 的单点错误会被放大成可见动作抖动 → 闭环抖动/安全风险 |
| 训练成本 | 全套闭环评估 3,500 rollouts = 113.6 H800 GPU-hours | 该研究的"评测成本"本身就说明闭环评估很贵，离线 MSE 才被滥用 |
| 模块边界 | 只换表征基底，其余全冻结 | 说明这是一个**可插拔接口**问题：tokenizer 可以独立评估/替换 |

一句话：**如果把动作 tokenizer 当压缩器优化（追 MSE），你会得到更脆的控制器**。工程上应把"序列熵 / 困惑度"和"扰动增益 G_z"当作和 MSE 平级的验收指标。

## 5. 数据与评测 (Data & Eval)

**动作规格**：chunk horizon T=16，动作维 D=7（3D 平移 + 3D 轴角旋转 + 1D 二值夹爪），展平 M=112。姿态缩放到 [-1,1]，夹爪保持 [0,1]，再 z-score 标准化。

**评测协议**：
- 主干：Qwen3-VL-4B，双 128×128 图像输入，**无 proprioception（本体感知）**。
- 微调：LoRA（r=64, α=128）作用于 attention 投影，AdamW，30k steps。
- 每步预测 K=14 个 token，解码为 T=16 个动作。
- 拟合数据：Tasks 0–8；Task 9 严格排除（offline 诊断里 PCA 是 leave-one-task-out 重拟合，与下游策略协议区分开）。
- 闭环：每任务/种子 50 个配对初始状态，7 次运行 = **3,500 rollouts**；宏平均成功率用 20,000 次 paired bootstrap 估计不确定性。

**离线诊断维度**：20 个 rate–distortion 区间（K∈{7,14,21,28} × 多种量化精度）、跨任务 leave-one-out、跨数据集零样本迁移（LIBERO-Object / LIBERO-Goal）、token 熵与 n-gram 困惑度（Lidstone 平滑，不同 episode split）。

**关键数字**（来源：论文 Table 1–4）：
- 名义设定（K=14, 8-bit）：PCA 重建 MSE 比 DCT 低 **8.3%**（0.0083 vs 0.0091），20 个配置中 PCA 赢 14 个。
- 2-bit 量化：DCT 在所有 token 预算下都更好（结构性解释：DCT 保通道谐波结构，PCA 粗误差经反投影扩散到多坐标）。
- 跨任务 leave-one-out：PCA 赢 6/10，宏平均 MSE 降 6.2%。
- 跨数据集 LIBERO-Goal：K∈{7,14} 时 DCT 低 22.9–42.2%；K∈{21,28} 时 PCA 夺回优势，K=28 时最高改善 28.3%。
- 闭环（三种子平均）：DCT 86.2% vs PCA 83.2%，差 **3.0 pp**；seed 42/43 DCT 领先 6.2/5.3 pp（PCA−DCT 的 95% CI 分别为 [-10.7,-1.8]、[-9.3,-1.3]），**seed 44 反序**（PCA +2.7 pp，CI [-1.8,+7.1] 含 0）。
- Task 9（held-out）：两种 tokenizer 全部 0/50，无法做跨任务结论。

## 6. 能力与失败模式 (Capabilities & Failure Modes)

**能做什么**
- 干净地隔离"表征基底"这一单一变量，给出跨三把尺子的横向名次。
- 提供可复用的诊断工具：token 熵 / 困惑度（序列可预测性）、扰动增益 G_z（解码器稳定性）。
- 揭示**非单调**的 rate–distortion ↔ 控制关系，这是选型时最容易踩的坑。

**不能做什么 / 何时失败**
- 只在桌面操作基准 LIBERO-Spatial 上验证 → 不能外推到移动、双臂、人形或形态多样性场景。
- 闭环只有 3 个策略训练种子，且 1 个序反 → 3.0 pp 的均值差只能当**描述性**观察，不是推断性结论。
- Task 9 全员 0/50 的地板效应 → held-out 泛化完全测不出。
- AE 是"重建导向"基线，**不是**量化感知的学习式 tokenizer；因此"神经表征不行"这一结论不能扣到 FASTer / MoEActok 这类可学习 codebook 头上（作者自己声明了这点）。
- 扰动增益是**局部**度量，不等于因果影响。

### 6.1 隐含假设 (Hidden Assumptions)

- **假设 LIBERO-Spatial 的结论代表"自回归 VLA 动作 tokenization"的一般规律**——但只测了一个主干、一个基准。
- **假设固定 K=14 的标量 token 接口能公平代表三类表征**——AE 被塞进 14 维连续瓶颈，可能对非线性表征不公平（它本可配更大瓶颈）。
- **假设"无 proprioception + 双 128×128 图像"是中性设定**——但视觉分辨率/无本体感知可能系统性改变不同 tokenizer 的敏感度。
- **假设 token 扰动 δz 的均匀采样能代表真实策略的预测误差分布**——真实自回归错误可能不是均匀的。
- **假设单一随机种子反转只是"优化噪声"**——也可能暗示差异本身就在噪声量级内（作者自认样本不足）。

- **建議章節路徑**：先读 §1（框架与三族表征）→ 再看 §2.2/§2.3（DCT/PCA/AE 怎么建、怎么量化）→ 重点 §3.3（序列可预测性）+ §4.3（扰动增益与 AE 反例）→ 最后 §4.2（闭环数字与种子敏感度）→ 可跳 §3.2 的跨数据集细节（除非你做迁移）。

- **不值得精讀的理由**：如果你不做离散动作 tokenization（例如用 diffusion / 连续回归）、或已熟悉"重建≠下游性能"的普遍教训，读摘要 + §1.2 的 Eureka Moment 就够了。这篇的价值在**结论的方向性与诊断指标**，不在新架构。
