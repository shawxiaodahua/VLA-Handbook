对抗补丁就像贴在摄像头前的一张小贴纸，能让机器人操作策略突然「看错」而失控。这篇论文不问「补丁长什么样」，而是问「补丁在模型脑子里点亮了哪个神经元」。他们用稀疏自编码器找到一个"补丁探测器"特征，然后训练一个小探针在旁边盯着——只有当探针喊「有攻击！」时，才把这个特征从表征里减掉。结果是：间歇攻击下存活率上升，而如果一直减（不管有没有攻击），机器人反而变笨。

## 1. 核心架構/方法總覽 (Overview / Architecture)

整体是一条「训练期选特征 + 推理期检测+干预」的两阶段流水线。VLA 策略参数**全程冻结**，不微调、不改输入图像。

### 1.1 系统对比概览 (System Component Comparison)

| 组件 | 输入 | 输出 | 训练/推理 | 关键设置 |
|------|------|------|-----------|----------|
| TopK SAE | 残差流表征（token 均值池化）| 稀疏特征激活 z | 训练期（每条候选层各训一个）| 1× 扩张；K=12(π0.5) / K=6(SmolVLA)；6,677 步；仅用干净轨迹 |
| 攻击相关特征选择 | 补丁开/关的开环 rollout | 选中层-特征对 (ℓ*, j*) | 训练期（10 条开发 rollout）| 逐 rollout 算 Pearson 相关，取 >0.6 出现最多者 |
| 线性探针 | 层 k (k ≤ ℓ*) 的 token 均值池化表征 | 攻击概率 p_t | 训练期（100 对 rollout，60/20/20 划分）| 逻辑回归；阈值 τ 使 FPR ≤ 2% |
| 条件式干预 | 探针门控 g_t + 选中特征激活 | 修改后的前缀 token 表征 | 推理期（零参数更新）| 干预强度 λ；仅 g_t=1 时施加 |
| VLA 策略 | 观测 o_t + 语言 l | 动作 a_t | 冻结，不参与防御训练 | π0.5（仅 agent 相机）/ SmolVLA（agent+wrist 相机）|

### 1.2 关键机制 (Key Mechanism)

- **为什么用 SAE 而不是直接看注意力 / 梯度**：SAE 把稠密的多义表征分解成稀疏、单义的「特征」，这样「补丁存在」就能对应到少数几个可命名的维度，便于定位和干预。
- **为什么要「条件式」而非「一直抑制」**：作者用补丁开/关的 rollout 证明，被选特征在**干净观测下也会激活**。若一直减，名义任务性能会崩（π0.5 名义 SR 从 54.4% 掉到 35.2%）。所以必须让探针来决定「何时减」。
- **为什么探针层要早于干预层 (k ≤ ℓ*)**：只有当检测结果在干预发生前就可用，才能避免时序倒挂——检测必须在更浅的层完成。

⚡ **Eureka Moment**：**对抗攻击在 VLA 内部留下了可被稀疏特征「点名」的指纹；因此防御可以退化为一道「检测门 + 一次向量减法」，完全绕开昂贵的对抗微调。**

### 1.3 信息流/架構圖 (Flow / Diagram)

```
推理时刻 t:
 观测 o_t ──► VLA 前向（冻结）
                │
   层 k (浅层) ─┼──► token 均值池化 h̄_t^(k) ──► 线性探针 ──► p_t = σ(wᵀh̄ + b)
                │                                        │
                │                              g_t = I[p_t > τ]  (detect gate)
                │                                        │
   层 ℓ* ──────┼──► 对每个前缀 token r:
                │      h̃_{t,r}^(ℓ*) = h_{t,r}^(ℓ*) − g_t · λ · z_{t,j*}^(ℓ*) · d_{j*}^(ℓ*)
                │                └────── suppress（仅当 g_t=1）──────┘
                ▼
          后续层 ──► 动作 a_t = π(o_t, l)
```

## 2. 數學核心 (Math Core)

📌 **Napkin Formula**（一行抓住本质）：

```
h̃_{t,r}^(ℓ*) = h_{t,r}^(ℓ*) − g_t · λ · z_{t,j*}^(ℓ*) · d_{j*}^(ℓ*)
```

**目标**：在推理期改善攻击下的任务成功率，同时尽量不损伤干净观测下的性能。

**三个公式块（依时间顺序）**：

```
(1) SAE 特征提取（先均值池化前缀 token，再编码）
    h̄_t^(i) = (1/N_t) · Σ_{r=1}^{N_t} h_{t,r}^(i)
    z_t^(i)  = E^(i)( h̄_t^(i) )

(2) 攻击检测（浅层 k ≤ ℓ*）
    p_t = σ( wᵀ h̄_t^(k) + b )            # σ = sigmoid
    g_t = I[ p_t > τ ]                     # I = 指示函数, τ = 阈值

(3) 条件式抑制（对层 ℓ* 的每个前缀 token r）
    h̃_{t,r}^(ℓ*) = h_{t,r}^(ℓ*) − g_t · λ · z_{t,j*}^(ℓ*) · d_{j*}^(ℓ*)
```

**变量说明**：

| 符号 | 含义 |
|------|------|
| h_{t,r}^(i) | 第 i 层、第 r 个前缀 token、控制步 t 的表征向量（d 维）|
| N_t | 前缀 token 数 |
| h̄_t^(i) | token 均值池化后的表征 |
| E^(i)(·) | 第 i 层 SAE 编码器；z_t^(i) 为稀疏激活 |
| (ℓ*, j*) | 选中的层-特征对（干预目标）|
| d_{j*}^(ℓ*) | 该特征的 SAE 解码方向（ℝ^d）|
| z_{t,j*}^(ℓ*) | 该特征在 t 步的激活值 |
| w, b | 线性探针参数 |
| τ | 检测阈值（令 FPR ≤ 2%）|
| g_t | 检测门控 ∈ {0,1} |
| λ | 干预强度 |

**直觉**：把表征想象成一组正交的「语义旋钮」。SAE 找到了那个名叫「有补丁」的旋钮；z·d 就是这个旋钮当前贡献给表征的向量。抑制 = 沿该方向把贡献减掉。

- λ = 1：完全移除该特征贡献；
- 0 < λ < 1：部分衰减（实验中最佳在 0.2–0.3 区间）；
- λ > 1：不仅移除，还朝反方向「推过头」，即过冲 steer。

> 符号与本文/相关文档保持一致：向量加粗/箭头统一用 h̃ 表示干预后表征；g_t 为布尔门控，乘法遵循广播到每个前缀 token。

## 3. 帶數字走一遍：玩具例子 (Worked Example)

以 π0.5、间歇攻击 n = 10 为例走一个控制步。

**假设**：某步 t，探针输出 p_t = 0.87，阈值 τ = 0.30，λ = 0.20；SAE 选中特征激活 z_{t,j*} = 1.5；解码方向 d_{j*} 为某单位方向向量（为简化，只考虑该方向标量分量）。

```
第 1 步：检测
  p_t = 0.87 > τ = 0.30  →  g_t = 1        # 攻擎被检出

第 2 步：计算抑制量
  suppress = g_t · λ · z_{t,j*} = 1 · 0.20 · 1.5 = 0.30

第 3 步：修改表征（沿 d_{j*} 方向）
  h̃ = h − 0.30 · d_{j*}

若某前缀 token 沿该方向的原分量为 h·d = 0.80：
  修改后 = 0.80 − 0.30 = 0.50   # 补丁相关成分被衰减约 37.5%
```

**反向对照（干净观测）**：若这一步没有补丁，探针 p_t = 0.05 ≤ τ，则 g_t = 0，suppress = 0，表征**原样保留**——这正是「条件式」相对「持续抑制」的核心优势。

**为什么 λ 不能大**：若把 λ 设为 1（完全移除），在干净帧上探针偶尔误报（FPR 0.39%–0.71%）也会触发全额抑制，累积起来就让名义性能滑坡。实验里 π0.5 名义 SR 从 54.4% 掉到 35.2% 就是 λ=1 持续干预的代价。

**闭环数字核对（论文 Table 2，π0.5, n=10）**：

```
Baseline(无干预)        SR = 26.0%
w/o Det.(持续抑制)      SR 更低（掉点）
本文(条件抑制)          SR = 32.4%   ← 主结果，+6.4 个点
w/ Oracle Det.(完美检测) SR ≈ 本文水平
```

## 4. 工程視角 (Engineering View)

| 维度 | 情况 | 工程含义 |
|------|------|----------|
| 推理开销 | 一次线性探针（2048 维点积）+ 一次向量减 | 相对一次 VLA 前向可忽略；可在控制回路的每步叠加 |
| 参数更新 | 无 | 无需对抗微调（对比 Xu et al. 需重训视觉编码器），部署成本低 |
| 前置成本 | 每模型需训 SAE + 选特征 + 训探针 | 一次性离线成本；换模型/换机器人需重做 |
| 控制频率 | 干预为逐控制步在线操作 | 不改变策略本身的动作输出频率，只改内部表征 |
| 时延约束 | 探针层 k 必须在干预层 ℓ* 之前 | 架构上强制「先检测后干预」，避免超出单步预算 |
| 敏感性 | λ ∈ {0.25,0.5,1,2,4}，最佳 0.2–0.3 | 强干预会把表征推过头；需在开发集上单独调 |
| 误报影响 | FPR ≤ 2% 门限 | 误报 = 在干净帧上错误减特征 → 直接掉点，故阈值不可放松 |

**关键 trade-off**：**鲁棒性 vs 名义性能**。λ 越大越抗攻击，但名义性能越差；最优 λ 随攻击强度变化（n=3 用 0.3，n=10 用 0.2）。这是一条需要在开发集上显式调参的细线。

**部署约束直觉**：本方法是「推理期补丁」，天然契合已冻结、已量化的生产策略——不需要动权重，可插拔。但它假设你能拿到中间层表征（白盒）；对只暴露 API 的黑盒策略不适用。

| 夹爪探针 | FPR 9.45%，对白/黑/噪声检出 16%–23% | 不同补丁训练出的探针特异性差异大 |

### 6.1 隱含假設 (Hidden Assumptions)

- **白盒访问**：假设防御者能读取 VLA 中间层表征（残差流）；黑盒 API 场景不适用。
- **已知攻击族**：SAE 特征与探针都在**干净轨迹 + 特定补丁**上选取/训练；对未见攻击类型的迁移性未被验证（作者明确列为未来工作）。
- **仿真 → 物理可迁移性**：全部实验在 LIBERO-10 仿真；作者自承需在真实机器人上测试。
- **单一 DoF 攻击**：主攻击只针对 DoF 1；更复杂的多自由度/多部位攻击未覆盖。
- **补丁在时间上可分段检测**：方法依赖「补丁间歇可见」这一前提；持续可见时失效。
