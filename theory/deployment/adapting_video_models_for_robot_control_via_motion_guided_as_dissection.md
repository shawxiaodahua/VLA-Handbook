## 1. 核心架构 / 方法总览 (Overview / Architecture)

### 1.1 系统对比概览

| 模块 | 输入 | 输出 | 时序/频率约定 | 训练 vs 推理差异 |
|---|---|---|---|---|
| 共享视频扩散骨干（Cosmos3-Nano 或 Wan2.2-5B） | 含噪潜在 z_t^τ、含噪动作 a_t^{τ_a}、当前观测 o_t、指令 c、本体状态 q_t | 视觉速度 û_v、动作速度 û_a | Cosmos3 单次前向生成 16 个动作 + 8 个未来视频帧，步长 2；Fast-WAM 不改输入/输出帧与时域，执行用 12 个动作 | 训练：标准路径 + MoGAP 辅助路径 |
| 标准 WAM 损失（L_video, L_action） | 未来潜在 z_t、动作块 a_{t:t+H} | 流匹配速度回归 | 每训练步 | 仅训练（作为训练目标） |
| MoGAP 辅助路径 | 非对称噪声 z_t^{τ_M}、运动掩码 M | L_MoGAP | 每训练步 | **仅训练**；推理时 MoGAP token 省略（图 4） |

说明：Fast-WAM 的骨干是 Wan2.2-5B 视频扩散 + **单独参数化的动作专家**，且推理时**不预测未来视觉**（论文 §3.2、§B.2）；Cosmos3-Nano 是 16B 参数、单骨干联合视觉-动作预测。两者是不同架构，MoGAP 在两组上分别验证，收益分别报告（38.8→47.5 与 52.3→62.3），不可混为一组属性。

### 1.2 关键机制

1. **运动分数引导**：用视频潜在的时间差分 m_{n,p} = ||z_{t,n,p} − z_{t,n−1,p}||₂ 作为"动态 vs 静态"的指示信号，不需要光流外挂、深度或外部教师（§2.2）。
2. **非对称噪声分配**：动态 token 用更高的扩散时间步 τ_v⁺ = τ_v + (1−τ_v)·ξ（ξ 从 τ_v 的采样分布独立抽取并缩放到 [τ_v,1]），静态 token 保持 τ_v。意义：动态区域损坏更重，静态区域保留更多信息作为场景上下文（§2.3）。
3. **二值掩码** M_{n,p} = 1[m_{n,p} > m̄_n]，阈值是每个时间切片的**空间均值**；此阈值只决定"哪些 token 进高噪声组"，不改变 τ_v 本身。
4. **仅训练辅助路径 + 非对称注意力掩码**：MoGAP token 可注意自身、当前观测与含噪动作表示（单向；原始 WAM token 不能反向注意 MoGAP token），但**不能**看主路径的含噪未来视觉 token；主路径（含噪视觉 + 动作）**不能**看 MoGAP token（图 4）。推理时整组 MoGAP token 被丢弃。
5. **损失归一化**：L_MoGAP 只对动态 token 求和，并按每个时间切片的动态 token 数 |S_n| 归一化，避免"动态比例"改变总损失权重（式 2.11）。

⚡ **Eureka Moment**：视频预训练的"全图重建"不是控制最需要的监督信号；把**信息预算从静态纹理挪到动态交互**，用一个"重损坏动态 + 轻损坏静态做上下文"的非对称任务，就能让预训练视频表征更贴控制。

### 1.3 信息流 / 架构图

```
                    ┌────────────────────────────────────────────┐
 训练时              │  共享视频扩散骨干 f_θ（无新增参数）        │
 o_t, c, q_t ──────►│                                            │
                    │  路径 A：标准 WAM                            │
```

## 2. 数学核心 (Math Core)

📌 **Napkin Formula**（一行抓住本质）：

```
L = L_video + λ_a·L_action + λ_MoGAP·E[动态 token 上的流匹配误差]
   动态 token 被加更多噪声，静态 token 保持原噪声当上下文
```

先给目标：训练一个世界-动作模型，在**共享视频扩散骨干**上同时学好未来视觉和动作；再给结构方程；最后给直觉。

**① WAM 的联合分布**（论文式 2.1）：

```
p_θ(o_{t+1:t+H+1}, a_{t:t+H} | o_t, c, q_t)
```

**② 流匹配加噪**（式 2.2）：

```
z_t^{τ_v} = (1 − τ_v)·z_t + τ_v·ε_v
a_t^{τ_a} = (1 − τ_a)·a_{t:t+H} + τ_a·ε_a
ε_v, ε_a ~ N(0, I)  独立采样
```

**③ 标准 WAM 损失**（式 2.3–2.5）：

```
L_video  = E[ ||û_v − (ε_v − z_t)||² ]
L_action = E[ ||û_a − (ε_a − a_{t:t+H})||² ]
L        = L_video + λ_a·L_action
```

**④ 动机研究：运动分数与重分配权重**（式 2.6–2.7）：

```
m_{n,p}   = ||z_{t,n,p} − z_{t,n−1,p}||₂
m̃_{n,p}  = m_{n,p} / ( (1/P)·Σ_q m_{n,q} )
w_{n,p}   = (ε + m̃_{n,p}^β) / ( (1/P)·Σ_q (ε + m̃_{n,q}^β) )
L'_video  = E[ (1/(N·P))·Σ_n Σ_p w_{n,p}·L_video^{n,p} ]
```

**⑤ MoGAP 的非对称加噪**（式 2.8–2.10）：

```
ξ ~ T_v（视频时间步采样分布），缩放到 [τ_v, 1]
τ_v⁺       = τ_v + (1 − τ_v)·ξ
M_{n,p}    = 1[ m_{n,p} > m̄_n ]                  # 阈值 = 空间均值
τ_{n,p}    = τ_v⁺  若 M_{n,p}=1；否则 τ_v
z_t^{τ_M}  = diag(1 − τ_M)·z_t + diag(τ_M)·ε'_v  # ε'_v 与 ε_v 独立
```

**⑥ MoGAP 损失**（式 2.11）：

```
S_n = { p | M_{n,p}=1 }，掩码为空时全选
L_MoGAP = E[ (1/N)·Σ_n (1/|S_n|)·Σ_{p∈S_n} ||û_v,n,p^{τ_M} − (ε'_{v,n,p} − z_{t,n,p})||² ]
```

**⑦ 总损失**（式 2.12）：

```
L = L_video + λ_a·L_action + λ_MoGAP·L_MoGAP
```

**符号与本文来源保持一致**：n 遍历未来潜在时间切片（共 N 个），p 遍历空间 latent 位置（共 P 个）；τ_v 是基础视觉扩散时间步；λ_MoGAP = 1.0（§3.1、§B.5）；动机研究的 β = 2（§B.5）。

**直觉**：扩散时间步越高，潜在里保留的干净信息越少——可以把这理解为"部分掩码"（Chen et al. 2024）。把动态 token 推到 τ_v⁺、静态 token 留在 τ_v，等于让模型**在更少动态线索 + 更多静态上下文**的条件下学习预测动态，从而强迫表征聚焦控制相关区域。

## 3. 带数字走一遍：玩具例子 (Worked Example)

> ⚠️ 以下数值是**假设的玩具例子**，用于走通公式结构，不代表论文任意实验的真实数值。所有步骤逐一验算。

**设定**：一个 2×2 潜在网格（P=4），单一未来时间切片（N=1）。运动分数假设为：

```
m = [[1.0, 0.2],
     [0.3, 2.0]]
```

空间均值 m̄ = (1.0+0.2+0.3+2.0)/4 = 0.875。
二值掩码（阈值 = 均值）：

```
M = [[1, 0],
     [0, 1]]   # 左上、右下为动态 token
```

**动机研究权重**（式 2.6，β=2，ε=0）：
m̃ = m/0.875 = [[1.143, 0.229], [0.343, 2.286]]；m̃² 总和 = 1.306+0.052+0.118+5.224 = 6.700；分母 = 6.700/4 = 1.675。

```
w = m̃²/1.675 = [[0.780, 0.031],
                [0.070, 3.119]]
均值 = (0.780+0.031+0.070+3.119)/4 ≈ 1.000   ✓（按定义归一化到 1）
```

动态两个 token 拿走 0.780+3.119 = 3.899，占总权重 97.5%；静态两个只拿 0.101。

**MoGAP 非对称加噪**：设基础 τ_v = 0.4，ξ = 0.7 → τ_v⁺ = 0.4 + (1−0.4)×0.7 = 0.82。动态 token 用 0.82，静态 token 用 0.40。设干净潜在 z 全为 0.5，独立噪声 ε' 为：

```
ε' = [[0.10, −0.20],
      [0.30,  0.05]]
```

**非对称含噪输入** z_t^{τ_M} = (1−τ_{n,p})·z + τ_{n,p}·ε'：

```
(0,0) 动态：0.18×0.5 + 0.82×0.10 = 0.172
(0,1) 静态：0.60×0.5 + 0.40×(−0.20) = 0.22
(1,0) 静态：0.60×0.5 + 0.40×0.30  = 0.42
(1,1) 动态：0.18×0.5 + 0.82×0.05 = 0.131
```

**回归目标** ε' − z：

```
(0,0)：0.10 − 0.50 = −0.40
(0,1)：−0.20 − 0.50 = −0.70
(1,0)：0.30 − 0.50 = −0.20
(1,1)：0.05 − 0.50 = −0.45
```

**损失归一化**：S_n = {(0,0), (1,1)}，|S_n| = 2。完美模型时 L_MoGAP = 0。若用"预测值全 0"作对照，则 L_MoGAP = (1/1)×(1/2)×((0−(−0.40))² + (0−(−0.45))²) = 0.5×0.3625 = 0.181。对照：若把静态两个 token 也算进去，损失和为 (0.49 + 0.04)/2 = 0.265——这就是为什么**只对动态 token 求损失**能避免静态区域主导梯度。

**验算小结**：非对称加噪后动态 token 的输入更接近噪声（0.172、0.131），静态 token 仍保留结构（0.22、0.42）；损失只在动态 token 上计算，并按 |S_n| 归一化，使总损失权重与"动态 token 比例"解耦。

## 6. 能力与失败模式 (Capabilities & Failure Modes)

**能做什么**

1. 在 GR-1 Tabletop 上把 Cosmos3 基线的 24 任务平均成功率从 52.3% 提到 62.3%（+10.0 pp），并在 PnP（48.3→60.8）和 Articulated（64.3→66.7）两个任务组上均提升（Table 1）。
2. **无需外部教师**即超过使用 DINOv2、VGGT、VideoMAEv2、V-JEPA2.1-L 做表征对齐的方法（Table 2：MoGAP 62.3 vs 最好的 VideoREPA 59.2）。
3. 在两条不同 WAM 架构上都有效（Cosmos3-Nano、Fast-WAM），说明不是单一骨干的偶然现象（Table 3b）。
4. 多视角下可适配：手腕相机因相机自身运动主导潜在差分，作者把所有手腕 token 直接归入高噪声组（§3.2），这一手工补丁本身说明运动分数不是万能的。
5. 真实机器人上对执行中的目标物移位（训练集未见此类演示）表现出更好的重规划能力（Figure 7、Figure 6）。

**不能/不够做什么（论文实测或作者明确说明）**

1. **训练开销**：MoGAP 增加 1.26× 训练时间（14.7 h→18.5 h，4×H200）；作者在 Limitations 中承认这是主要代价。
2. **辅助路径不可省**：消融显示"用 MoGAP 替换主视觉监督"只有 54.4%，完整辅助路径 62.3%；去掉非对称性 55.3%，方向反向 55.2%（Table 3a）。两侧监督信号是互补的，但机制解释仍是定性的。
3. **真实机器人规模有限**：单一 16B 骨干、单一数据集、168 次试验；未见跨机器人、跨形态系统评测。
4. **运动分数的边界**：Table 4a 的 AUROC 显示运动分数能高亮移动手臂/手（0.887）与被操作物体（0.834），并相对抑制背景（0.430，低于随机 0.5 说明背景评分相对更低）。但 AUROC 只说明"排序能力"，不说明快速镜头运动、遮挡、静止任务下的可靠性——手腕视角需要手工置为高噪声，就是反例。
5. **未给代码仓库**：来源记录中 repo_url 为空，本次不作仓库推断；如需复现需联系作者或等官方发布。

### 6.1 隐含假设 (Hidden Assumptions)

> 以下是**我的条件性分析**，不是论文原文明确主张。

1. **潜在时间差分 ≈ 控制相关动态**。这忽略了"视觉变化小但控制关键"的区域：例如接近抓取点时的微小形变、液体/布料/可变形物体在低对比度下的动态。运动分数用阈值 m̄_n 二值化后，这类区域会被划入静态组、只作为上下文。
2. **静态区域是安全上下文**。低噪声静态 token 作为上下文，前提是静态区域不含误导信息；杂乱桌面、反光、阴影、静态干扰物可能被误当上下文。
3. **相机运动 = 场景运动**。动态评分基于潜在差分，不区分"机器人运动"与"相机自身运动"；在 RoboCasa-Kitchen 多视角仿真中，手腕相机视角因相机自身运动主导潜在差分而被整体归入高噪声组；真实机器人 OpenArm 仅用左目 egocentric 视角、无手腕相机，因此该手工补丁不能直接说明真实机器人设置下的失效。
4. **辅助路径与主损失互补**。消融证实两者都要保留，但"为什么互补"（全噪声范围监督 + 非对称监督提供不同信号）只有定性解释，缺少对外部复现的检验。
5. **每个时间切片独立归一化**。式 2.11 按 |S_n| 归一化，假设动态 token 比例在切片间不应改变总权重；但不同切片动态比例可能差异很大，归一化是否引入方差未被系统测试。

**差异分析**

- 与 Diffusion Forcing（Chen et al. 2024）和 Self-supervised Flow Matching（Chefer et al. 2026）的关系：MoGAP 借用了"扩散噪声 = 部分掩码"和 token 级噪声分配的思想，但把它**用于控制相关的空间重分配**，而不是通用的视频自监督。
- 与教师对齐方法（AGRA、VideoREPA、Geometry Forcing、TSA）的关系：那些方法引入外部表征或几何教师；MoGAP 不引入任何外部模型，只在原生潜在空间内重分配监督。
- 与 Fast-WAM 的关系：Fast-WAM 推理时省略未来视觉；MoGAP 作为训练时辅助路径，与"推理时不生成未来视觉"不冲突，因此能叠加（Table 3b）。

**面试 Tip**：被问"WAM 如何把视频预测和动作训练对齐"时，一句话答——不换骨干、不加教师，用运动分数给动态/静态 token 做**非对称噪声分配**，让动态 token 在更高损坏下从静态上下文里预测，从而把预训练视频表征往控制相关区域拉。

## 8. 精读建议 (Reading Guide)

- **值得精读原文的人**：
  1. 做视频扩散骨干 VLA / World Action Model 的研究者，关心"视觉预测目标如何影响动作学习"。
  2. 想在现有训练流水线上加一个**无外部教师、推理零开销**自监督辅助任务的工程团队。
  3. 正在评估把某个视频扩散骨干迁移到新机器人平台可行性的工程师，需要看清"哪些设置换骨干/换具身还能成立"。
- **建议章节路径**：先读 §2.2（动机研究，理解为什么空间重分配有效）→ 再读 §2.3（非对称预测的构造与注意力掩码）→ 然后 §3.2 与 Table 1/2/3（条件化读结果）→ §3.3 与 Figure 6/7（真实机器人）→ 可跳 §4 相关工作（若已熟悉 WAM 谱系）。
- **不值得精读的理由**：如果你不做机器人学习、或只做 LLM 骨干 VLA、或已经熟悉 Diffusion Forcing 的非对称 token 加噪思路，读摘要 + 表 1/2/3 即可；核心增量是"把非对称加噪用于空间上按运动分数分组"，不是新架构。
