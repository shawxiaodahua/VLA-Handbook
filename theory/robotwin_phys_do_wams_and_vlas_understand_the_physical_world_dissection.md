## 1. 核心架构/方法总览 (Overview / Architecture)

RoboTwin-Phys 本身**不是新模型**，而是一个 benchmark + 数据集 + 评测协议的组合。它构建在 RoboTwin-2.0 的 50 任务双臂平台之上，不新增任务，只增加「物理变化」这一独立维度。

### 1.1 系统对比概览 (System Component Comparison)

| 组件 | 输入 | 输出 | 时序/频率 | 训练 vs 推理 |
|------|------|------|-----------|--------------|
| 物理采样器 (Sampler) | episode seed | 13 维物理参数向量 | 每 episode 初始化时采样一次，episode 内冻结 | 两者共用 |
| 任务路由 (Task-Aware Router) | 任务名 + 全局配置 | 全局域 或 专用域 | 环境构建时静态决定 | 两者共用 |
| 可行性过滤器 (Feasibility Gate) | 采样条件 + 专家规划器 | 保留/剔除该 instance | 离线预先执行 | 仅数据生成/评测池构建 |
| 专家演示管线 | 可行物理条件 | HDF5 轨迹 + MP4 + phys_meta | 离线批处理 | 仅训练集 |
| 评测协议 | 模型 + 三档环境 | 成功率 (%) | 每任务 100 次 rollout | 仅推理 |
| 物理真值标注 | 采样参数 | 13 维 ground-truth JSON | 每 episode 一份 | 仅监督信号 |

三档评测环境（这是理解全文的关键）：

| 环境协议 | 视觉/布局随机 | 物理参数 | 用途 |
|----------|--------------|----------|------|
| Clean | 关闭 | 名义值 | 名义基线 |
| Official Random | 开启 | 名义值 | 传统泛化基线 |
| Physical Random | 开启 | 13 维连续采样 | 本文主张的新维度 |

### 1.2 关键机制 (Key Mechanism)

- **独立维度设计**：物理采样与视觉/布局随机**正交**，因此可以单独开、单独关、或同时开，从而把「物理鲁棒性」从「视觉鲁棒性」里剥离出来。
- **任务感知物理有效性 (Task-Aware Physical Validity)**：单一全局范围会造出「数值合法但任务不合理」的配置。例：beat_block_hammer 的锤子很细，若套用全局质心偏移域 (−1.5, 1.5) cm，质心可能跑到锤体之外。因此 9 个物理敏感任务使用专用域。
- **可行性闸门**：采样条件必须通过**专家规划器**预先验证能完成任务，否则剔除。保证「失败 = 模型不行」，而不是「该条件下根本无解」。
- **连续 vs 离散**：物理因子在物理合理区间内**连续采样**，而非挑几个离散案例，避免人工挑样本引入偏差。
- **物理真值可监督**：每条演示附带 13 维 ground-truth，把隐藏的仿真状态变成显式学习目标。

⚡ **Eureka Moment**：把「物理参数」从仿真器的隐藏常量变成 benchmark 的**一等评测变量**，并用物理真值把「失败」变成可归因、可监督的学习信号——行不行，一次说清。

## 2. 数学核心 (Math Core)

📌 **Napkin Formula**（一行抓住本质）：

```
鲁棒性缺口 Δ_phys = SR(Official Random) − SR(Physical Random)   ≫   Δ_vis = SR(Clean) − SR(Official Random)
```

**目标**：量化「物理条件多样性」是否构成一个独立于视觉/布局随机的失败维度。

**核心量**：

```
物理条件向量     θ = (θ_1, ..., θ_13),  θ_k ~ U(low_k(task), high_k(task))
每 episode 固定  θ_t = θ_0  for all t in [0, T]
成功率           SR = (1/N) · Σ_{i=1}^{N} 1[task_i 成功]
物理鲁棒缺口      Δ_phys = SR_vis − SR_phys
判定准则          Δ_phys ≫ Δ_vis  ⟹  物理多样性是一个独立维度
```

**变量说明**：

| 符号 | 含义 |
|------|------|
| θ_k | 第 k 个物理属性（质量、摩擦、阻尼……） |
| low_k/high_k | 任务相关采样下界/上界（全局或专用域） |
| θ_t | t 时刻生效的物理条件（episode 内为常数） |
| SR | 成功率，每任务 100 次 rollout 的平均 |
| Δ_phys / Δ_vis | 物理缺口 / 视觉缺口 |

**直觉**：如果模型真的「理解物理」，改物理参数不该比改外观更致命。实验显示 Δ_phys 远大于 Δ_vis，说明现有模型更多是在拟合视觉相关性，而非内化接触动力学。

> 符号与本文保持一致：θ 表示物理条件向量，SR 为成功率。原文含大量 LaTeX 上下标，此处已改为纯文本/代码块表达。

## 3. 带数字走一遍：玩具例子 (Worked Example)

用 Fast-WAM 的公开数字走一遍（Clean 绝对值需从原文 Table 1 取，这里放**明示的假设值**以演示闭式计算）：

```
假设（演示用，非原文）: SR_clean = 60.00 %

已知差量（原文 §4.2）:
  Δ_vis  = SR_clean − SR_official       = 0.10 点
  ⟹  SR_official ≈ 60.00 − 0.10         = 59.90 %

  SR_phys = 44.24 %  (原文 Table 1)

物理缺口:
  Δ_phys = 59.90 − 44.24 = 15.66 点
  相对跌幅 = 15.66 / 59.90 ≈ 26.1 %

对比:
  Δ_vis  = 0.10 点  (≈0.2%)
  ⟹  Δ_phys / Δ_vis ≈ 156×
```

**闭环解读**：同一模型，换外观几乎不痛（0.10 点），换物理条件掉 26%。这个比值就是本文想让评委看到的「隐藏失败维度」的量化证据。其余四模型同样呈现 Δ_phys ≫ Δ_vis：Motus 1.64 点视觉缺口 vs 39.60% 物理成功率；FACT 1.80 点 vs 39.14%；π0.5 5.98 点 vs 31.60%；Galaxea-VLA 0.90 点 vs 37.82%。

## 4. 工程视角 (Engineering View)

| 维度 | 数据/约束 | 工程含义 |
|------|-----------|----------|
| 采样频率 | 每 episode 一次，episode 内冻结 | 不能把物理参数当「每帧输入」；策略要么先估计后冻结，要么显式条件化 |
| 可复现性 | 由 episode seed 决定随机流 | 评测可精确复现，便于回归测试与 CI |
| 可行性过滤成本 | 需专家规划器离线执行 | 建池阶段有额外算力开销，但一次性 |
| 评测规模 | 50 任务 × 100 rollout × 5 模型 = 25,000 次/档 | 三档共 ~75,000 次 rollout，是实打实的大规模评测 |
| 数据兼容性 | HDF5 + MP4 + phys_meta JSON，兼容 RoboTwin 格式 | 现有训练/推理管线**无需改接口**即可接入 |
| 部署约束 | 物理真值仅在仿真可得 | 真机上需**物理属性估计器**替代 ground-truth，本文只提供仿真监督 |

关键在于：本文把物理条件做成了**可监督的学习目标**（phys_meta），这意味着下游可以做「条件感知策略」——先估计 θ，再 condition 到策略上，而不是硬扛。

## 5. 数据与评测 (Data & Eval)

**数据集**：RoboTwin-Phys Training Set v1
- 规模：> 5,000 条专家演示
- 每条：HDF5 轨迹（动作 + 状态 + 相机流）+ MP4 视频 + phys_meta（13 维物理真值 JSON）
- 生成原则：每条演示都在其采样物理条件下**通过专家可行性验证**
- 兼容 RoboTwin 官方格式，轨迹接口零改动

**13 个物理属性（全局域，来自 Appendix A / Table 2）**：

| 属性 | 范围 |
|------|------|
| Object mass（含惯量张量联动） | ×(0.125, 4) |
| Center of mass | (−1.5, 1.5) cm，x/y/z 独立 |
| Geometry scale | ×(0.85, 1.05) 均匀缩放 |
| Table tilt | (0, 2)°，方位角固定 90° |
| Table height | (−8, 0) cm（相对 0.74 m 名义高度） |
| External force | (0, 0.1)×mg，方向固定 +X |
| Camera distance & angle | 三档：轨道位移 (0,10) cm / 平移 (0,3) cm / 旋转 (0,10)° |
| Friction μ | (0.01, 1.25) |
| Restitution | (0, 0.5) |
| Object joint damping | (0, 25)（抽屉/柜门/开关等铰接物） |
| Arm & gripper joint damping | ×(0.5, 3)，臂与夹爪共享同一缩放因子 |

> 注：另有 2 个属性在 Table 2 中按类别列示（scene geometry / sensing configuration 分组），9 个物理敏感任务使用专用域（Appendix B / Table 3）。

**评测对象（5 个模型）**：Fast-WAM、Motus、FACT、π0.5、Galaxea-VLA (G0.5)。

**总体结果（Table 1，成功率 %）**：

| 模型 | Clean→Official 视觉缺口 | Physical Random SR |
|------|--------------------------|--------------------|
| Fast-WAM | 0.10 点 | 44.24 |
| Motus | 1.64 点 | 39.60 |
| FACT | 1.80 点 | 39.14 |
| π0.5 | 5.98 点 | 31.60 |
| Galaxea-VLA | 0.90 点 | 37.82 |

**任务级结构（Appendix D，节选）**：beat_block_hammer 全线低下（Fast-WAM 17 / Motus 13 / FACT 11 / π0.5 8 / Galaxea 8）；pick_diverse_bottles、move_stapler_pad、put_bottles_dustbin、place_can_basket 同样低。反之 grab_roller、shake_bottle、shake_bottle_horizontally、place_container_plate 相对稳健。跨模型一致的难/易任务结构说明失败**不是随机的**，而是系统性压在接触动力学、物体稳定性、质量分布、铰接运动上。

## 6. 能力与失败模式 (Capabilities & Failure Modes)

**能做什么**：
- 系统测量模型对物理条件多样性的鲁棒性（三档可拆解）
- 支持物理属性估计 / 条件感知表征 / 物理条件化策略训练（有真值）
- 暴露视觉鲁棒性无法覆盖的失败维度

**不能做什么 / 失败模式**：
- 面向**物理参数敏感**的任务（撞击、堆叠、单薄物体、塑料/金属材质差异、铰接开关）几乎全面失守——原因：这些任务结果由接触动力学、质量分布、摩擦主导，而模型主要依赖视觉相关特征。
- 未验证真机：所有结论限于 RoboTwin 仿真域，sim-to-real 的物理参数映射待外部复现。
- 未给出改进方法：诊断强于治疗，如何让模型内化物理条件仍留给后续工作。

### 6.1 隐含假设 (Hidden Assumptions)

- **独立性假设**：13 个属性**独立采样**，但真实世界质量与摩擦、质心与惯量常相关；独立采样可能产生现实中罕见的组合。
- **可行性 = 有效性**：用专家规划器能否成功来判定 instance 有效，但专家成功不等于该物理条件在真实世界可实现。
- **平台代表性**：RoboTwin-2.0 的 50 个双臂桌面任务能否代表「物理多样性」的整体挑战，未加论证。
- **单位与物理意义**：摩擦 (0.01, 1.25) 等无量纲/未标定范围与真实材料的对应关系未说明，冲击真实部署时的可比性存疑。
- **评测公平性**：5 个模型的 checkpoint / 训练预算是否可比，原文未充分披露。

🎯 **面试 Tip**：被问到「VLA 泛化评测的盲点是什么」——答：现有 benchmark 只随机「看得到的东西」（外观/布局/视角），却固定「感受得到的东西」（质量/摩擦/阻尼/质心）。RoboTwin-Phys 把 13 个物理属性连续化后，发现模型视觉鲁棒性几乎不下降（<2 点）而物理鲁棒性大跌（成功率降到 31~44%），说明当前 VLA/WAM 更多在拟合视觉相关性而非内化接触动力学——这是一个**独立且未被测量的失败维度**。
