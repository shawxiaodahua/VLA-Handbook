這篇論文問的是：機器人手裡捏東西時，**接觸力/滑動**這些關鍵狀態是圖片看不出來的，而學一個「動作條件的觸覺世界模型」又極缺數據——真機觸覺採集太貴、還綁死某個本體。作者的發現是：只要讓人類和機器人**戴同一套觸覺佈局、用同一套動作表示**，人類自然互動的觸覺軌跡就能監督同一個模型，且能遷移到未見的機器人任務。對 VLA 研究者的意義是——**人類觸覺可能是繼真機、模擬之後的第三條縮放軸**，而且和真機數據是互補的，不是替代的。

### 關鍵機制 (Key Mechanism)

- **共享感測佈局（shared sensing layout）**：人類與機器人手戴同構壓阻陣列（每手 5 個 4×4 指尖墊 + 1 個 15×16 掌墊 = 320 taxels），使兩域觸覺觀測落在同一表徵空間——這是「不需要學習觸覺域映射」的前提。
- **動作重定向（human→robot）**：追蹤人類手腕 6-DoF + 25 關鍵點手骨架，經 IK 映射到 WujiHand2（20-DoF），統一為 **67-D 動作**（雙腕 + 雙 20-DoF 手 + 頭部相機運動），消去人類特有座標。
- **Anatomy-aware tokenization（Split-Hands）**：指尖與掌部分別用共享編碼器，加 pad identity embedding 保留解剖對應；避免把解剖上不相連的區域排成「假鄰域」。
- **Anchored residual latents**：只預測相對初始觸覺的**變化量**，把模型注意力集中在動作引發的接觸變化，而非靜態壓力背景。
- **Dual-rate action conditioning**：視頻 latent 每 4 幀一個動作 chunk，觸覺則逐幀注入，匹配兩種模態各自的原生時間解析度。
- **MoT（Mixture-of-Transformers）**：兩路 expert 每層用 masked joint self-attention 交換上下文，各自保留 modality-specific AdaLN 與 FFN——在共享與獨立之間取得折中。

⚡ **Eureka Moment**：**只要觸覺觀測空間與動作空間「對齊」，人類和機器人的接觸動力學就是可轉移的**——於是同一個動作條件世界模型可以同時吃人類軌跡與真機軌跡，人類數據成為一條獨立的縮放軸。

## 2. 數學核心 (Math Core)

📌 **Napkin Formula**（一行抓住本質）：

```
p_θ(v_1:T, x_1:T | v_0, x_0, a_1:T, ℓ)   ← 動作條件下聯合預測未來視頻+觸覺
```

**目標**：在給定初始視覺 `v_0`、初始雙側觸覺圖 `x_0`、語言指令 `ℓ`、未來動作序列 `a_1:T` 的條件下，聯合建模未來視頻與觸覺的分佈。

**核心方程（式 1，§III-A）**：

```
p_θ(v_1:T, x_1:T | v_0, x_0, a_1:T, ℓ)
```

**錨定殘差觸覺 latent（式 2）**：令 `E_x` / `D_x` 為觸覺編碼/解碼器，`z_t = E_x(x_t)`：

```
r_t = z_t - z_0
x̂_t = D_x(z_0 + r̂_t)
```

**雙率動作條件（式 3）**：視頻 chunk `j`、觸覺步 `t`：

```
c^v_j = φ_v(a_{4j-3 : 4j}),    c^v_0 = 0
c^x_t = φ_x(a_t),              c^x_0 = 0
```

**動作表示（式 6）**：

```
a_t = [e^L_t, e^R_t, q^L_t, q^R_t, e^c_t] ∈ R^67
（e：首幀相對手腕運動；q ∈ R^20：手部構型；c：頭部相機）
```

**訓練目標（式 4，conditional flow matching）**：

```
L = L_video^FM + λ_tac · L_tactile^FM
```

**策略評估一致性（式 7，MMRV，越低越好）**：`R_ik`/`S_ik` 為策略 i 在任務 k 的真實/想像分數，`v_ij,k = 1` 當 `(R_ik - R_jk)(S_ik - S_jk) < 0`（排序反轉）：

```
MMRV_k = (1/N) · Σ_i max_j ( |R_ik - R_jk| · v_ij,k ),   N = 3
```

**變量說明**：

| 符號 | 含義 |
|------|------|
| `v_0, x_0` | 初始 RGB 觀測、初始雙側觸覺圖（作為乾淨上下文保留） |
| `z_0` | 初始觸覺編碼，殘差預測的錨點 |
| `r_t` | 相對初始狀態的觸覺 latent 變化量 |
| `a_t ∈ R^67` | 人機共享的 67 維動作表示 |
| `λ_tac` | 觸覺損失權重，平衡兩路 flow matching |
| `φ_v, φ_x` | 視頻/觸覺各自的動作條件編碼器 |

**直覺**：flow matching 把生成看作從噪聲到數據的連續流；這裡視頻與觸覺**各自流、但靠 joint attention 耦合**，不引入額外的跨模態對齊損失。殘差形式讓「動作沒改變接觸」的區域自動接近零，把容量留給真正發生接觸變化的稀疏區域——這與評估中強調 Contact-IoU/F1 而非全局 MSE 的取向一致。

## 3. 帶數字走一遍：玩具例子 (Worked Example)

設某一時刻觸覺編碼為二維 `z_0 = [2.0, 5.0]`（初始輕握），下一時刻真實觸覺編碼 `z_1 = [2.4, 4.2]`（食指加壓、掌心卸力）。

**殘差編碼**：

```
r_1 = z_1 - z_0 = [0.4, -0.8]
```

模型只需預測 `r̂_1 = [0.4, -0.8]` 附近的變化量，而非整個壓力背景——若模型輸出 `r̂_1 = [0.3, -0.6]`（略欠），解碼為：

```
x̂_1 = D_x(z_0 + r̂_1) = D_x([2.3, 4.4])   ≈ 接近真實，且背景仍被 z_0 鎖住
```

**縮放趨勢的「可計算閉環」**（Table I 實測，非假設）：固定 5h 真機，人數據 0→100h：

| 人類數據 | 視覺 PSNR ↑ | Traj. Acc ↑ | 觸覺 PSNR ↑ | Contact-IoU ↑ | Contact-F1 ↑ |
|----------|-------------|-------------|-------------|----------------|---------------|
| 0h（Robot-only） | 23.47 | 0.89 | 24.81 | 0.42 | 0.55 |
| +10h | — | — | 幾乎持平 | — | — |
| +50h | — | — | — | — | — |
| +100h（本文） | 27.10 | 0.96 | 29.18 | 0.59 | 0.71 |

關鍵的**形狀**：視覺指標在 +50h~+100h 之間**飽和**，而接觸指標（Contact-IoU/F1）**持續改善**——這說明人類數據帶來的可遷移結構，主要體現在「看不見的接觸動力學」上，而非像素外觀。+10h 幾乎無效，說明這條縮放軸存在一個「起步閾值」。

## 4. 工程視角 (Engineering View)

| 維度 | 含義 |
|------|------|
| 骨幹規模 | 視頻 expert 由 Wan2.2-TI2V-5B 初始化 → 5B 級骨幹，部署成本高；觸覺 expert 刻意「輕量」以控制總量 |
| 時序對齊 | 視頻 latent 4× 壓縮、觸覺保持觀測率，二者時間解析度不同 → 必須雙率注入（式 3），否則細粒度接觸時序會丟 |
| 感測頻率 | 手套 60 Hz，訓練保留 320/360 taxels；部署機器人手需同一 320 佈局 |
| 動作空間 | 統一 67-D；人類→機器人靠 IK 重定向，去除人體特有成座標後兩域共用 |
| 推理成本 | 每步需解碼未來 RGB 幀 + 壓力圖；閉環 rollout 時預測觀測又回饋給策略 → 延遲需要評估（論文未給具體 fps，> TODO） |
| 內存/凍結策略 | Visual VAE 與 tactile decoder 凍結；Split-Hands tokenizer 預訓練後凍結 → 可預訓練、可替換編解碼器 |
| 部署約束 | 需要人機同構觸覺手套 + 20-DoF 靈巧手，硬體門檻是主要落地瓶頸 |

**工程含義**：這不是一個「換個損失函數就能上」的工作——它的可複現性綁在**硬體同構性**上。若你的機器手沒有與採集手套一一對應的 taxel 佈局，共享感測空間這一前提就斷了，方法的核心優勢消失。

## 6. 能力與失敗模式 (Capabilities & Failure Modes)

**能做**：
- 動作條件下聯合預測未來 RGB + 雙側觸覺圖；人類數據可遷移到未見機器人任務（視覺/幾何/接觸）。
- 作為**策略評估器**：WM-Mix 平均 Pearson 0.844 > WM-Robot 0.646，平均 MMRV 0.017 < 0.025；用 100 human 替換一半 task-specific 真機示範仍能保持一致性（WM-Robot vs WM-Mix 池化 Pearson 0.925）。
- 作為**合成數據生成器**：對 FTP-1 有幫助（+WM-Mix 四任務均值 0.694 vs 全真機 0.731）。

**不能做 / 局限**：
- **合成數據收益不穩定**：π0.5 均值 0.625→0.494、X-VLA 0.500→0.400（Stand Bottle 為 0）。作者明言「合成數據的可用性取決於策略與任務」——評估器一致 ≠ 訓練同樣有效。
- **排序錯誤未解**：Stand Bottle 上兩個 WM 都反轉了 π0.5 與 X-VLA 的順序（MMRV 皆 0.0667）。
- **僅單一平台**：真機只用 Tianji 臂 + 20-DoF Wuji 手，桌面雙臂任務；**未驗證**移動/人形/其他觸覺感測器。
- **硬體強綁定**：方法前提是人機同構觸覺佈局，換感測器即需重做共享界面。

### 6.1 隱含假設 (Hidden Assumptions)

1. **接觸動力學可跨本體轉移**——這是全文最核心、也是最未被獨立驗證的假設；作者用「共享佈局 + 動作重定向」使其**看似**成立，但沒有做「打破同構性」的對照實驗。
2. **IK 重定向後的人類動作與機器人可行動作分佈足夠接近**——若重定向引入系統偏差（如人手指比 20-DoF 手更靈活），監督信號可能失真。
3. **320 taxel 取樣不丟關鍵接觸信息**——從 360 降到 320 的取捨未做消融。
4. **接觸權重重建足以支撐稀疏接觸表徵**——假設非接觸區主導的問題已被 tokenizer 預訓練解決。
5. **人類 100h 與真機 5h 的任務集「不相交」足夠確保遷移而非過擬合**——但兩者都來自同一實驗室採集協議，可能共享採集偏差。
