## 1. 核心架構/方法總覽 (Overview / Architecture)

ZeroTouch 是一個「訓練期多模態、部署期純視覺」的接觸狀態估計器。它不是完整策略——接近軌跡與抓取位姿由上游客制器或策略提供，ZeroTouch 只負責**預測接觸狀態**與**控制夾爪閉合**。

### 1.1 系統對比概覽 (System Component Comparison)

| 模組 | 輸入 | 輸出 | 訓練時 | 部署時 | 備註 |
|------|------|------|--------|--------|------|
| 視覺骨幹 | 手腕 RGB (`o_vis`) | patch-level visual tokens | ✅ 凍結 | ✅ | 用 frozen DINOv2 |
| 狀態編碼器 | 夾爪位置 + 局部重力方向 (`o_prop`, `g_local`) | 特徵縮放/偏置 | ✅ | ✅ | 輕量 MLP，輸出 FiLM 參數 |
| FiLM 調製 | 狀態 embedding | 調製後的視覺 tokens | ✅ | ✅ | 在 cross-attention **之前**注入狀態 |
| 觸覺查詢解碼器 | 18×24 可學習 query + 視覺 | 稠密形變圖 `D` | ✅ | ✅ | 自注意力 + 交叉注意力 + MLP |
| 全局交互 token | tokens | 潛在 `z_t` | ✅ | ✅ | 供力/力矩與目標力頭使用 |
| Wrench 頭 | `z_t` | 六軸 `w = [Fx,Fy,Fz,Mx,My,Mz]` | ✅ | ✅ | 用記錄 wrench 監督 |
| 目標力頭 | 接觸前視覺幀 | `F*`（抓取級目標力） | ✅ | ✅ | 只在合格接觸前幀監督 |
| 觸覺傳感器 | DM-Tac W2 | 形變 + 六軸 wrench | ✅ 特權監督 | ❌ 不使用 | 部署完全不輸入 |

### 1.2 關鍵機制 (Key Mechanism)

- **非對稱模態（privileged supervision）**：觸覺只在訓練時作為「老師」給稠密形變與六軸 wrench 的監督信號，部署時模型只有 RGB + 機器人狀態。這是本文最本質的設計取捨。
- **重力方向作為額外本體感覺**：`g_local` 是夾爪/工具座標系下的歸一化重力向量。作者觀察到「視覺上相似」的抓取配置，因為方向不同會產生**不同的力/力矩響應**，加入 `g_local` 可以消歧。
- **FiLM 前置調製**：狀態 embedding 生成的縮放/偏置在 cross-attention **之前**作用於視覺 token，讓夾爪配置同時影響輸出的「幅度」與「用於接觸推理的空間特徵」，而不只是事後縮放。
- **兩個力量的角色分離**：瞬時 `F_z(t)` 描述當前法向受力（壓縮越深越負）；`F*` 是**情節級**的期望目標力，由接觸前視覺預測。前者用於閉合控制，後者用於決定何時停。

⚡ **Eureka Moment**：把「目標夾緊力」定義為一次**成功抓取軌跡中、閉合後穩定期間法向力的中位數** `F* = median_{t∈T_settle} F_z(t)`——它不是理論最優力，而是一個「物理可解釋、來自成功示範」的抓取級標籤，讓模型能同時回答「現在多大力」和「該用多大力」。

## 2. 數學核心 (Math Core)

📌 **Napkin Formula**（一行抓住本質）：

```
從視覺與狀態學出 (D_hat, w_hat, F*_hat)，再用 F_z(t) ≤ F* 決定停止閉合
```

**目標**：在無觸覺輸入下，從 `(o_vis, o_prop, g_local)` 預測接觸狀態與目標力。

**映射（部署期）**：

```
(o_vis_t, o_prop_t, g_local_t) → (D_hat_t, w_hat_t, F*_hat)
```

**預測量定義**：

```
w_hat_t = [F_x, F_y, F_z, M_x, M_y, M_z]        # 瞬時六軸力/力矩
F* = median_{t ∈ T_settle} F_z(t)               # 抓取級目標力（負值=壓縮）
```

**閉合終止規則**：

```
F_z_hat(t)  >  F*   ⇒  繼續閉合 (continue closing)
F_z_hat(t)  <= F*   ⇒  停止並保持 (stop and hold)
```

**變量說明**：

| 符號 | 含義 | 來源 |
|------|------|------|
| `o_vis_t` | 手腕相機 RGB 觀測 | 相機 |
| `o_prop_t` | 夾爪狀態（位置等） | 機器人 |
| `g_local_t` | 局部 TCP 座標系下歸一化重力向量 `[gx,gy,gz]`，`‖g‖₂≈1` | 姿態推算 |
| `D_hat_t` | 稠密接觸形變表示（分量 `dz, dx, dy`） | 模型輸出 |
| `w_hat_t` | 六軸 wrench 估計 | 模型輸出 |
| `F*` | 期望抓取壓縮力（情節級） | 接觸前幀預測 / 訓練期監督 |
| `T_settle` | 閉合後夾爪位置穩定且維持有效接觸的時間區間 | 數據處理 |

**直覺**：`F_z` 與 `F*` 是兩個時間尺度的量——一個是「此刻讀數」，一個是「這個抓取該壓到多深」。控制器做的是**相對比較**（當前 vs 目標），而不是絕對力回歸。作者明確指出：即便 `F_z` 與 `F*` 各自都有可見偏差，只要它們在**同一個視覺表徵下協同偏移**，相對準則的誤差就可能被抵消——這是它能超越純回歸基線的關鍵。

> 符號與本文保持一致：壓縮對應負的法向力；`F*` 越負表示壓得越緊。作者強調 `F*` 是**經驗性定義**，不聲稱全域最優或理論保證的最小安全力。

## 3. 帶數字走一遍：玩具例子 (Worked Example)

假設某一抓取配置下，訓練集裡的成功軌跡在穩定期量到的法向力樣本為：

```
F_z 樣本 (N):  -3.1,  -3.0,  -3.4,  -3.2,  -2.9,  -3.3
排序後中位數 = -3.1  →  F* = -3.1 N
```

於是 `F* = -3.1 N` 被記為這個抓取的目標壓縮力（負=壓縮）。

部署時夾爪增量閉合，模型從 RGB 連續估 `F_z_hat(t)`：

```
t=0  F_z_hat = -0.4    > -3.1  → 繼續閉合
t=1  F_z_hat = -1.6    > -3.1  → 繼續閉合
t=2  F_z_hat = -2.7    > -3.1  → 繼續閉合
t=3  F_z_hat = -3.05   > -3.1  → 繼續閉合（快到了）
t=4  F_z_hat = -3.2   <= -3.1  → 停止並保持  ✅
```

注意第 4 步：模型估計略「過衝」到 -3.2，但只要相對比較 `F_z_hat <= F*` 成立就停。這裡體現了 §2 的直覺：**兩個估計的偏差同向時，停止時機仍然落在真值交叉點附近**。

一個可計算的誤差視角（法向力 MAE，第 4 節有消融數字）：

```
baseline (state-only)   MAE_Fz = 2.017 N
完整模型               MAE_Fz = 0.531 N
絕對改善 = 2.017 - 0.531 = 1.486 N (≈ 73.7% 相對下降)
```

## 4. 工程視角 (Engineering View)

| 工程維度 | 觀察 | 工程含義 |
|----------|------|----------|
| 部署硬體 | 不需觸覺傳感器 | 可用普通腕部 RGB + 夾爪狀態；省掉觸覺接口、布線、標定維護 |
| 訓練成本 | 需一次性帶觸覺採集 | 觸覺被「折舊」進模型權重；後續部署規模化成本低 |
| 輸入頻率 | 依賴腕部相機幀率 | 閉合控制頻率受視覺推理延遲限制，非高頻力控回路 |
| 模組邊界 | 上游客制器提供接近/位姿 | ZeroTouch 只管「閉合到多深」，與策略解耦，便於替換 |
| 穩定性設計 | 用中位數而非峰值定 `F*` | 作者觀察到閉合後有瞬時力峰後回落；用峰值會系統性高估目標力 |
| 感測器約定 | DM-Tac W2 視覺觸覺，壓縮=負 `F_z` | 遷移到其他傳感器/符號約定時需重標定 |

一個關鍵工程取捨：**「目標力」分支只在合格接觸前幀上監督**。即訓練時要用「抓起來 5 cm、持穩 2 s 不掉」的過濾準則，只有通過的成功軌跡才進入 `F*` 監督。這意味著資料管線需要一套自動化的成功判別（此處是人工/規則化 lift-and-hold 準則），否則 `F*` 標籤質量會被失敗抓取污染。

## 6. 能力與失敗模式 (Capabilities & Failure Modes)

**能做**：

- 從腕部 RGB 預測稠密接觸形變、六軸 wrench、以及抓取級目標力
- 在無觸覺硬體下完成力感知的閉合終止（視覺閉環）
- 跨抓取位置、夾爪姿態、物體幾何與負載變化（實測三種偏移）

**不能做 / 未驗證**：

- **不是完整策略**：接近軌跡與抓取位姿需上游提供，本文不處理「抓哪裡」
- 未驗證移動、雙臂、人形平台——實驗是桌面單臂
- 目標力為經驗中位數，**非**理論最優或保證不滑的安全下界
- 依賴特定觸覺傳感器（DM-Tac W2）與符號約定做訓練監督
- 數據規模偏小（270 episodes），泛化邊界仍待外部復現

### 6.1 隱含假設 (Hidden Assumptions)

- **假設單一腕部相機視角足以消歧接觸力學**：作者承認「相同外觀可能對應不同 wrench」，但只補了重力方向一個本體感覺信號；多接觸點/遮擋場景是否仍夠用未驗證。
- **假設 `F*` 中位數是合理監督**：實際上它綁定於數據採集的 lift-and-hold 準則與夾爪規格，換夾爪/物體表面摩擦係數後該標籤未必可遷移。
- **假設觸覺監督信號本身準確**：所有 `F_z`、wrench 監督都來自 DM-Tac W2 的讀數，傳感器自身標定誤差會成為監督噪聲下界。
- **假設上游策略可靠**：方法把接近/位姿外包，若上游給錯位姿，閉合控制再準也救不回來——這部分風險被方法邊界「切走」了。
