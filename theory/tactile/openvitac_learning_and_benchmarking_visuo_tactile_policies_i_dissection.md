### 1.2 关键机制 (Key Mechanism)

- **用能力维度而非任务清单来组织基准**：PP 考"看不见的物理属性"、FA 考"别捏碎"、CR 考"持续接触"、PR 考"几何公差"。这样设计的好处是消融结果可以按维度归因，而不是按任务罗列。
- **real-to-sim 是"资产级 + 任务级"两层对齐**：资产级用多视图重建物体几何、必要时拆成功能件；任务级对齐物体初始位姿、目标位姿、机器人初始状态。这样仿真任务不是"像"，而是"对应"。
- **设计空间被压成两个正交轴**：触觉表示（SigLIP / T3 / Sparsh / AnyTouch2）× 触觉集成（①–⑤）。表示对比共享同一 π_0.5 骨干与同一 token 级拼接接口；集成对比则改变接入方式（Table 4 中④ Expert 对应 FTP-1 的 T3+Expert，并非共享 π_0.5 token 接口的变体）。
- **co-training 不做特征对齐**：只按 α 混采两个域的数据、共用同一个 flow-matching BC 损失。作者的立场是"任务语义对齐比特征对齐更重要"。

⚡ **Eureka Moment**：
> 触觉信息应该"早"进而不是"晚"进——token 级拼接把触觉 token 放在 VLM 输入端，让触觉和视觉-语言在完整策略计算中交互；而动作级条件、后期精修这类"晚进"方案，把触觉限制在下游，学不到接触相关的中间表征。

## 2. 数学核心 (Math Core)

📌 **Napkin Formula**（一行抓住本质）：

```
OpenVTLA = π_0.5 的 VLM 输入序列 ⊕ AnyTouch2(触觉历史)   （拼接，不是调制、不是旁路）
```

**目标**：在固定真机数据预算下，用仿真数据 + 触觉输入提升真机成功率。

**核心方程**（论文 Eq. 1，co-training 损失）：

```
L_co = (1 - α) · L_BC(D_r) + α · L_BC(D_s)
```

**变量说明**：

| 符号 | 含义 | 论文中的取值/说明 |
|------|------|-------------------|
| L_BC | flow-matching 行为克隆损失 | 与 π_0.5 一致 |
| D_r | 真机演示集 | 每任务固定 100 条（In-B v2 为 300） |
| D_s | 仿真演示集 | 250 或 500 条，来自多样化场景配置 |
| α | 仿真采样概率 | **独立于数据集大小**，是采样概率不是数据比例 |

**直觉**：α 不是"仿真数据占比"，而是"每个 batch 里从仿真池抽样的概率"。这一点很重要——如果按数据量比例设 α，500 条仿真 vs 100 条真机会得到 α≈0.83，仿真会淹没真机；论文明确说 α 独立于数据集大小，意味着这是一个可独立调的课程参数。

**触觉表示的对比口径**（论文 §4.3）：在相同 token 级拼接接口下，只换编码器，任务级结果归一化后取平均——这是一种受控的比较，但注意它把"编码器预训练质量"和"时序建模能力"两个因素混在了一起，论文用附录 D 的两个消融（随机初始化、重复当前帧）来拆解。

## 3. 带数字走一遍：玩具例子 (Worked Example)

以下为**假设性验算**，用来展示如何读论文里的成功率表，不是论文原始实验。

假设某任务真机评测做 20 次试验（论文表 3 与表 5 的常见设置就是 20 trials）：

```
情形 A：π_0.5 纯真机训练，成功 3/20
        成功率 = 3/20 = 15.0%
情形 B：π_0.5 + 500 条仿真 co-training，成功 8/20
        成功率 = 8/20 = 40.0%
提升 = 40.0% - 15.0% = +25.0 个百分点 = +5 次成功
```

**可计算的含义**：在 20 trials 的粒度下，**1 次试验 = 5 个百分点**。所以单个 20-trial 任务内小于 5 点的差异才不到 1 次试验；但 OpenVTLA 与 FTP-1 的 54.6% vs 51.9%（差 2.7 点）是跨 8 个任务等权平均后的差异，其粒度不是 5 点，不能据此说不到 1 次试验，仍需看任务级分布与置信区间。本文的解释是：任务级非加权平均使各任务等权；若改用总成功次数/总试验次数，In-B v2 的 30 trials 会获得更高权重。论文明确给出非加权口径，但未将这一解释写成作者的选择动机。

再验算表 3 的聚合方式（用 π_0.5 一行）：

```
任务级成功率：
RC 10/20=50.0, ECS 10/20=50.0, GC 16/20=80.0, GA 7/20=35.0,
PD 12/20=60.0, In-USB 3/20=15.0, In-B v1 5/20=25.0, In-B v2 4/30=13.3
非加权平均 = (50+50+80+35+60+15+25+13.3)/8 = 41.0%
```

与论文 Table 3 的 41.0 一致。✓ 说明"Avg."确实是**任务级等权平均**，不是按试验数加权。读表时先把各任务转为成功率，再等权平均；不要把 30-trial 任务的原始成功次数直接与 20-trial 任务相加。

| 约束 | 论文给出的数字/事实 | 工程含义 |

## 5. 数据与评测 (Data & Eval)

**数据组成**（论文 Table S2，按每种触觉传感器配置统计）：

| 域 | 任务数 | 规模 | 帧数 |
|----|--------|------|------|
| 仿真 | 11 | 1,300 episodes | ~918K |
| 真机 | 8 | 2,400 demos | ~2.1M |

仿真每任务 100 episodes（In-B v2 为 300）；真机 GC/RC/ECS/PD 各 100 demos，GA/In-USB 各 200，In-B v1 400，In-B v2 1200。训练时真机每任务只随机抽 100 条（In-B v2 抽 300），所以**采集池 ≠ 训练集**，这一点在复现时容易踩坑。

**评测设置**：
- 所有策略按任务**单独训练一个策略**（single-task setting），不是多任务通用策略。
- 仿真用预定义、平衡的任务条件 + 任务特定二值成功判据。
- 真机 In-B v2 有 3 种物体语义 × 2 种场景布局 = 6 种配置，评测时分别评再按任务聚合。
- sim–real 一致性用 SIMPLER 的口径：只看**相对排序**是否保持，不要求成功率相同。7 个方法在 8 个共享任务上：Pearson r = 0.967，MMRV = 0.006（论文 §4.2）。

**主结果**（论文 Table 2 / Table 3）：

| 家族 | 仿真最高 | 真机最高 |
|------|----------|----------|
| VLA | InternVLA-A1.5 51.5% | InternVLA-A1.5 43.1% |
| WAM | FastWAM 37.4% | FastWAM 29.0% |
| VTLA | FTP-1 61.2% | FTP-1 51.9% |
| OpenVTLA | **68.7%** | **54.6%** |

> ⚠️ **两处需要向作者确认的数字不一致**（如实标注，不做修正）：
> 1. 引言（§1）称"最强 WAM 仿真 53.3%"，但 Table 2 中三个 WAM 的最高值是 FastWAM 的 37.4%。
> 2. 引言（§1）称"最强 WAM 真机 48.5%"，但 Table 3 中唯一 WAM 是 FastWAM 的 29.0%。
> 按 Table 2/3，仿真与真机均为 VTLA > VLA > WAM；但若采用引言（§1）中的 53.3%/48.5%，仿真中 WAM 会高于最强 VLA 的 51.5%，因此该排序只能按表格数据成立。引用具体数字时应以表格为准。

**触觉表示消融**（论文 §4.3，同一 token 拼接接口）：AnyTouch2 68.7% > Sparsh 64.7% > SigLIP 59.5% > T3 58.1%。AnyTouch2 相对 Sparsh 在 ECS 上 +12 点、USB 插入上 +10 点。

**Co-training 结果**（论文 Table 5，每任务 100 条真机 + 0/250/500 条仿真，每条件 20 trials）：

| 模型 | 仿真条数 | In-USB | GA |
|------|----------|--------|-----|

## 6. 能力与失败模式 (Capabilities & Failure Modes)

**能做**：
- 在 PP 任务上，触觉带来的收益最大（OpenVTLA 仿真 WC 89%、HC 99%、RC 100%，相对 π_0.5 的 53/60/64 提升约 36–39 点（WC +36、HC +39、RC +36））。这符合直觉：重量、硬度、粗糙度这些属性视觉上本来就模糊。
- 在 Table 2 的仿真 FA（GC）任务上，π_0.5 为 39%，OpenVTLA 为 69%；Table 3 真机中分别为 16/20（80%）与 19/20（95%）。这些结果支持触觉在该设置下有益，不能证明所有力敏感操作都必须使用触觉。
- 在 Table 2 的仿真 CR（GA/PD）任务上，π_0.5 为 87%/99%，OpenVTLA 为 91%/99%；Table 3 真机则分别为 35%/60% 与 50%/60%。仿真中的较高成功率不能当作真机结果。
- Co-training 在固定真机预算下能稳定提升真机成功率，且在视觉扰动下提供额外鲁棒性。

**不能做 / 做不好**：
- **PR 任务整体仍是短板**：表 2 中最好的 OpenVTLA 在 In-USB 27%、In-B v1 11%、In-B v2 8.0%，表 3 真机 In-B v2 仅 5/30。作者明确说"触觉 sensing 本身不足以支撑可靠的精细操作"。
- **WAM 家族在该基准上整体偏弱**：仿真最高 37.4%，真机 29.0%。注意这不等于 WAM 方法本身差，论文 Table S4 显示各家族训练预算并不完全一致，例如 Lingbot-VA 为 5k steps；这些信息不足以确定低分的具体原因。
- **跨传感器泛化未验证**：论文支持 3 种传感器，但主表没有按传感器拆分的对比。TODO：待补。
- **长程/可变形物体未覆盖**：作者在 Limitations 里自述，未来才扩展到 deformable object、surface interaction、long-horizon household。

### 6.1 隐含假设 (Hidden Assumptions)

| 假设 | 为什么可能不成立 |
|------|------------------|
| 仿真里"对齐任务语义"就足以让 co-training 有效 | 论文自己也承认触觉渲染有 gap，OpenVTLA 的 co-training 增益（+15 点）小于 π_0.5（+20 点），作者推测是接触信号跨域残差导致的 |
| 单任务训练能代表策略能力 | 真实部署通常是多任务/长程，单任务结论外推需谨慎 |
| 20 trials 足以区分方法 | 单个 20-trial 任务中 1 trial = 5 点；跨 8 任务平均的 2.7 点差异需结合任务分布与不确定性评估，不能用该粒度直接判断显著性 |
| token 级拼接不增加推理成本 | AnyTouch2 虽紧凑，但序列变长是事实，论文未报延迟 |
| TacEx 的触觉渲染能代表真实接触 | 作者自述这是主要局限之一 |
| π_0.5 是公平的共享骨干 | 不同家族的原始训练配方不同（步数、batch、优化器），跨家族比较的是"完整策略"而非单一变量，论文 §C 也有此声明 |

## 8. 精读建议 (Reading Guide)

- **值得精读原文的人**：
  1. 正在给现有 VLA 加触觉、需要选"表示 + 接入点"的研究者——直接看 §3.2 与 §4.3、Table 4。
  2. 需要一套 sim–real 可对齐评测协议、且手里有至少一种触觉传感器的工程团队——看 §3.1、§B.2、§B.3。
  3. 研究 sim–real co-training 在触觉模态下是否仍成立的人——看 §3.3、§4.4、Table 5。

- **建议章节路径**：先读 §1 图 1 + §3.2 设计空间（建立框架）→ 再看 §4.2 主表 + §4.3 两张消融表（建立"早融合 + 时序表征"的结论）→ 最后看 §4.4 co-training（建立"仿真数据能补真机"的结论）→ 附录 B/C 只在复现时查。

- **不值得精读的理由**：如果你不做机器人操作、或已熟悉 π_0.5 + 触觉拼接这一类做法、或只关心纯视觉 VLA 的规模化，读摘要 + Table 2/4 即可；论文的贡献主要在"评测协议与设计空间归因"，不在新模型结构。
