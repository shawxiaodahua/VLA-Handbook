💡 **X-Ray 开场**

接触丰富操作有一个被忽视的"感官冲突"：定位/对齐/接近阶段，视觉与本体感受是主力，腕部力觉此时主要是噪声，硬塞进策略反而干扰视觉运动行为；一旦接触发生，视觉上几乎相同的构型可能对应完全不同的物理状态（没顶到位、卡住、已完成），此时力觉才变成关键信号。

论文的答案是：不要用一个策略在整条轨迹上"全局适配力觉"，而是保留一个任务适配好的 base expert 专门管非接触段，另起一个 contact expert 只吃接触段数据、只关心力。对 VLA 研究者意味着：**多模态融合的收益可能不来自更好的融合算子，而来自更窄的融合位置**。

### 1.2 关键机制 (Key Mechanism)

- **两阶段训练**：先用完整演示把 π0.5 适配到目标任务（得到任务适配 VLM + base expert）；随后冻结这两者，从 base expert 初始化 contact expert，只用接触段数据更新它与其力输入模块。作用是防止力觉导向的适配直接改写已获得的视觉运动能力（论文 §III-A）。
- **接触段切分靠力阈值**：对每个时刻 t，在时间邻域 W_t 内取力模长最大值，超过任务阈值 δ_task 则标为接触。邻域向接触起点/释放点两侧扩张若干帧，以保留专家切换与接触动作生成所需的过渡上下文（论文 §III-B）。
- **力 token 注入**：近期 wrench 历史经归一化、展平、线性投影成一个 token，追加在接触专家的动作 token 序列最前；base expert 的序列里没有这个 token（论文式 (2)(3)）。
- **接触局部化力注意课程**：把 FACTR 的视觉模糊课程只施加在 contact expert 上，并额外加了 state-token masking——在早期后训练阶段把一部分序列化状态 token 的离散 ID 替换为词表 ID 0，随着课程衰减逐步恢复（论文 §III-C）。
- **迟滞路由**：进入与离开接触阶段使用不同阈值，且要求决策连续若干控制步稳定才切换；切换时丢弃上一动作块中未执行的动作并重新生成（论文 §III-B）。

⚡ **Eureka Moment**：力觉不是"加进去就会被用"，也不是"全程都该用"——它是一个**位置问题**：把力觉专精放进一个只负责接触段、只拿接触段数据训练的独立专家里，再用课程在该专家内部把视觉与本体感受捷径压掉。

## 2. 数学核心 (Math Core)

📌 **Napkin Formula**

```
接触判定 = 1[ 邻域内 ||f_j||₂ 的最大值 > δ_task ]     ← 一切"阶段局部化"都挂在这个开关上
```

**目标**：把力觉适配限制在"力确实有信息量"的数据子集上，同时让 contact expert 无法靠视觉细节或机器人状态抄近路。

**（1）共享前缀与阶段标签**

```
X_t^P = [X_t^I, X^l, X_t^q]                              (式 1)

W_t = {t-m, ..., t+n}                                    (时间邻域)
c_t = 1[ max_{j∈W_t} ||f_j||₂ > δ_task ]                 (式 4)
D_C = { (I_t, l, q_t, F_t^C, a_t) | c_t = 1 }            (式 5)
```

**（2）力 token 与接触专家动作序列**

```
z_t^F = W_F · vec( Norm(F_t^C) ) + b_F                   (式 2)

X_{t,τ}^C = [ z_t^F, z_{t,τ}^{a,1}, ..., z_{t,τ}^{a,H} ] (式 3)
```

**（3）接触局部化课程（视觉模糊系数与状态掩码概率同源）**

```
Ĩ_t = I_t * G_{σ_s},      σ_s = σ_max · λ_s              (式 6)

         ⎧ 1,                          s < S_w
λ_s  =   ⎨ 1 - (s - S_w)/S_d,          S_w ≤ s < S_w + S_d   (式 7)
         ⎩ 0,                          s ≥ S_w + S_d

m_{t,j} ~ Bernoulli(p_s),  p_s = p_max · λ_s             (式 8)

         ⎧ x_0,     m_{t,j} = 1        （词表 ID 0，走 embedding 查表）
x̃_{t,j} = ⎨
         ⎩ x_{t,j},  m_{t,j} = 0        (式 9)
```

> 符号与原文保持一致：λ_s 同时驱动视觉模糊强度与状态 token 掩码概率，因此两者同步衰减；语言 token 与结构 token 始终不掩码。

| 符号 | 含义 | 论文给出的取值/说明 |

**直觉**：式 (4) 是一个"力证据裁决器"，它决定了哪些帧进 D_C、哪些帧留给 base expert，同时训练 stage estimator 的标签也来自它。式 (7)(8) 用同一个 λ_s 把"看不清"和"不知道自己的状态"绑在一起同步退火——早期只能力觉和语言可用，后期完整观测回归，从而让 contact expert 学会在部署时（完整观测）依然依赖力。

## 3. 带数字走一遍：玩具例子 (Worked Example)

> 以下为**假设性算例**，用于验算论文给出的公开常数之间的关系，不代表论文实测运行过程。

**假设**：训练总步数 30,000（论文 §IV-A 的实现细节），S_w = 1,000，S_d = 29,000，σ_max = 4.0，p_max = 0.5。

（a）课程日程验算：注意 S_w + S_d = 1,000 + 29,000 = 30,000，恰好等于训练步数，因此 λ_s 在训练结束时刚好降到 0。

```
s = 0        → s < S_w        → λ = 1.0   → σ_s = 4.0,  p_s = 0.50
s = 999      → s < S_w        → λ = 1.0   → σ_s = 4.0,  p_s = 0.50
s = 1,000    → 进入线性段      → λ = 1.0   → σ_s = 4.0,  p_s = 0.50
s = 15,500   → (15500-1000)/29000 = 0.5 → λ = 0.5 → σ_s = 2.0,  p_s = 0.25
s = 29,999   → 1 - 28999/29000 ≈ 0.000034 → λ ≈ 0 → σ_s ≈ 0,  p_s ≈ 0
s ≥ 30,000   → λ = 0          → 完整观测恢复
```

工程含义：大约前 1,000 步（占 3.3%）处于"完全强抑制"，其后 29,000 步逐步放开。假设 batch size 8，则 30,000 步 ≈ 240,000 个样本级前向。

（b）接触标签窗口验算（以 tip attachment 的 (n,m) = (10,25) 为例，按式 (4) 字面方向解释）：

```
假设在 t = 100 帧处力超过 δ_task = 5.0 N
W_100 = {100-25, ..., 100+10} = {75, ..., 110}   → 36 帧
机器人控制频率 15 Hz → 36 帧 ≈ 2.40 s
其中接触前 25 帧 ≈ 1.67 s，接触后 10 帧 ≈ 0.67 s

若改为论文文字描述的"前 n 帧、后 m 帧"，则应为 {90, ..., 125}，长度同样是 36 帧。
```

可见两种解读在**窗口长度**上一致（m+n+1 = 36 帧），差别只在窗口相对 t 的偏移方向。对"接触段数据占比"的估计影响可达数百毫秒量级。

（c）成功率条件化验算（论文表 I，tip attachment）：

```
非接触成功率 75% → 20 次试验中约 15 次进入接触阶段
接触阶段条件成功率 = 14/15 = 93.33%   ✓ 与论文给出的 14/15 (93.3%) 一致
整体成功率 70% → 14/20 = 70%          ✓ 自洽
```

同一算法可用于 aspiration：非接触 100%（20 次）→ 接触 10/20 = 50% → 整体 50%；wiping：非接触 100%（20 次）→ 接触 18/20 = 90% → 整体 90%。三个任务全部自洽，说明表 I 的 stage-wise 指标定义是"接触阶段分母 = 非接触成功次数"。

（d）抽样噪声感受：每任务 20 次试验，1 次试验 = 5 个百分点。表 III 中 20%（4/20）与 15%（3/20）仅差 1 次成功，论文自己也指出这一差异"corresponds to only one successful trial"。而 15% → 70% 的差异对应 11 次成功，量级上更可信。

## 5. 数据与评测 (Data & Eval)

**平台**：Elephant Robotics Mercury B2 双臂机器人，15 Hz；3 个 Intel RealSense D435 相机（两个臂载近距视角 + 一个第三人称视角）；每个腕部一个六轴力/力矩传感器（论文 §IV-A，Fig. 3）。

**任务与阶段分解**：

| 任务 | 非接触段 | 接触段 | 成功判据 |
|------|----------|--------|----------|
| pipette tip attachment | 对准 tip 锥面与目标 tip | 下压直到稳固就位后回撤 | 微吸管回撤后 tip 仍稳固安装 |
| bimanual pipette aspiration | 右臂定位吸头入液；左臂对准按钮 | 按压并释放活塞按钮完成吸液 | 完成有效吸液动作 |
| whiteboard wiping | 抓取橡皮 | 建立接触、保持法向接触擦拭 | 标记被擦除且橡皮保持有效接触 |

**数据量**：tip attachment 130 条演示；aspiration 与 wiping 各 50 条（论文 §IV-A）。

**评测协议**：

- 主对比：每个方法、每个任务 **20 次真机试验**；试验前物体在预定义工作空间内随机放置；所有方法共用同一组测试摆放位置。
- 泛化：**每任务 10 次试验**，全部在演示中未出现的抓取高度上；tip attachment 全为 Low 条件，aspiration 为 5 次 High + 5 次 Low 合并报告（论文 §IV-C，表 II）。
- 指标：整体成功率 + 非接触阶段成功率 + 接触阶段成功率（接触阶段以非接触成功为条件）；aspiration 额外报告成功试验上相对 1,000 μL 参考体积的平均绝对误差（MAE）。
- 课程与训练常数：σ_max=4.0，p_max=0.5，S_w=1,000，S_d=29,000，训练 30,000 步，batch size 8；δ_task 分别为 5.0 / 2.0 / 4.0 N；(n,m) 分别为 (10,25) / (20,20) / (40,40) 帧。
- 路由：主对比中两个双专家方法在 tip attachment 与 aspiration 使用论文所述自动路由器；**wiping 使用手动触发**切换到 contact expert，且双专家变体共用同一路由协议（论文 §IV-A）。

⚠️ 编辑注：volume MAE 只在成功试验上统计。例如 Global FAC 变体 aspiration 成功率仅 5%，其 420.0 μL 的 MAE 建立在一个很小的分母上，不宜与其他变体直接横向比较。

|------|------|
| 接触阶段大幅提升 | 接触条件成功率 93.3%（14/15）、50%（10/20）、90%（18/20） |
| 整体成功率领先最强基线 | 70% / 50% / 90%，分别高出 40 / 20 / 20 个百分点 |
| 非接触行为基本保全 | 75% / 100% / 100%（tip attachment 相比 π0.5 的 90% 有下降） |
| 未见抓取高度下的泛化 | 两个 pipette 任务均为 5/10 = 50%，基线大多为 0–10% |
| 状态掩码是关键 | 去掉 state masking 后 15%，完整版 70%（tip attachment，各 20 次试验） |

**失败模式（论文报告）**

- tip attachment 上，基线常见失败是插入力不足、tip 脱落、反复插入回撤；DEFT-VLA 在进入接触的 15 次中完成 14 次。
- aspiration 上，DEFT-VLA 完成 10 次有效吸液（最强替代方案为 6 次），残余失败主要是反复按压或专家切换时机错误。
- wiping 上，20 次中 18 次成功，**仅有的 2 次失败由接触力过大造成**。
- 全局 FAC 会把力注意训练扩散到准备阶段，直接破坏视觉主导行为（aspiration 非接触 35%，wiping 50%）。

### 6.1 隐含假设 (Hidden Assumptions)

- **δ_task 可迁移**：三个任务的接触阈值是分别手调的 5.0 / 2.0 / 4.0 N。新任务、新传感器或不同腕部刚度下需重新标定，论文未给出标定方法。
- **力信号在演示中能可靠区分接触/非接触**：整条数据管线依赖式 (4) 的阈值判定，但未报告误标率或对阈值扰动的敏感性。
- **stage estimator 与部署分布一致**：路由器用同一批演示的接触标签训练；在泛化实验中表现尚可（表 II），但未做显式的路由器错误率分析。
- **视觉细节与机器人状态是主要捷径**：消融只在 tip attachment 上验证了 state masking 的必要性，未在其他两个任务上重复该消融。
- **手动切换是临时手段**：wiping 的手动触发说明自动路由在该任务上未达可用状态，结论不能外推为"自动路由已通用"。
- **backbone 无关性未验证**：所有方法都建立在任务适配的 π0.5 上，结论不必然迁移到其他 VLA 主干。

## 7. 与相关工作对比 (Comparison)

| 方法/路线 | 关注点 | 力觉进入策略的位置 | 训练方式 | 适用场景 |
|-----------|--------|--------------------|----------|----------|
| FoAR | 何时让力影响策略 | 用预测的未来接触调制力融合 | 单策略 | 接触丰富操作 |
| Reactive Diffusion Policy | 高频物理反馈 | 快速触觉/力条件回路 | 慢-快双环 | 需响应性接触控制 |
| ForceVLA | 让力在行为上有用 | FVLMoE 在动作生成内部做模态/阶段路由（单策略） | 单策略内路由 | 接触丰富操作 |
| FACTR / CRAFT | 抑制捷径 | 力注意课程（全局作用于单专家） | 课程式后训练 | 接触丰富策略学习 |
| Force Policy | 分离自由空间与接触 | 视觉引导自由运动 + 高频接触控制分离 | 分模块 | 混合力位控制 |
| LIFT（论文 §II-B 提及） | 力的反应式注入 | 加一个由原 action expert 初始化的力条件反应专家 | 后训练加速 | 力注入 |
| **DEFT-VLA（本文）** | 阶段局部化 + 捷径抑制 | **在两个独立参数化的动作专家之间切换**，课程只作用于 contact expert | 两阶段，冻结 VLM 与 base expert | 视觉准备 + 力敏感接触的任务 |

与最接近的 ForceVLA 的差别在于：ForceVLA 在**单一策略内部**做模态与阶段路由；DEFT-VLA 在**两个分别参数化的专家之间**做显式切换，从而让力导向优化不触碰已适配的视觉运动能力（论文 §II-B）。

🎯 **面试 Tip**：被问到"这篇和 ForceVLA/FACTR 有什么本质区别"时，一句话——**FACTR 管'让模型用力'，ForceVLA 管'什么时候用力'，DEFT-VLA 管'在哪里用力'：把力觉专精隔离到一个只吃接触段数据的独立专家，并用同一退火系数同时压掉视觉与状态两条捷径。**

## 8. 精读建议 (Reading Guide)

- **值得精读原文的人**：
  1. 做力觉/触觉 VLA 的研究者——§III-B 的力 token 形式与接触段切分可直接复用；
  2. 需要把多模态后训练接入已有 π0.5/OpenVLA 类基座的工程师——§III-A 的两阶段冻结协议是最小改动路径；
  3. 研究模仿学习捷径（causal confusion）的人——§III-C 的 state-token masking 是一个便宜且可独立复用的技巧。
- **建议章节路径**：先读 §III-A + §III-B（架构与力 token，决定你能不能抄）→ 再看 §IV-B 表 I 与 §IV-D 表 III（数字与消融，决定它值不值得抄）→ §II-B 可略读，重点是理解它相对 ForceVLA 的定位差异。
- **不值得精读的理由**：如果你不做机器人学习、或已经在用多专家 + 阶段路由的成熟系统，读摘要与表 I 即可——本文的主要贡献是"局部化"这一设计选择，而不是新的融合算子或新的基座模型。
