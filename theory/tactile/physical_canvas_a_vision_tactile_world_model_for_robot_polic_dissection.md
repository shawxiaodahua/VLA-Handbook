### 1.1 系统对比概览 (System Component Comparison)

### 1.2 关键机制 (Key Mechanism)

- **图像原生模态渲染**：marker 位移是每片 35×20 网格、700 个 marker 相对回合首帧的三维偏移 Δq；把 x/y/z 分别映射到 R/G/B，按固定尺度 s=0.06 裁剪归一化后当成一张图。任务状态则用“颜色表任务、纹理表结果”的低频条纹图表示。这样所有模态共享同一个 Wan VAE 和同一个时空 Transformer，不需要额外触觉编码器。
- **action 作为空间对齐的运动图**：用 URDF + 相机内外参把双臂关节目标投影成与 RGB 同裁剪同视角顺序的线框序列，经同一个 VAE 编码后在**位置逐 token 相加**到噪声画布上；唯独任务状态 token 位置不加（M_i=0），迫使状态预测从其他模态的自注意力里推出来。
- **首帧锚定 + 滚动参考**：整段 rollout 固定回合首帧 RGB anchor（走 cross-attention），当前多模态参考 r 由上一个 chunk 的末帧更新（走 observed reference tokens），避免长程漂移。
- **三重一致性后训练**：像素级监督管不住“语义一致性”，所以在图像空间解码出干净画布估计，再用冻结奖励模型回传梯度。

⚡ **Eureka Moment**：把“触觉”当成一种**视觉外观**而不是一种新模态——光学触觉图像和自然图像一样具有局部空间相关性和平移等变性，因此大规模视频先验可以直接迁移，工程上省掉了一整套触觉编码器与适配层。

## 2. 数学核心 (Math Core)

📌 **Napkin Formula**（一行抓住本质）：

```
世界模型 = 一张共享画布上的 action-conditioned flow matching + 三个冻结奖励模型的一致性约束
```

**（a）预测目标**：给定首帧 anchor、当前参考和未来 H 步动作，预测未来 H 帧多模态观测。

```
p_θ(o_{t+1:t+H} | o^cam_0, o_t, a_{t:t+H})
其中 a_{t:t+H} 是当前构型加 H 个未来目标构型，共 H+1 个状态
```

**（b）画布拼接与动作融合**：

```
x_t = Rasterize(o_t) = Concat_v [ I^cam_t, I^tac_t, g_disp(M^tac_t), g_state(s_t) ]
z̃_τ,i = z_τ,i + M_i · z^a_i,   M_i = 0 若 i 属于任务状态 token 位置，否则 1
```

**（c）flow matching 损失**（τ=0 为干净数据，τ=1 为噪声）：

```
z_τ = (1-τ)·z + τ·ε,  ε ~ N(0, I)
u_τ = ε - z
L_FM = E_{z,ε,τ} [ || v_θ(z̃_τ, τ; r, z_anc) - u_τ ||² ]
```

训练时噪声等级用移位采样（σ 量化为 10^-3 步长）：

```
u ~ U(0,1),  σ = 5u / (1 + 4u),  z_σ = (1-σ)·z + σ·ε
```

**（d）后训练：干净画布估计与两种损失**：

```
ẑ = z_τ - τ·v_θ(z̃_τ, τ; r, z_anc),   x̂ = D(P^{-1}(ẑ))
L_state   = E[ BCEWithLogits( ℓ̂_state / T_state , y_state ) ]      # 目标是真值帧经同一 RM 阈值化得到
L_q       = -E[ ρ_q( h_q(x_0, x̂) ) ],  q ∈ {scene, modality}        # 直接奖励最大化
```

**（e）GRPO 奖励与优势**（组大小 8，同一真实初始观测）：

```
R_i = 1[ p_i^end ≥ 0.7 ] ∈ {0,1}
A_i = (R_i - μ_G) / (σ_G + 1e-6)
ρ_i,k = exp( log π_θ(a_i,k|o_i,k) - log π_old(a_i,k|o_i,k) )
ℓ_clip = max( -A_i·ρ_i,k , -A_i·clip(ρ_i,k, 0.8, 1.28) )
ℓ_dual = min(ℓ_clip, -c·A_i) 若 A_i<0（c=3.0），否则 ℓ_clip
L_actor = mean over 有效位置 ℓ_dual
```

> 符号与原文一致：r 为当前多模态参考 token，z_anc 为首帧 anchor token，h_q 为各奖励模型自己的输入选择函数，ρ_q ∈ [0,1] 为一致性分数。

**直觉**：flow matching 那一路保证“能画出来且动作可控”；后训练那两路保证“画出来的东西在三件与任务成败有关的事上不自相矛盾”。作者特别强调 state 监督用真值帧的 RM 输出做二值目标，因此**失败轨迹也被保留**，不是把所有预测都往“成功”推。

## 3. 带数字走一遍：玩具例子 (Worked Example)

> 以下数值为**假设**，用于验算公式闭环，非论文实验数据。

**例 1：一个 flow matching 步与干净画布恢复**（标量版，验算式 (5)(7)）

设真实干净潜变量 z = 0.8，采样噪声 ε = -0.2，扩散时刻 τ = 0.5。

```
z_τ = (1-0.5)×0.8 + 0.5×(-0.2) = 0.4 - 0.1 = 0.3
目标速度 u_τ = ε - z = -0.2 - 0.8 = -1.0
若模型预测 v = -0.9，则 L_FM = (-0.9 - (-1.0))² = 0.01
恢复干净估计：ẑ = z_τ - τ·v = 0.3 - 0.5×(-0.9) = 0.75
与真值 0.8 的误差 0.05，正好等于 τ·(v - u_τ) = 0.5×0.1，验算通过
```

工程含义：这个 ẑ 要解码成图去喂奖励模型，所以**速度预测误差会被 τ 放大或缩小**——τ 小时误差小、τ 大时误差大，奖励梯度在扩散早期更“脏”。

**例 2：一组的 GRPO 优势与裁剪**（假设 group size = 8，3 成功 5 失败）

```
R = [1,1,1,0,0,0,0,0]，μ_G = 3/8 = 0.375
总体方差 = (3×0.625² + 5×0.375²)/8 = (1.171875 + 0.703125)/8 = 0.234375
σ_G = 0.4841
成功样本 A = (1-0.375)/0.4841 = +1.291
失败样本 A = (0-0.375)/0.4841 = -0.775
校验：3×1.291 + 5×(-0.775) ≈ 0 ✓
```

取一个成功样本（A=+1.291）：若 ρ=1.1，则 -Aρ = -1.420，-A·clip(1.1,0.8,1.28) = -1.420，裁剪不生效；若 ρ=1.5，则 -Aρ = -1.937，而 -A×1.28 = -1.652，取 max 得 -1.652，**裁剪生效**，梯度被封顶。这正是 PPO 式比率裁剪的作用：策略已经比旧策略更爱这个动作时，不再无限加大奖励。

**例 3：预测时序跨度按首末预测样本计**

数据以 10 Hz 同步，Δt = 0.1 s。式 (2) 给定当前参考 t，预测 t+1 到 t+H；单个 chunk 的 8 个未来帧到达 t+0.8 s，其首末预测样本内部跨度为 (8-1)×0.1 = 0.7 s（排除当前参考）。四个连续 chunk 到达 t+3.2 s，首末预测样本内部跨度为 31×0.1 = 3.1 s；0.7 s 与 3.1 s 只描述预测样本的内部跨度，不是历史上下文长度或记忆窗口。推理时 chunk 数不限于 4。

**笔者的条件性分析**（非论文结论）：按 10 Hz，8 条命令的执行跨度为 0.8 s；世界模型一个 chunk 预测 t+1 到 t+H 共 8 帧，到达 t+0.8 s，其首末预测帧内部跨度为 0.7 s。源文算法 F.2 明确用每段最后的 command 更新机器人状态、用生成末帧更新参考，因此这是固定的滚动调度而非“差一拍”缺陷；复现时应按该调度实现，重点关注 action 图渲染与状态更新的一致性。

数据来自**随机化策略 rollout**，刻意包含失败（漏抓、提前释放、交接不准、插入不到位），因为评估器必须建模非最优策略会访问的状态。三视图裁剪为 224×224 后横拼成 224×672；触觉用的是 Xense 内部相机相对参考的**差异图**（不是帧间差，也不是外部场景 RGB），400×700×3、8 bit。

**想象环境评测（世界模型内闭环）**
- 策略：ACT、FM、π0.5 三个家族；每个任务-策略对用**三个批次 × 20 个场景**，批次在不同时间采集，每任务共 9 个评估批次，每任务在汇总中权重相同。
- 指标：世界模型 rollout 成功率 vs 真机成功率，按任务算 Pearson，再取**任务级相关系数的算术平均**（不是把所有点混在一起算一个相关）。
- 结果（图 8 / §4.4，论文实测）：从 M2 到 M3（加 state 监督），均值 Pearson 0.602 → 0.885，均值 R² 0.413 → 0.791；增益在 Test Tube 与 Blocks 最大，Bottle 中等，Rubik's Cube 很小（M2 已接近上限）。作者据此主张“增益来自任务语义建模，而非像素级重建变好”，因为表 3 的低层重建指标是涨跌互现的。

**真实机器人评测（不是仿真）**
- 平台：ARX AC One 双臂，每臂 6 关节 + 夹爪，3 相机 + 4 片 Xense。
- 协议：表 4 数值为**三次运行的均值 ± 总体标准差**；成功判据由多位人类专家共同判定。
- 结果（论文实测，%）：π0.5 的 SFT 均值 59.1 → 在世界模型 M1 里 GRPO 后 67.5 → 在一致性后训练的 M4 里 GRPO 后 70.8；FM 的 SFT 均值 11.2 → 16.6 → 19.1。逐任务看，π0.5 用 M4 相对 M1 在 Blocks 与 Rubik's Cube 上分别多 6.6 与 10.0 个百分点，Bottle 反而从 90.0 降到 86.6；FM 的增益只在 Bottle 与 Blocks，Test Tube 与 Rubik's Cube 始终为 0（地板效应）。
- ACT 被排除在 GRPO 之外，理由是它不满足该实现所假设的扩散/flow-matching 形式；但 ACT 仍在评估实验里。

## 6. 能力与失败模式 (Capabilities & Failure Modes)

**能做的（有实测支撑）**
- 在四个真机双臂任务上生成视觉-触觉-状态一致的多模态未来，RGB 指标优于 EVAC / Open-Sora / WoVR（表 2：PSNR 21.172、SSIM 0.735、LPIPS 0.121、FID 21.459、FVD 116.274），末端执行器跟踪误差 0.685 px，比次优的 1.425 px 低 51.9%（这是论文自己给出的相对数，按其表格可复算）。
- 作为评估器：加 state 监督后，世界模型成功率与真机成功率的任务级相关性明显提高。
- 作为学习环境：冻结世界模型 + 冻结 State RM，用 GRPO 只更新策略，能在真机上带来平均成功率的提升。

**不能做 / 容易翻车的（区分论文实测与作者主张）**
- **只在自家四任务、单机器人平台、单一型号触觉传感器上验证**。跨机器人、跨传感器、跨任务的零样本迁移没有实验；作者只说共享视觉 VAE “suggests” 可迁移（表 1 是无触觉微调的 zero-shot 重建对比），这是主张而非跨域实验。
- **低层指标与高层一致性不同向**：表 3 里 M1→M2→M3 的 PSNR/LPIPS/FID/FVD 有涨有跌（例如 M2→M3 的 LPIPS 从 0.097 回升到 0.132，PSNR 从 20.975 略降到 20.699，但 FID、FVD、SSIM 改善）。用单一重建指标选模型会选错。
- **触觉事件检测并非单调改善**：M3→M4 的 Event F1 从 0.4550 掉到 0.4455，虽然 Contact MAE 与三项 marker MAE 都下降。作者没有解释这个 trade-off。
- **表 1 的对比是选择性叙述**：Wan VAE 在 PSNR（35.51 vs 31.72）和 LPIPS（0.0139 vs 0.0210）上优于 UniT，但 SSIM 是 0.9539 vs 0.9613，**低于** UniT；正文只提了前两项。
- **成功率整体偏低且方差大**：FM 在 Test Tube 与 Rubik's Cube 上 SFT 与 RL 后都是 0.0 ± 0.0，属于地板效应；表 4 的标准差与增益同量级（如 Blocks FM 25.0 ± 10.8 → 41.6 ± 6.2），三次运行的均值差不宜过度解读。
- **相关性证据的样本量小**：每个任务-策略对使用 3 批、每批 20 个场景，因此每任务为 3 个策略 × 3 批 = 9 个评估批次（180 次场景评估，不保证场景互不重复），再拟合任务级相关，估计量本身方差很大；“0.602 → 0.885”应理解为该设置下的观察值，而非稳定的评估器标定曲线（此为笔者的条件性分析）。
- **定性图不等于失效率**：图 6、图 7、图 18 的例子作者明确说是“diagnostic examples”，不是失败频率估计。

### 6.1 隐含假设 (Hidden Assumptions)

1. **触觉图像与自然图像同分布到足以复用视频 VAE**：表 1 只在一个外部触觉数据集（UniT 的 USB 3D-pose）上做重建对比，没有验证下游接触动力学的保真度。
2. **真值帧经 State RM 阈值化得到的二值标签，可以作为生成帧的监督目标**：这要求 State RM 在生成分布上不严重失准，但论文没有报告 State RM 在生成帧上的准确率。
3. **场景一致性对所有预测都成立**：所以 scene / modality 用奖励最大化（无条件），只有 state 用 BCE（有条件）。对于“场景本就该被大幅改变”的任务（例如把物体搬走），这个假设是否仍然成立没有被单独讨论。
4. **冻结世界模型 + 冻结奖励模型的 GRPO 不会奖励黑客**：奖励来自 State RM 对最后一帧的判定（阈值 0.7），策略可能学会“摆出被判成功的画面”而非真正完成任务；论文用真机成功率作为外部检验，但没有报告想象成功率与真机成功率的逐组偏差。
5. **动作 chunk 与视频帧节拍按固定调度衔接**：10 Hz 下 8 帧预测到达 t+0.8 s，首末预测帧内部跨度为 0.7 s；算法 F.2 用每段最后 command 与生成末帧更新机器人与参考。复现时需按此调度实现，而不是把它理解成源文未给对齐细节。

## 8. 精讀建議 (Reading Guide)

- **值得精讀原文的人**：
  1. 做生成式世界模型、想把它当评估器或 RL 环境的研究者——§3.3 的三重奖励设计是可复用的模板；
  2. 做视觉-触觉多模态、纠结“要不要单独触觉 encoder”的工程师——§3.2 与表 1 给了正反两面证据；
  3. 要判断“能不能用世界模型替代真机评测”的团队负责人——§4.4 的实验协议与样本量值得逐条核对。
- **建議章節路徑**：先读 §1 与图 3 建立全局 → 再读 §3.2 与公式 (3)(4) 理解画布与动作融合 → 然后 §3.3 与公式 (8)(9) 看奖励如何回传 → 最后 §4.4 / §4.5 与表 4 核对数字。附录 C（训练配置）、F（闭环调度）、G（GRPO 超参）在复现时必读，第一次读可跳过附录 I 的定性图。
- **不值得精讀的理由**：如果你不做机器人操作、或已熟悉“视频世界模型 + 奖励后训练”这套范式，读摘要与表 2、表 4 即可；本文的架构创新主要在模态摆放方式，而非新的生成模型或新的 RL 算法。
