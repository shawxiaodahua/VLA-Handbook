## 1. 核心架构/方法总览

### 1.1 系统组件对比概览

| 模块 | 输入 | 输出 | 论文设计 | 训练/推理差异 |
|------|------|------|----------|----------------|
| 视觉编码器 | 腕部 RGB `[B,H_o,3,H,W]` | 7×7 特征图 | 等变 ResNet | 相同 |
| 触觉编码器 | 触觉 RGB `[B,H_o,3,H,W]` | 7×7 特征图 | 等变 ResNet | 相同 |

补充接口：`H_o = 2`，`H_p = 16`，重规划前执行前 6 或 8 个动作；工作空间中心 `c_ws = (0, 0, 0.8)` 在归一化前从末端位置与平移动作中减去。动作 `a_t = (x_t, r¹_t, r²_t, γ_t) ∈ R¹⁰`，即 3 维平移 + 两个 3 维旋转轴 + 1 维夹爪。`l_max = 6` 时单通道球谐系数 49 个，SO(3) 系数 455 个。

### 1.2 关键机制

- **为什么先投影到球面**：作者观察到腕部相机与触觉传感器都刚性固连在末端执行器上；全局工作空间旋转会改变“传感器到世界”的变换，但传感器局部观测（相对相机-物体几何、局部触觉形变）保持不变。于是局部观测可以先在传感器坐标系里编码，再用末端朝向一次性旋转到工作空间。
- **为什么触觉用交叉注意力而不是拼接**：触觉 RGB 像素对应的是接触形变模式，不是观察方向；若沿用视觉的高斯方向先验会引入错误的空间假设。用视觉 token 作 query、触觉 token 作 key/value，可以让每个视觉方向按内容取触觉证据，同时保持球面索引不变（命题 1）。
- **为什么用有限群**：精确的连续 SO(3)/SO(2) 等变在实现上被离散化为有限子群 `I_60`（二十面体，60 个采样）或 `C_8`（绕重力轴 8 个采样）。作者明确说明：等变保证对选定有限群精确，是对连续对称性的实用离散化。
- **为什么用扩散**：动作块存在多模态，扩散策略适合建模多峰动作分布；等变解码器把带噪动作块与观测条件都表示成 steerable 特征，平移与两个旋转轴作向量、夹爪作标量。

⚡ **Eureka Moment**：把触觉从“全局条件向量”改成“球面上的方向条件”，并且放在谐波投影之前融合——这样触觉证据会随着工作空间旋转一起变换，而不是被当成与几何无关的额外特征拼进去。

## 2. 数学核心

📌 **Napkin Formula**（一行抓住本质）：

```
π(g·O) = g·π(O)   ← 工作空间等变目标；再靠"球面投影 + 触觉查询 + Wigner-D 校正"把它实现
```

**目标**：学习一个视觉-触觉策略，使观测被对称群元素 `g` 变换后，输出动作也按同样方式变换。

**融合与校正公式**（与论文 §3.2 一致）：

```
q_i = W_q v_i,   k_j = W_k τ_j,   u_j = W_u τ_j
α_ij = softmax_j( q_iᵀ k_j / sqrt(d_h) )
m_i  = Σ_j α_ij u_j
f_i  = LN( v_i + ψ([v_i, m_i]) )          ← 触觉条件化后的球面 token

C_t  = Σ_i f_i Y(s_i) w_i                 ← 球谐投影，w_i 为求积权重
ĉ_ℓ,t = D^ℓ(R_t) c_ℓ,t                    ← 用末端朝向把局部表示旋到工作空间
```

**扩散损失**（论文 Eq. 5）：

```
L_diff = E[ ‖ Γ_θ(A_t^k, E_θ(O_t), k) − ε ‖₂² ]
```

| 符号 | 含义 |
|------|------|
| `O_t` | 观测历史 `{o_{t−H_o+1}, …, o_t}`，`o_t = (I_t, T_t, p_t)` |
| `I_t`, `T_t`, `p_t` | 腕部 RGB、触觉 RGB、本体感觉状态 |
| `A_t` | 动作块 `{a_t, …, a_{t+H_p−1}} ∈ R^{H_p×10}` |
| `v_i`, `τ_j` | 视觉/触觉球面 token，各 P 个 |
| `D^ℓ(R)` | 谐波次数 ℓ 的 Wigner-D 表示 |
| `Γ_θ`, `E_θ` | 去噪网络、观测编码器 |
| `k`, `ε` | 扩散时间步、注入的高斯噪声 |

**直觉**：命题 1 保证触觉融合不会打乱视觉球面的方向索引——对视觉 token 做置换 `Π`，融合输出也恰好被同一个 `Π` 置换。所以“加触觉”不会破坏后面谐波投影所依赖的球面结构；而用 `R_t` 左乘谐波系数，则把“传感器局部不变”转换成“工作空间等变”。

## 3. 带数字走一遍：玩具例子

> ⚠️ 以下为**假设性玩具例子**，数值由我设定，用于验算命题 1 的置换性质；不是论文实验。

设一个极简情形：3 个视觉 token、2 个触觉 token，每个 token 是 1 维标量，`W_q = W_k = W_u = 1`，`d_h = 1`。

```
v = [1.0, 2.0, 3.0]
τ = [1.0, 0.0]
```

注意力分数 `q_iᵀk_j`（行=视觉 token，列=触觉 token）：

```
行1: [1.0, 0.0]
行2: [2.0, 0.0]
行3: [3.0, 0.0]
```

逐行 softmax：

```
行1: [0.7311, 0.2689]
行2: [0.8808, 0.1192]
行3: [0.9526, 0.0474]
```

因为 `u = τ = [1.0, 0.0]`，所以 `m_i = α_i0`：

```
m = [0.7311, 0.8808, 0.9526]
```

现在对视觉 token 做置换 `Π`（交换第 1、3 个）：`v' = [3.0, 1.0, 2.0]`。逐行 softmax 后：

```
m' = [0.9526, 0.7311, 0.8808] = Π m
```

验算：`m'` 确实是 `m` 按同一置换重排。`ψ`、残差和 LayerNorm 都是逐 token 操作，所以 `f' = Π f`。命题 1 在这个玩具设定下成立。**直观结论**：触觉可以改变每个方向上的特征内容，但不会改变“哪个特征对应球面哪个方向”。

再验算两个工程数字：

- 延迟：`I_60` 与 `C_8` 的 VISTA 模型侧延迟分别为 71.54 ms 与 63.74 ms（论文 Table 6，RTX 3090，batch=1，DDIM-8）。差值 `71.54 − 63.74 = 7.80 ms`；组采样数之比 `60/8 = 7.5`。也就是说 7.5 倍的群采样只带来约 12.2% 的模型侧推理延迟增长（7.80 / 63.74 ≈ 0.122），因为 U-Net 在组样本间共享权重。
- 执行窗口：10 Hz 下执行 6 个动作 = 0.6 s，8 个动作 = 0.8 s。单次推理 71.54 ms，窗口内理论上可完成 `600 / 71.54 ≈ 8.4` 次推理。瓶颈不在模型算力，而在“执行完一个 chunk 才换新触觉”的开环窗口。

## 6. 能力与失败模式

**能做到**（论文实测）：

- 在触觉信息量大的任务上提升显著：Lift Bottle 从 ISP 的 15.0% 升到 80.0%（+65 点）；Put Bottle in Shelf 从 77.5% 升到 87.5%。
- 融合方式优于替代方案：8 任务均值 ISP 68.1%、VISTA-global-`l0` 69.4%、Early Fusion 72.8%、ISP+Concat-Tac 74.1%、VISTA 80.9%。VISTA 比最强替代融合高 6.8 点，比纯视觉 ISP 高 12.8 点。
- 数据效率：50 demo 的 VISTA（80.9%）比 100 demo 的 EquiDiff + Tac（75.6%）高 5.3 点；加到 100 demo 后 VISTA 到 84.7%（+3.8 点）。
- 真机上对 sustained contact 的任务有效：Erase 9/10、Insert pencil 8/10。

**做不到 / 做不好**：

- **插入类任务增益小**：Insert HDMI +7.5、Insert Hole 0.0、Insert Tube +2.5、Pull Out Key +5.0。作者归因：触觉在有效接触后才更有信息量；且 VISTA 不像 EquiTac 那样显式建模接触内在几何，无法用触觉纠正接触前的视觉错位。
- **紧公差真机任务仍难**：Insert USB 只有 5/10，作者明确说紧公差是原因。
- **不是高频触觉闭环**：0.6–0.8 s 才用一次新触觉，可能漏掉瞬态滑移或接触变化；作者未研究更短 chunk 的权衡。
- **等变是离散且局部的**：保证只对选定有限群精确；不提供任意手内旋转的触觉内在等变。

### 6.1 隐含假设

1. **传感器刚性固连**。腕部相机与触觉传感器必须刚性安装在末端执行器上；固定外参可被学习模块吸收，但外参变化会破坏论证。
2. **联合旋转后局部观测不变**。作者假设机器人-物体-传感器一起旋转时，传感器局部视觉与触觉观测在校正前保持不变；背景/光照变化、重力相关接触、夹爪内滑移、标定误差、外部相机都会违反这一假设。
3. **任务对称性能被有限群近似**。`I_60` 或 `C_8` 是作者按任务几何预先选定的，不是自动学出来的；未来工作才提自动选择任务对称性。
4. **触觉 RGB 到空间方向的映射可学习**。触觉球面投影从零学、不用高斯先验；这等于假设数据足以让网络自己发现触觉像素与接触方向的关系。
5. **单种子 + 小样本评测**。仿真单种子、真机每任务 10 次试验；作者没有报告多种子方差。

## 7. 与相关工作对比

| 方法 | 是否工作空间等变 | 触觉如何进入 | 动作生成 | 仿真 50 demo 均值 |
|------|------------------|--------------|----------|---------------------|
| ManiFeel | 否 | 独立 ResNet 编码后与本体感觉拼接，作全局条件 | 1D 扩散 U-Net | 48.8% |
| VITAL | 否 | CLIP 视觉 + GelSight 触觉编码器在 transformer 中融合 | ACT CVAE transformer | 43.8% |
| UniVTAC | 否 | 触觉重建预训练编码器，左右两路触觉 | ACT | 21.3% |
| EquiDiff + Tac | 是（`C_8`） | 触觉特征视为 trivial `C_8` 表示，与本体感觉拼接后条件化 | `C_8` 等变扩散 U-Net | 65.0% |
| EquiTac | 指尖局部（`SO(2)` 法向图） | 触觉法向图等变网络，输出角度残差修正基策略 | 残差式 | 未在本文同协议评测 |
| VISTA | 是（`I_60` / `C_8`） | 触觉球面 token 被视觉 token 跨注意力查询，再谐波投影 | 有限群等变扩散 U-Net | **80.9%** |

对比要点：EquiDiff + Tac 与 VISTA 的差别不是“有没有触觉”，而是“触觉在球面融合之前进还是之后进”。EquiDiff + Tac 有等变解码器和触觉输入，但没有球面触觉提升、没有视觉-触觉球面融合、也没有 `I_60` 实例化；作者用 15.9 点的差距论证“只有等变解码 + 触觉输入不够”。

**面试 Tip**：如果被问“VISTA 和 EquiDiff + Tac 差在哪”，一句话答：EquiDiff + Tac 把触觉当全局条件，VISTA 把触觉当球面上的方向条件，并且放在谐波投影之前融合，所以触觉证据会跟着工作空间旋转一起变换。

## 8. 精读建议

- **值得精读原文的人**：
  1. 做视觉-触觉策略、想在低示教预算下提升接触丰富任务的研究者；
  2. 做等变策略、关心“触觉怎么进入等变架构”的工程师；
  3. 要评估把球面表示 + 扩散解码迁移到自家机械臂可行性的工程团队。
- **建议章节路径**：先读 §3.2（球面投影、融合、命题 1）→ 再看 §4.2 与 Table 8–10（融合消融与数据效率）→ 最后看 §5 局限性与 §A.9 延迟。§2 相关工作可在需要定位与 EquiTac/EquiDiff 的关系时再回看。
- **不值得精读的理由**：如果你不做机器人学习、或已熟悉等变扩散策略且只关心大模型 scaling，读摘要与 §1 贡献列表即可；本文的实验域是单臂桌面接触丰富任务，不外推到移动/双臂/人形。
