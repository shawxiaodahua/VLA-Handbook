## X-Ray

VLA-Touch 不是把触觉 token 塞进 VLA 继续预训练，而是把触觉拆成两个接口：高层用 Octopi 把 GelSight 序列读成语言，交给 GPT-4o 重规划；低层用 BRIDGeR 以 RDT-1B 动作为起点做触觉条件精炼。它的工程赌注是模块化、松耦合，在触觉增强阶段固定 base VLA；RDT 此前做过无触觉微调；代价是外部 VLM API、额外控制器训练、8 Hz 控制频率和有限的真机评测。

## 问题与定位

视觉 VLA 能读场景和指令，却很难从图像判断物体软硬、表面粗糙度、接触事件和摩擦力。触觉能补这些信息，但把触觉塞进大规模 VLA 很麻烦：现有 VLA 多数只训练过视觉、语言和动作，没有触觉输入机制；大规模多模态触觉数据也稀缺。

VLA-Touch 的选择是“先完成无触觉 VLA 适配，再固定底座接入双层触觉模块”。作者把系统类比为三个部分：VLM 任务规划器类似前额叶的高层认知；Octopi 触觉-语言模型类似次级体感皮层；触觉增强控制器类似后顶叶皮层。这个类比是解释框架，不是实验证据。

## 方法：两层触觉，两种接口

### 高层：触觉变成语言，供 VLM 重规划

任务规划循环如下：GPT-4o 接收任务目标、场景图像、历史指令和触觉语言反馈，输出一句原始动作指令以及“还需要获取什么信息”。RDT-1B 执行该指令对应的动作块。指令完成、超过最大执行步数或执行失败后，系统读取最近触觉观测，用 Octopi 把 6 帧 GelSight 信号转成物体属性语言描述，再交给 GPT-4o 生成下一条指令。

力信号不是 Octopi 的原生输出。作者单独用 7×9 marker 阵列的位移估计力向量，聚合成低维触觉量 m_t=(X,Y,M)，并把参考力向量一起给 GPT-4o，帮助它判断杯子空/满等相对力场景。也就是说，高层反馈由“语言属性”和“数值力”混合组成，不是纯语言。

### 低层：以 VLA 动作为起点做插值精炼

低层采用 BRIDGeR 的随机插值控制器。它不直接从高斯噪声去噪，而是从 VLA 生成的动作块出发，在触觉和状态条件下把动作分布“桥”到专家动作分布。控制器输入包括：VLA 源动作块、DINOv2 提取的 RGB 视觉嵌入、机器人本体状态、低维触觉力向量。输出是精炼后的动作块。

推理时，VLA 生成 64 步动作块，控制器只精炼前 48 步，然后滑动窗口继续；控制器最多以 8 Hz 更新，精炼动作由笛卡尔 PD 控制器执行，芒果削皮任务改用阻抗控制器。

## Eureka Moment

真正巧妙的不是某个新网络，而是接口分解：触觉对 VLM 说“人话”，对控制器说“力向量”。前者复用 GPT-4o 的语义推理，后者复用 BRIDGeR 的分布桥接；触觉增强阶段固定 base VLA，减少对大规模触觉预训练的需求，但仍需本任务示范和控制器训练。代价是系统变成多模块拼装，错误会分布在规划、触觉语义、动作精炼三个环节。

## 数学核心

### 目标

作者要让控制器学习：给定 VLA 源动作块 a[t:t+Ta] 和观测条件 z_t，输出接近专家动作 a_exp[t:t+Ta] 的精炼动作。z_t 包含本体历史、DINOv2 视觉历史、触觉历史，历史长度 n=2，动作块长度 Ta=64。

### 公式（作者附录 C 的 BRIDGeR 表述）

```text
a_τ = I(τ, a_0, a_1, x) + γ(τ) z
I(0, a_0, a_1, x) = a_0
I(1, a_0, a_1, x) = a_1
γ(0) = γ(1) = 0

d a_τ = b_F(τ, a_τ, x) dτ + sqrt(2 ε(τ)) dW_τ

min_θ (1/|D_VLA|) Σ || a_exp[t:t+Ta] − π_I(â[t:t+Ta] | a[t:t+Ta], z_t; θ) ||²
```

### 变量

- τ：连续插值时间，从 0 到 1。
- a_0：源策略动作，本文中是 VLA 生成的动作。
- a_1：目标策略动作，本文中是专家示范动作。
- x：条件变量，包括视觉、本体和触觉条件。
- z：标准高斯噪声；γ 控制噪声日程。
- b_F：速度函数；ε 控制扩散强度；W 是 Wiener 过程。
- π_I：插值控制器；θ 是控制器参数。
- D_VLA：配对构造的训练集，包含 VLA 动作、观测条件和专家动作。

### 直觉

传统扩散策略从噪声开始生成动作；BRIDGeR 从“已经会做大部分动作”的 VLA 分布开始，只学习触觉带来的修正。作者主张这能用更少扩散步数获得更好效果，因为源分布已经包含大量任务先验。这个主张是作者解释，不是本文独立验证的结论。

### Napkin Formula

```text
精炼动作 ≈ 在触觉条件 z 下，从 VLA 动作 a 桥接到专家动作 a_exp 的条件分布
```

换句话说：不是“触觉重新生成动作”，而是“在 VLA 先验附近，用触觉把动作拉向专家分布”。

## 可计算玩具例子（示意，不是作者实验）

### 例 1：线性插值路径

设某个一维动作坐标为 VLA 源动作 a_0=0.80，专家动作 a_1=0.74。取线性插值：

```text
I(τ) = (1−τ)·0.80 + τ·0.74，γ=0
```

走 4 个等距步：

```text
τ=0.00 -> 0.800
τ=0.25 -> 0.785
τ=0.50 -> 0.770
τ=0.75 -> 0.755
τ=1.00 -> 0.740
```

这只说明“从源动作端点走到目标动作端点”的路径概念；真实控制器不是手工线性插值，而是学习到的条件桥。

### 例 2：触觉力向量压缩

为演示二维向量范数，额外假设 X=0.30、Y=0.40 且 M 定义为合力向量的欧氏范数；则：

```text
M = sqrt(0.30² + 0.40²) = 0.50
m_t = (0.30, 0.40, 0.50)
```

这是数学示例，不是作者力估计实现的复现。论文 §3.2 说明先估计每个 marker 的向量，再聚合为 (X,Y,M)，但未在该节展开 M 的计算式；向量求和后取范数与逐点范数求和不能混同。这里的 0.50 没有牛顿单位。

## 工程实现边界

准确说法是：base VLA 没有用触觉数据微调，但不是“所有模块完全不训练”。RDT-1B 先在无关 Franka 数据上微调 100k 步、约 80 小时以对齐动作空间；再在每个任务数据上无触觉微调 20k 步、约 16 小时；BRIDGeR 控制器用配对数据有监督训练；Octopi 是预训练模块；GPT-4o 是外部 API。

数据采集为动觉示教：Cup 的 Pick 40 条、Place 60 条，合计约 8 分钟；Wipe 的 Pick 40 条、Wipe 60 条，约 15 分钟；Peel 的 Pick 60 条、Peel 120 条，约 30 分钟。传感器以 10 Hz 采集，包括两路相机、GelSight 和机器人本体状态。

硬件为 Franka Emika Panda、Robotiq 2F-140 夹爪、单侧 GelSight Mini、两台 RealSense，推理工作站为 RTX 4090。控制器最多 8 Hz，未利用作者提到的 ≥25 Hz 高频触觉信号。

开源范围要按 README 原话理解：提供数据集和控制器 checkpoint 链接、RDT-1B 安装与若干训练/测试脚本；处理后的数据集可联系作者；完整推理脚本仍写着“our version will release soon”。因此不能写成“一键全链复现已开放”。README 的 arXiv 徽章文本出现 2410.07584，但链接与论文标题指向 2507.17294；本文以 arXiv 2507.17294v2 为准，不采用徽章编号。

工程建议（非作者结论）：把高层语言反馈和低层力信号分开记录，便于判断失败是“选错物体”还是“接触控制失败”；先校准力参考向量再跨物体比较；评测时固定 Table 1 与 Table 2 的口径，不混比；把每项 20 次试验当小样本，报告原始计数。

## 数据与评测

### 规划结果

作者报告（Figure 3C，每条件 20 次）：仅给场景图时，GPT-4o 常回答“无法判断”，强制选择接近随机。给原始触觉图，粗糙度识别 100%，力 50%，硬度 60%。结构化触觉反馈条件下，力判断为 90%，硬度为 75%。其中硬度使用 Octopi 相关属性反馈；力判断单独使用 marker tracking 估计值及参考向量，不是 Octopi 的力预测。

### 消融与失败模式

Table 1 还显示：去掉触觉（w/o Touch）对接触密集阶段影响更大；去掉视觉（w/o Vision）主要影响空间定位和抓取位置。作者报告 cup placement 去触觉下降 50%、wipe 下降 42%、peel 下降 50%；去视觉 cup placement 下降 30%。

失败模式包括：Cup 中 RDT 常在闭合夹爪前把杯子推走，Residual 控制器出现系统性后偏，导致抓取不稳和洒水；Wipe 中常见边缘抓取，Residual 偏向只擦中央；Peel 中 RDT 常滑动不切割，Residual 容易中途抬起削皮器。Interpolant 被作者描述为接触保持更好，但这些是任务级观察，不是统计检验。

Appendix B 还有一个重要权衡：在擦洗任务中，完整语言描述和连续分类器都达到 100%；但在芒果硬度这种细微差异上，语言描述只有 60%，连续分类器为 75%。这说明“触觉转语言”并非越语言越好，离散化可能丢失细粒度硬度信息。Appendix B 本段未单独列出这组格式消融的试验次数；不能仅凭主实验 20 次自动推定其分母。

### Hidden Assumptions

- 触觉只装在单侧手指，另一侧接触不可见；系统默认单侧信号足以支持决策。
- 力阈值和参考向量依赖当前杯子、夹爪和标定；跨物体复用不一定成立。
- GPT-4o 能稳定读懂数值触觉描述并做选择；提示词和外部 API 行为是系统变量。
- 专家示范覆盖任务，控制器训练分布覆盖评测状态；分布外动作未被证明可修。
- 主结果表的每项分母为 20；本次核读的 §4、Appendix B/C 未见针对这些比较的置信区间或显著性检验报告，不把作者的“显著”措辞升级为统计显著性结论。
- 控制最多 8 Hz，未利用 ≥25 Hz 高频触觉；动态接触场景的优势未被充分检验。
- 泛化主要覆盖物体位置、目标位置和样本差异；没有跨任务、跨传感器、跨本体的泛化结论。

## 基线比较与面试 Tip

规划基线有三组：GPT-4o 仅场景图；GPT-4o 加原始触觉图；GPT-4o 加 Octopi 语言反馈。控制基线有三组：RDT；RDT 加 Residual LSTM 控制器；RDT 加 Interpolant 控制器。双层消融有三组：w/o Planning、w/o Control、VLA-Touch。

面试 Tip：

1. 被问“这是不是端到端触觉 VLA？”回答：不是。base VLA 没有触觉微调，但控制器有训练，RDT 也做过无触觉任务微调；Octopi 和 GPT-4o 是外部/预训练模块。
2. 被问“为什么 Table 2 比 Table 1 低？”回答：Table 1 是操控终点，Table 2 是规划+操控整体，口径不同，不能混比。
3. 被问“语言反馈是不是最优？”回答：对粗糙度等明显差异，语言和连续输出都可能很好；对细微硬度，Appendix B 显示连续分类器 75% 高于语言 60%，语言有粒度损失。
4. 被问“能直接复现吗？”回答：数据集和控制器 checkpoint 有链接，训练/测试脚本部分开放；完整推理脚本 README 写明将发布，不能宣称一键全链复现。

## 结论

VLA-Touch 的价值不在“造了一个触觉基础模型”，而在系统分解：触觉对 VLM 说语言，对控制器说力向量，base VLA 在完成无触觉适配后，于触觉增强阶段固定。作者用 Cup/Wipe/Peel 三个接触密集任务展示了双层反馈的收益，并用消融说明视觉与触觉都重要。

证据边界同样清楚：单机器人、单侧 GelSight、每任务 20 次、8 Hz 控制、外部 VLM API、部分开源；没有跨传感器或跨本体泛化结论。把它当作“有部分复现资源的模块化触觉增强 VLA 研究原型”比当作“通用触觉 VLA 已解决”更准确。
