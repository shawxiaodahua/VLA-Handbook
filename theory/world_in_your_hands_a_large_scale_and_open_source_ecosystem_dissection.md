## 1. 核心架構/方法總覽 (Overview / Architecture)

WIYH 不是一个新策略模型，而是一套**数据基础设施**：可穿戴采集套件（Oracle Suite）+ 三阶段标注管线 + 双层质量验证 + 策略级评测协议。

### 1.1 系統對比概覽 (System Component Comparison)

| 模块 | 输入 | 输出 | 频率/时序 | 训练 vs 推理差异 |
|------|------|------|-----------|------------------|
| H-FPVHive（胸挂感知） | 第一人称视觉环境 | 2×鱼眼 + 2×针孔 RGB + 4×红外 | 硬件同步 | 仅采集期使用 |
| H-Gloves（手套动捕） | 手部运动 | Manus 手套 + 6 IMU + MCU + 3×鱼眼 | 硬件同步 | 仅采集期使用 |
| H-Backpack（背包算力） | 各模块数据流 | 计算/存储/供电（NVIDIA Orin） | 在线同步 | 仅采集期使用 |
| 自动动捕标注 | 红外 + RGB + IMU | 双手 6D 腕部位姿轨迹 | 离线重建 | 产出动作标签 |
| 标注管线 | 同步原始录像 | 原子动作 + 感知 + 视觉语言标注 | 离线三阶段 | 产出监督信号 |

### 1.2 關鍵機制 (Key Mechanism)

- **无外部基建**：不需动捕室或第三人称追踪，套件自带相对定位（H-FPVHive 的红外模块负责相对定位 H-Gloves），因此可以「随时随地」采。
- **采集吞吐**：论文报告约为遥操作机器人数据采集的 **5×**，日采集量从 150 提升到 720 episodes（§3.1）。
- **半自动标注**：用 Qwen2.5-VL-72B 提议时序边界与生成多样化指令，**人类标注员负责边界纠错、技能-物体匹配与指令一致性**（§3.2）。
- **双层验证**：动捕室真值（腕部位姿平均误差 < 5 mm）+ 野外重投影一致性检查（把估计的手骨架/轨迹投回第一人称视图，与手部掩码比对）（§3.3）。

⚡ **Eureka Moment**：**让「野外人类数据」有价值的不是采集规模，而是动作标签的毫米级精度与验证机制**——未经重投影过滤和人工验证的 WIYH*，在同等规模下几乎不带来增益。

## 2. 數學核心 (Math Core)

📌 **Napkin Formula**（一行抓住本质）：

```
π* = argmin_π  E_{(o,a) ~ D_robot ∪ D_ego} [ L(π(o), a) ],   s.t.  || a_ego − a_mocap || < ε
```

即：联合训练的目标就是在机器人数据与人类数据上最小化模仿损失，而**人类动作标签必须落在毫米级误差带 ε 内**，否则会污染监督。

**目标**：把「第一人称人类演示」当作可扩展的跨具身监督来训练操作策略。

**关键公式（重投影一致性检查，公式形式为本文方法的工程抽象）**：

```
e_reproj = (1/N) · Σ_j || Π_K( X_j ) − m_j ||₂
若 e_reproj > τ  →  标记人工复核或剔除
```

变量说明：

| 符号 | 含义 |
|------|------|
| Π_K | 相机内参 K 下的投影函数 |
| X_j | 第 j 个 3D 手骨架/腕部轨迹点 |
| m_j | 第一人称视图中对应手部掩码像素 |
| e_reproj | 平均重投影误差 |
| τ | 一致性阈值（超出则剔除） |
| L | 模仿学习损失（论文用 Fast-WAM 基座，具体损失见其原文） |

**直觉**：如果估计的 3D 手轨迹是错的，那么把它投影回图像时就会与「实际手在哪」的掩码对不上。这个廉价的自监督式几何检查，就是筛掉噪声动作标签的守门员——也正是 WIYH 与 WIYH* 的唯一区别。

## 3. 帶數字走一遍：玩具例子 (Worked Example)

以论文 Table 2 的杂乱多物体场景（500 robot clips）为例，看「加人类数据」的闭环：

| 配置 | 机器人片段 | 人类片段 | 成功率 SR |
|------|-----------|---------|-----------|
| 仅机器人 | 200 | 0 | 0.0% |
| 仅机器人 | 500 | 0 | 8.0% |
| 联合 | 500 | 800 | **60.0%** |

可计算的闭环：机器人数据从 200→500（+150%），SR 只从 0%→8%（+8 个百分点）；而**额外加 800 条人类数据（同任务、杂乱场景）**，SR 从 8%→60%（+52 个百分点）。

另一组（单物体 500 clips）：43.3% → 56.7%（+13.4 个百分点），验证人类数据能帮策略泛化到未见初始位姿。

真机迁移（Table 3，玫瑰插花 + 礼品打包）：无预训练平均 15% → 有 WIYH 预训练 70%，且在未见物体上提升尤其明显。

**直觉**：机器人数据「准但窄」，人类数据「广而野」——两者互补时，泛化增益远大于单纯堆机器人数据。

## 5. 數據與評測 (Data & Eval)

**数据组成**（表 1）：1,045 小时 / 125.4k clips，覆盖 10 个真实场景（宴会、洗衣、物流、酒店、百货、办公室、超市、工业、清洁、烛光晚餐），40+ 任务、100+ 操作技能、500+ 物体。

**标注类型**：校准视觉观测、3D 手/腕轨迹、手骨架、深度、掩码、任务与子任务语言、视觉语言监督（后两类仅子集）。

**评测设置（三组）**：

1. **任务匹配的 ego-robot 联合训练**：机器人数据在受限场景采，人类数据在杂乱多物体场景采 → 测泛化。
2. **RoboCasa 预训练**：EgoDex / VITRA / WIYH / WIYH* 四者对齐到 80K episodes，之后在 10% 官方演示上后训练 → 测预训练信号质量。
3. **真机迁移**：WIYH 预训练 + 两个真实任务后训练（玫瑰插花、礼品打包）→ 测物理世界有效性。

**关键结果**：WIYH 在**关节物体（articulated）任务**上最强；拾放任务对预训练分布不敏感。

## 6. 能力與失敗模式 (Capabilities & Failure Modes)

**能做**：
- 在杂乱多物体、未见初始位姿场景显著提升成功率（8%→60%）。
- 为关节物体等对时序切分敏感的细粒度任务提供有效预训练信号。
- 以 ~5× 吞吐低成本扩充演示数据，跨 10 场景/500+ 物体。

**不能做 / 失败模式**：
- **未验证数据反噬**：WIYH* 与 WIYH 同源、同规模，却明显落后且几乎无增益 → 噪声动作标签会抵消规模优势。
- 拾放任务上各预训练数据集差异小 → 说明并非所有任务都吃这一套分布。
- 跨具身迁移证据仅限桌面/单臂，未验证移动、双臂、人形平台。
- 无全手触觉（与 Ken 关注的「触觉 + VLA」方向直接相关：这是本文明确留出的空白）。

### 6.1 隱含假設 (Hidden Assumptions)

- 假设「人类第一人称操作动作」可与机器人动作域对齐（跨具身重定向）——论文称重定向下节在附录 D.1，但动作空间差异的真实误差未在主文量化。
- 假设人类操作者按 SOP 采集能代表真实操作分布——采集的标准化程度可能反而引入选择偏差。
- 假设重投影一致性高 = 动作标签可靠——几何一致不等于语义/动力学正确，闭合回路时仍需验证。
- 假设 Fast-WAM 基座能公平承载所有预训练数据集——基座选择可能偏置结论。
