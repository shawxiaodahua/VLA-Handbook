# 接触密集数据采集工程专题：人类手套、机器人触觉、手持传感指、力/肌电与仿真 / Contact-Rich Data Collection Engineering: Human Gloves, Robot Tactile, Handheld Sensing Fingers, Force/EMG and Simulation

> 整理日期：2026-10-25。观察窗口：2026-04-25 至 2026-10-25；窗口外项目为旧基础，另标 outside_window。本文核验公开材料（arXiv 摘要/HTML/PDF、项目页、GitHub README、数据集页面），但未下载大数据、未复现实验、未逐篇完整复现。所有项目为阅读/接入研究卡。凡标“本文建议/工程推断”处均为分析意见，非原文结论或已跑实验。

## 核心结论

1. **接触信号异构是接入第一障碍**：光学触觉（PolyUMI、HapTile、ViTaMIn、FreeTacMan）、压力阵列手套（TouchScale、EgoTouch、OSMO）、指尖力/力矩（OmniUMI、FACTR 2、ForceBand 的 sEMG+指尖力）与仿真 taxel 输出（Tactile Genesis、DexJoCo）不可互换；跨源融合前必须做物理量映射与时间锚定。
2. **时间同步是多数系统的隐含工程成本**：常用“最慢流插值 + 单一参考时钟”（TouchScale 的 30Hz 训练时间轴、PolyUMI 的 10Hz 策略时间轴、DexViTac 以触觉 60Hz 为全局锚点作语义对齐），但原始时间戳与重采样后的差异、SLAM/外参误差多未公开量化。
3. **发布状态普遍 unknown**：TouchScale、PolyUMI、HapTile、TouchAnything（EgoTouch）、RCT、ForceBand、FreeTacMan、DexViTac 均为“将公开/拟开源”或未给下载入口；代码许可≠数据许可，arXiv 论文许可不可外推。OSMO 的下载脚本仍标 TODO，HapTile 的 HF 页面查看器报 HDF5 打开失败且 README 为空。
4. **划分与监督粒度决定结论可信度**：RCT 显示帧随机划分会因同一次按压的近重复帧泄漏，去掉接触序列重叠后 Recall@1 下降 17.7 个百分点；材料留出后仅 25.1±6.1%（三次抽样平均）。TouchScale 无动作标签，训练用质检标签（Pass/Review/Reject 为逐手质检状态，取较严重手为回合结果）只用于筛除/送审，并非被拟合的监督目标；其下游监督来自机器人后训练任务。
5. **负结果与边界必须保留**：HapTile 报告加入触觉并非一致提升，部分配置反降；Tactile Genesis 指出当前真实 XHand1 灵敏度不足以学温度任务；Ego2Contact 仿真 Pen Cap Removal 预测触觉成功率仅 1.0%（GT 95.0%）；这些是选型与验收的约束，不是可忽略噪声。

### 人类手套（压力阵列）

<a id="p-touchscale"></a>
### TouchScale

- **日期/窗口状态**：arXiv v1 2026-10-07，v2 2026-10-08，in_window（首发为 v1 提交记录，v2 为修订版）。GitHub 提交记录最早 2026-10-04（qc 目录），项目页日期 unknown。
- **机制与监督**：双手触觉手套每只 880 taxel 覆盖五指与手掌，记录法向压力，配头戴 RGB-D（头部 RGB 与 depth 均 30Hz，深度提供度量几何）与双腕 RGB（均 30Hz）。每条记录含自我中心 RGB-D、腕部 RGB 与双手全掌触觉，**不含动作标签**。逐手质检用 VLM 盲视（不看触觉）判读腕视接触，输出 Pass/Review/Reject；这是筛选状态，不是被模型拟合的中间训练目标。下游策略仅做视觉-触觉中期训练，不做人手动作重定向。
- **边界**：机器人评测限单平台（xArm6 + BrainCo Revo 2）四任务，每任务 50 示教、20 次试验，规模有限；数据由第三方供应商采集、约 20 人，跨人群泛化未量化；未来触觉预测与动作预测误差仅弱相关（r=0.119）。
- **接入检查**：确认项目页数据是否已实际开放、分卷大小与数据许可；在小样本上跑 check_sync.py 验证六路流时间戳对齐与触觉基线噪声阈值，并核对训练用 30Hz 时间轴与原始时间戳差异（原始时间戳随数据发布保留）。
- **来源**：[arXiv abs](https://arxiv.org/abs/2610.10288)、[arXiv HTML](https://arxiv.org/html/2610.10288)、[GitHub](https://github.com/phai-lab/touchscale)、[项目页](https://touch-scale.github.io/)。数据访问 unknown：论文称将公开发布全部同步视觉-触觉记录与重建物体模型，但可见原文未给下载入口或可用性确认；数据许可 unknown（代码 MIT、n0-vtla 目录 CC BY-SA 4.0、N0-VTLA 权重受 Gemma 条款约束）。成功率 22.5%→57.5% 为论文/项目页自述。
- **深读**：[TouchScale 深读笔记](../theory/tactile/touchscale_500_hours_of_human_vision_and_touch_for_visual_ta_dissection.md)

<a id="p-touchanything-egotouch"></a>
### TouchAnything / EgoTouch

- **日期/窗口状态**：2026-05-13，in_window。项目页给出但数据集“将公开”，实际可下载性 unknown。
- **机制与监督**：EgoTouch 为 208 任务、1891 回合、约 20 小时、约 210 万帧的多视角自我中心视频，30Hz；硬件含头戴 RGB、双腕 RGB、Rokoko 动捕手套与定制压力手套（每手 256 通道 8 位串口），时间戳同步到 30Hz。监督为压力网格重映射（21×21 手形网格，217 有效单元）后的接触估计，按回合 8/1/1 与 seen/unseen 物体划分。
- **边界**：数据为佩戴触觉手套实采，作者自述存在手套外观偏置，不能等同裸手触觉；腕视角仍有遮挡与失败案例（如黑手套贴黑裤导致首帧误判接触）。
- **接入检查**：确认项目页是否真发布 HDF5/压力网格数据与逐条许可，核对 seen/unseen 划分是否公开，并检查 256 通道到网格的重映射参数是否随数据提供。
- **来源**：[arXiv abs](https://arxiv.org/abs/2605.13083)、[arXiv HTML](https://arxiv.org/html/2605.13083)、[项目页](https://jianyi2004.github.io/TouchAnything-Website/)。数据许可 unknown。

<a id="p-haptile"></a>
### HapTile

- **日期/窗口状态**：arXiv v1 2026-06-03，v2 2026-06-19，in_window。HuggingFace 数据集页面首次日期 unknown，undated。
- **机制与监督**：UR5e + Robotiq 2F-85，两指各装自研视触觉传感器，1726 条示范、38 任务、9 类技能，15Hz 采样，统一为 7D 末端增量动作。触觉表面运动由标记点光流估计，**离散映射为振动幅度**（二值力阈值）反馈给操作员，不是连续力反馈；监督为任务示教与语言指令。
- **边界**：采集限单一实验室场景，作者自述缺乏场景、光照与背景多样性；表 2 显示加入触觉并非一致提升（如 π0 在 Wiping a whiteboard 的 V+TM 达 100%，但 Pouring liquid 的 V+TM 为 0%），是选型约束。
- **接入检查**：核实 haptile-dataset.github.io 是否已上线、数据许可与下载方式；HF 页面 README 为空且查看器报 `file signature not found`，需手动检查仓库文件列表与 HDF5 文件头（可能是 LFS 指针误提交）。
- **来源**：[arXiv abs](https://arxiv.org/abs/2606.04825)、[arXiv HTML](https://arxiv.org/html/2606.04825)、[HF dataset](https://huggingface.co/datasets/HapTile2026/HapTile)。论文称将开源，实际可访问性与数据许可 unknown。

### OSMO

- **日期/窗口状态**：首次日期 unknown，undated（README 无日期）。

### 机器人触觉（视触觉/标记点/聚合压力）

<a id="p-rct"></a>
### RCT

- **日期/窗口状态**：2026-06-30，in_window。
- **机制与监督**：真实机器人按压采集，29,279 个触觉帧，122 种材料、7 个类别，三枚 DIGIT 传感器、多个接触位置。监督为**材料级**：每种材料一张参考图像与材料级描述词，非逐帧姿态条件视觉目标或帧级触觉描述。
- **边界**：采集限工业参考材料平面按压，不含任意几何、曲面或动态探索；同一按压内帧高度相关（相邻帧约 0.10mm 压入步长），帧随机划分会把近重复样本同时放入训练与测试。去掉接触序列重叠后触觉到文本 Recall@1 下降 17.7 个百分点；材料留出时三次抽样平均 25.1±6.1%。附录 E 指出有 1 个材料 ID 格式不一致，训练覆盖为 121/122，修正已入发布元数据。
- **接入检查**：到项目页与仓库核对数据是否真可下载、数据许可、是否提供接触序列 ID 与留出划分文件、121/122 材料 ID 修正是否已落地。
- **来源**：[arXiv abs](https://arxiv.org/abs/2606.31694)、[arXiv HTML](https://arxiv.org/html/2606.31694)、[项目页](https://faerber-lab.github.io/RCT/)、[GitHub](https://github.com/faerber-lab/RCT)。数据许可 unknown（论文 arXiv 许可不等于数据许可）。

<a id="p-freetacman"></a>
### FreeTacMan

- **日期/窗口状态**：首次日期 unknown；会议 2026-06-01 至 06-05，加入 Xplore 2026-09-30，undated（窗口内活动但无预印本首发日）。
- **机制与监督**：可穿戴夹爪带视触觉传感器，由人手佩戴直观操作；高精度光学追踪系统捕获末端位姿，同步视觉与触觉反馈。摘要称数据集含超 3000k 对配位姿视触图像、1 万条演示轨迹、50 个接触丰富任务——该数字需核对是否为笔误。
- **边界**：仅见 IEEE Xplore 摘要与引言，未见全文方法细节；开源仅为意向表述，未见具体代码库或数据链接。
- **接入检查**：核实 3000k 是 3,000,000 还是 3000 对，确认硬件与数据集实际发布仓库、许可类型、光学追踪位姿精度与触觉同步时延。
- **来源**：[IEEE Xplore](https://ieeexplore.ieee.org/document/11696142)。数据访问 unknown，数据许可 unknown。

<a id="p-ego2contact"></a>
### Ego2Contact

- **日期/窗口状态**：2026-10-16，in_window。
- **机制与监督**：人类训练数据来自 EgoTouch（seen 179 / unseen 85 episode 测试集），预测器输出每手 217 个有效网格单元的双手触觉场；真机平台为 xArm6 + BrainCo Revo 2 手穿每手 880 taxel 手套，VR 遥操作采集五任务约 123k 帧做配对适配。监督为人手接触场预测 + 真机 glove 测量。
- **边界**：仿真 Pen Cap Removal 任务预测触觉成功率仅 1.0%，远低于 GT 的 95.0%；未说明数据或代码发布与许可。
- **接入检查**：核对 EgoTouch 原始数据许可，确认 Ego2Contact 是否另行发布机器人 880-taxel 采集数据与代码仓库，以及 217 网格到 880 taxel 的岭回归解码与区域聚合规则。
- **来源**：[arXiv abs](https://arxiv.org/abs/2610.22932)、[arXiv HTML](https://arxiv.org/html/2610.22932)。数据访问 unknown，数据许可 unknown。

<a id="p-dexvitac"></a>
### DexViTac（outside_window 旧基础）

- **日期/窗口状态**：2026-03-18，outside_window（旧基础另标）。
- **机制与监督**：鱼眼相机、动捕手套、高分辨率触觉传感器与 T265 集成，采集紧耦合视觉-触觉-运动学演示；手部运动学用 19-DOF 伸缩/展开相对参数而非绝对关节角；以触觉 60Hz 时间戳为全局语义锚点对齐多模态流。数据集覆盖 10+ 环境、40+ 任务、2400+ 演示。
- **边界**：实采人类演示需重定向到机器人，固定基座单臂，作者自述无法双臂与长程；成功率来自四任务各 30 次试验（平均 85.8%），非同分布泛化。
- **接入检查**：核对项目页是否真发布数据集与硬件图纸，确认数据许可、触觉传感器标定/去噪参数是否随数据提供。
- **来源**：[arXiv abs](https://arxiv.org/abs/2603.17851)、[arXiv HTML](https://arxiv.org/html/2603.17851)。开源为作者计划表述，代码与数据许可 unknown。

> 说明：HapTile 已在人类手套组列为压力/视触觉混合卡；其机器人平台亦可归入机器人触觉，为避免重复，此处不再单列。

### 手持传感指（光学触觉 / UMI 式）

<a id="p-polyumi-vista"></a>
### PolyUMI / VisTA

- **日期/窗口状态**：arXiv v1 2026-09-24，v2 2026-10-20，in_window（首发为 v1，v2 为修订版）。GitHub 最早提交 2026-08-12，项目页日期 unknown。
- **机制与监督**：手持夹爪同步记录腕部相机、光学触觉指、接触音频与本体感觉，无需有线工作站；本体感觉来自 GoPro 单目惯性 SLAM + 夹爪 IMU 或 OptiTrack，加机器人关节编码器与 FK。所有观测按最慢流时间戳插值对齐，**以 10Hz 构造策略输入**；策略输出相对当前末端位姿的 16 步动作块（3D 平移 + 6D 旋转 + 相对夹爪宽度），插值为关节力矩。监督为手持示教动作块。
- **边界**：手持夹爪为 UMI 式遥操作演示，非自主采集；实验任务为 Franka FR3 上滑移控制/擦板/拧灯泡等有限任务；触觉形状识别用 135 场景共 2700 张触觉图（场景级划分）。完整视觉-触觉-音频策略滑移控制 10 次成功 8 次，纯视觉 10 次成功 2 次（论文/项目页自述，样本小）。拧灯泡任务视觉基线最佳，触觉未带来增益。
- **接入检查**：访问项目页确认代码、固件、硬件文件与数据集各自实际许可及是否已发布（论文 CC BY 4.0 不可当数据许可）；核对 GoPro 与 Pi/音频同步在 pzarr 预处理中的对齐精度、SLAM 漂移对夹爪宽度与腕部位姿的影响、感知指换装后是否需重标定。
- **来源**：[arXiv abs](https://arxiv.org/abs/2609.29760)、[arXiv HTML](https://arxiv.org/html/2609.29760)、[GitHub](https://github.com/PolyUMI-VisTA/PolyUMI-system)、[项目页](https://polyumi-vista.github.io/)。数据访问 unknown，数据许可 unknown。README 标注 vision-tactile-audio 策略 under development，代码仅在 RTX 6000 Ada 48GB 测试。
- **深读**：[PolyUMI / VisTA 深读笔记](../theory/tactile/polyumi_vista_collection_2026.md)

<a id="p-omniumi"></a>
### OmniUMI（outside_window 旧基础）

- **日期/窗口状态**：arXiv v1 2026-04-12，v3 2026-05-05，outside_window（旧基础另标，v1 提交早于窗口起点）。
- **机制与监督**：紧凑手持设备同步采集 RGB、深度、轨迹、触觉、内部抓取力与外部交互力旋；内部抓取力由电机电流经传动模型估计，不加额外指尖力传感器；外部力旋经重力偏置补偿并从传感器系变换到末端执行器系；电机化夹爪避免机械触发机构污染力/矩测量。监督为手持示教与力旋。
- **边界**：触觉通道被轻量编码嵌入，非本文重点，传感器型号未明确；仅在三个任务、单一系统实例上评估，作者自述覆盖有限；试验次数与成功判定标准需以正文/附录为准。作者自述缺“人类对齐信号如何因果影响下游性能”的隔离分析。
- **接入检查**：核对项目页是否发布数据/硬件，确认内部力估计与外部力重力补偿的标定流程及试次统计口径。
- **来源**：[arXiv abs](https://arxiv.org/abs/2604.10647)、[arXiv HTML](https://arxiv.org/html/2604.10647)。数据访问 unknown，数据许可 unknown。

### ViTaMIn（outside_window 旧基础）

- **日期/窗口状态**：arXiv v1 2025-04-08，v2 2025-09-01，outside_window（旧基础另标）。
- **机制与监督**：手持夹爪由 GoPro 10 鱼眼腕部相机、两个 AllTact 手指、同步相机与树莓派 5 + 电池组成；触觉传感器 30FPS、640×480，捕捉手指整体与接触面局部形变；SLAM 提供腕部位姿。监督为示教轨迹与触觉流；预训练冻结图像 CLIP 编码器、只微调触觉编码器。

- **来源**：[arXiv abs](https://arxiv.org/abs/2504.06156)、[arXiv HTML](https://arxiv.org/html/2504.06156)。数据访问 unknown，数据许可 unknown。

### 力/肌电与仿真

### ForceBand

- **日期/窗口状态**：2026-06-24，in_window（仅读 v1 HTML）。
- **机制与监督**：8 通道 sEMG（7 通道指相关肌肉 + 1 通道腕屈）+ IMU，物料成本可低至约 300 美元并开源 BOM；标定需约 15 分钟配对 sEMG/IMU/指尖力，之后演示采集仅需腕带与视频。数据集约 10 小时，含自我中心视频、sEMG、IMU 与逐指指尖力，覆盖四类动作与四种手势；监督为配对指尖力。
- **边界**：当前流程仅 4 名用户且需逐用户标定，跨用户泛化未解决；正文称 release 数据集但未给下载地址或许可；UR-5 抓取-挤压-放置 87% 成功率为自述，峰值力约 3.2N 至 19N。
- **接入检查**：确认 10 小时数据集实际下载地址、许可条款、是否含真值指尖力，以及 BOM 是否公开可获取。
- **来源**：[arXiv abs](https://arxiv.org/abs/2606.26093)、[arXiv HTML](https://arxiv.org/html/2606.26093)、[项目页](https://forceband-emg.github.io/)。数据访问 unknown，数据许可 unknown（论文 CC BY 4.0 不代表数据集许可）。

<a id="p-tactile-genesis"></a>
### Tactile Genesis

- **日期/窗口状态**：2026-06-21，in_window（v2 2026-07-09 为修订版）。
- **机制与监督**：统一接口下暴露二值接触、接触深度、逐 taxel 力/力矩、弹性体位移、几何邻近、接触音频与体素温度场，可配置位置、分辨率与噪声；单 GPU 可扩展至超 2 万并行环境与 1000 taxel，吞吐较既有触觉仿真器提升 3–20 倍。监督为任务奖励与特权教师蒸馏到学生策略。
- **边界**：这是仿真平台与消融研究，非原始实采数据集；真实数据仅限 XHand1 指尖聚合压力，未提供完整实采数据集；温度实验结论为当前真实硬件灵敏度不足以学习该任务；学生策略受教师上界约束。实机部署仅观察到 1–2 次连续旋转，与指尖 agg_bool 仿真结果一致。
- **接入检查**：核实 Genesis World 中触觉传感器的具体版本与提交，确认伴生 dexterous_hands 仓库是否公开及许可；实机 XHand1 taxel 布局未文档化，需确认能否与仿真 probe 布局对齐。消融结论：传感器覆盖比类型更关键，全手 200 taxel 即足够，逐 taxel 力/力矩是推荐默认表示。
- **来源**：[arXiv abs](https://arxiv.org/abs/2606.22332)、[arXiv HTML](https://arxiv.org/html/2606.22332)。代码称将发布 GitHub 但未给链接与许可，数据访问 unknown，数据许可 unknown。

## 可执行的最小对照试验设计（本文建议，尚未运行）

**目的**：在统一时间轴与划分审计下，比较“纯视觉”与“视觉 + 接触信号”在单一接触密集任务上的差异，验证接入链路而非复现某篇论文。以下为工程建议，非已跑实验。

- **输入**：
  - 一个固定工作台场景与 2–3 个物体；一台单手或双臂机械臂；
  - 一个可用的手持示教设备（或人手手套）采集约 60–100 条示教，另留 20 条用于 held-out；
  - 至少两路接触信号：光学触觉视频/图像与力或压力通道之一；记录原始时间戳，不做隐式重采样；
  - 固定相机外参文件与场景标定记录。
- **对照**：
  - A 组：仅视觉策略；
  - B 组：视觉 + 接触信号（按最慢流插值对齐到统一 10–30Hz 时间轴，具体频率依设备实测）；
  - C 组（审计用）：在 B 组数据上做“按接触序列/按物体留出”划分，与帧随机划分对比，检查性能差距。
- **输出**：
  - 每组的每任务试验次数、成功/失败计数与失败模式分类；
  - B 与 A 的成功率差及其置信区间（按二项比例，样本量由 pilot 决定，不预设阈值）；
  - C 组划分差异的 Recall/成功率差；
  - 时间同步残差统计（各路流相对参考时钟的偏移分布）与触觉基线噪声。
- **停止/复核条件**：
  - 若接触信号在基线静置状态下噪声超出传感器规格或出现持续漂移，停止训练、先做标定复核；
  - 若时间同步残差分布出现双峰或明显跳变，停止并复核时钟源；
  - 若 C 组与帧随机划分差距接近或超过 pilot 观察到的量级，回退到按接触序列/物体留出并重报结果；
  - 若某路数据许可或下载状态仍为 unknown，不得将该项纳入正式对照，仅作探索性记录；
  - 任一组试验次数不足以区分两个比例时，报告为“未定”，不写“更好/更差”。

## 下一步值得跟踪的问题

1. TouchScale、PolyUMI、HapTile、RCT、ForceBand 等的数据下载入口与数据许可是否在窗口后实际落地；代码许可与数据许可是否区分。
2. HapTile HF 页面的 HDF5 读取失败是 LFS 指针问题还是数据缺失；README 为空是否随后补数据卡。
3. Ego2Contact 仿真 Pen Cap Removal 仅 1.0% 的失败原因：是触觉场预测偏差、区域聚合规则，还是任务本身超出人手训练分布。
4. Tactile Genesis 的 dexterous_hands 仓库与 Genesis World 具体版本是否公开，实机 XHand1 taxel 布局能否与仿真 probe 对齐。
5. 各系统 SLAM/外参误差对动作块与力旋的实际传播量级；ViTaMIn 约 1/60 + 1/30 秒同步误差是否可接受。
6. RCT 的“按接触序列划分”是否成为后续触觉数据集默认划分惯例；材料留出性能 25.1±6.1% 是否在其他材料集上复现。
7. ForceBand 跨用户泛化与逐用户标定成本能否降低；FACTR 2 力矩估计在非 Piper 机型上的校准需求。
8. OSMO 的 `download_data.sh` 是否解除 TODO；HapTile、FreeTacMan 的开源意向是否有后续仓库。
