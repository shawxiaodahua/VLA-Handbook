# 自主真机数据采集系统：工程接入研究卡 / Autonomous Real-World Robot Data Collection: Engineering Access Cards

> 2026-10-25 整理；覆盖 2026-04-25 至 2026-10-25 窗口内条目，窗口外旧基础（RoboCade、PlayWorld）另标。核验范围限于公开 arXiv 摘要与 HTML 全文及项目页链接文本；未下载大数据、未运行代码、未复现实验。各条均为阅读/接入研究卡，不冒充逐篇完整复现笔记。下文数字只保留理解机制所必需且条件完整的少数，其余（代码/数据许可、发布状态）凡原文未声明均写 unknown 或未核实。

## 核心结论

- 自动化程度差异很大：AutoDex、ENPIRE、PlayWorld 宣称整环无人干预（各有平台边界）；Zero2Skill 是"自主执行 + 预算耗尽转人工"；RECALL 只在仿真里采恢复数据，真机取高不确定状态仍需人。
- 统一的口径难题是"成功"到底指什么。Zero2Skill 明确拆执行标签与结果标签（含 unknown），ENPIRE 把成功定义为固定重试次数内的单次 rollout 成功率——这两条最值得作为工程对照的标签模板。
- 数据/代码许可几乎全部 unknown，项目页"将发布"不等于已下载；PlayWorld 是旧基础且确有自主真实 play，本页并非全是新发布。
- 失败与接管轨迹的保留策略：Zero2Skill 只记录机械臂运动期间数据且不记录推理；RECALL 证明只用新恢复数据微调会严重遗忘（总体 28.4%、采集任务 0.4%），全回放才恢复到 72.4% 总体——回放策略是接入必查项。

ASCII 链路（建议的采集-核验环，非任一论文原文流程）：

```
任务/指令 → 策略执行 → [结果核验器] ─成功→ 入库(含元数据)
                │                 └失败/unknown→ [重试预算]
                │                                  ├未耗尽→ 复位/重试(记录)
                │                                  └耗尽→ 人工接管 或 安全中止
                └全程: 保留失败/接管/中止轨迹 + 执行标签 vs 结果标签分离
```

## 项目研究卡

### <a id="p-autodex"></a>AutoDex

日期 2026-06-22（窗口内，非新首发推断）。机制：以 20 相机工作单元自动完成感知、执行、标注、重置的抓取验证环路，原文称整环无需人工干预。监督信号来自后处理的多视角跟踪判定（非在线控制环标注），并生成含同步多视角与机器人状态的轨迹库。边界：仅针对固定臂-手配置的稳定抓取，双臂、移动、指间重抓与功能抓取不在范围，且继承上游 BODex 盲区。接入检查：先核实项目页是否实际放出 3593 条试验数据与采集代码及各自许可，再评估脱离致密相机阵列后位姿可靠性是否仍可用。数据/代码许可 unknown，项目页"将发布"未核实可下载。
来源：https://arxiv.org/abs/2606.23689 ；https://arxiv.org/html/2606.23689

### <a id="p-zero2skill"></a>Zero2Skill

日期 2026-07-15（窗口内）。机制：脚本驱动的自主采集、验证与复位，仅在阶段反复验证失败、耗尽显式重试预算时通知远程操作员。监督信号为 VLM 验证器，并严格分离执行标签（动作链是否跑完）与结果标签（成功/失败/unknown，基础设施错误记 unknown 而非失败）。边界：仅桌面清理单任务、双臂 Piper + 头戴 RGB-D，多轮数据飞轮仅为设计能力未完整验证，论文自述 20 次盲测不证明两数据源等价。接入检查：核对项目页是否提供数据集/采集代码及许可与轨迹数量，并确认验证器与人工一致性的统计口径。数据访问 unknown，许可 unknown。
来源：https://arxiv.org/abs/2607.14047 ；https://arxiv.org/html/2607.14047

### <a id="p-recall"></a>RECALL

日期 2026-06-22（窗口内）。机制：在 LIBERO-10 仿真中在线采集高不确定中间状态的恢复经验，扩充 VLA 训练。监督信号为仿真器可重置到中间状态所产生的在线恢复轨迹与其成功/失败。边界：全部实验在仿真，真机噪声、安全约束与重置成本未覆盖；真机获取高不确定状态通常需运行时人工接管。接入检查：核对真机上恢复演示的获取方式（是否需人工接管），以及恢复数据集是否公开及许可。数据/代码未提及公开，许可 unknown（论文 CC BY 4.0 不代表数据许可）。
来源：https://arxiv.org/abs/2606.23617 ；https://arxiv.org/html/2606.23617

### <a id="p-enpire"></a>ENPIRE

日期 2026-06-18（窗口内）。机制：两阶段框架，第一阶段编码智能体依人类反馈构建并离线验证自动环境接口（安全边界、自动复位、核验程序），固化后作为不可变 API；第二阶段进入全自动真机策略改进。监督信号为依少量成功/失败演示合成的二元奖励函数，并用夹爪扭矩作触觉替代做滑移检测。成功口径为固定重试次数（此处 8 次）内单次 rollout 完成任务的机会，而非 i.i.d. best-of-N。边界：代码链接仅在正文出现未验证，数据集发布范围未知。接入检查：核对真实数据是否发布、范围（内部/公开子集）、许可，以及自动奖励与重试口径的具体实现。数据访问 unknown，许可 unknown。
来源：https://arxiv.org/abs/2606.19980 ；https://arxiv.org/html/2606.19980

### <a id="p-robocade"></a>RoboCade

日期 2025-12-24（窗口外旧基础，非本窗口新发布）。机制：基于低成本 GELLO 控制器对人类游戏化遥操作真实机械臂（Franka FR3，与 DROID 对齐的相机配置）进行采集——这是人类参与的遥操作，不是全自动采集。监督信号为人类遥操作示范轨迹。边界：单个平台三个任务的小规模采集，非大规模公开数据集；远程遥操作的安全性约束（工作空间/幅值限制）可能影响数据分布。接入检查：核对数据集与代码是否随论文发布及许可，并评估安全约束对数据分布的影响。数据/代码 unknown，许可 unknown（论文 CC BY 4.0 不等于数据集许可）。
来源：https://arxiv.org/abs/2512.21235 ；https://arxiv.org/html/2512.21235

### <a id="p-playworld"></a>PlayWorld

日期 2026-03-09（窗口外旧基础；论文确有自主真实 play，不能宣称本页全是新发布）。机制：在 DROID 设置上无需额外硬件改造，支持最长八小时连续全自主采集，以可接受任意自然语言指令的 VLA 策略执行、扰动指令作多样性来源，训机器人世界模型。监督信号为自主 play 中的机器人-物体交互与语言指令扰动；由轻量安全过滤限定保守工作空间、VLM 检测物体漂移触发重置。边界：自博弈数据是否公开未见明确说明，夜间无人运行仅在单实验室 DROID 设置验证。接入检查：核对项目页是否真提供自博弈数据集下载、许可与帧率/视角口径，以及公开代码中安全过滤与重置的实现。数据访问 unknown，许可 unknown。
来源：https://arxiv.org/abs/2603.09030 ；https://arxiv.org/html/2603.09030

## 最小对照试验设计（本文建议，未运行）

目的：在同平台同任务上比较不同自动化程度路线，并检验失败/接管轨迹的保留与标签口径对下游策略的影响。

- 输入：同一桌面操作任务、同一机器人平台；预置固定的重试预算与人工接管规则；统一采集相机与关节记录口径。
- 对照（至少三臂）：①纯人工遥操作示范（对照基线，如 RoboCade 风格人类参与采集）；②自主执行 + 验证器 + 预算耗尽转人工（Zero2Skill 风格双标签）；③自主执行 + 自动复位（无人工介入，类似 AutoDex/ENPIRE 宣称路径，按其边界裁剪）。
- 输出（全部按五类分别计数并单独留存轨迹）：任务成功、复位成功、结果核验（成功/失败/unknown 三分）、人工接管次数与情境、安全中止次数与原因；同时保留所有失败、接管与中止轨迹，不以只保留成功轨迹的方式入库。
- 停止/复核条件：若某臂出现安全中止或接管集中出现于某阶段，暂停该臂并复核；若验证器与人工标注一致性明显不足（阈值由预备试跑标定，不预置未证数值），复核验证器实现后再续；若某臂数据许可/发布状态仍 unknown，仅作流程对照、不并入训练集。
- 统计口径：报告样本量与不确定性，不引用单次盲测作等价性结论（对齐 Zero2Skill 对 20 次盲测的自我说明）。

## 下一步值得跟踪的问题

1. AutoDex 项目页是否实际放出试验数据与采集代码，及各自许可（当前"将发布"未核实）。
2. Zero2Skill 验证器与人工标注一致性的样本量与统计不确定性；多轮飞轮是否在后续工作中获得完整验证。
3. RECALL 真机获取高不确定状态是否必须人工接管，以及恢复数据集是否公开。
4. ENPIRE 真实数据的发布范围（内部/公开子集）、许可，与 8 次重试口径在复现中的具体实现。
5. RoboCade 与 PlayWorld 数据/代码是否公开及许可，以及安全约束/安全过滤对数据分布的影响。
6. 各系统"任务成功/复位成功/结果核验/人工接管/安全中止"是否可统一成可比口径，尤其 execution 与 outcome 标签的分离能否跨系统复用。
